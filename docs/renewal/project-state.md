## 승인/관찰/제안 분리
### 사용자 설명으로 확보된 사업 방향
- 기존 편직 제품/생지 활용 가공원단 공급 확대.
- 판매처 확대 집중 제품군 **폴라폴리스, 인타록, T/R 싱글, DTY 싱글** 4종(판매량 많고 대응 수월하다는 사용자 판단; 제품군 내 우선순위·세부 SKU 미정).
- 보드레: 국내 사용은 상대적으로 적고 수출에서 사용되는 편이라는 사용자 경험. 보유 생지·원사가 많고 추가 거래처를 희망함. 1차 집중 4종과 별도의 판로 확대 기회로 검토.
- 자체 공장 편직 + 협력 가공.
- 샘플이 있는 비전문 바이어도 중요한 기회.
- **선별적 완제품 선재고(D-014, D-015):** 폴라폴리스·인타록·T/R 싱글·DTY 싱글 4개 제품군 **모두** 일부 사양에 한해 염색·가공 완료 원단을 바로 납품 가능한 상태로 보유. 여러 업체가 공통으로 찾는 사양 중심으로 선별 확보하며, 실제 SKU/색상·수량·기존 배정 상태에 따른 신규 주문 출고 가능 여부는 확인이 필요함.
- **신규 샘플 개발 원칙(D-016):** 생산 역량 내라면 새로운 고객 샘플을 적극 검토하고 샘플 자산을 확대.
- **신규 원사 조달 비용 경계(D-017):** 없는 원사를 새로 구매해야 하는 샘플은 기계 기본 투입량으로 비용이 커서 회사 부담으로 진행 어려움. 고객 비용 부담 시에만 예외 검토 가능(수락 보장 아님).
- **샘플비·생산 일정(D-018):** 보유 원사를 사용하더라도 기계 세팅 변경 등 샘플 제작 작업에는 비용을 청구. 예상 발주가 있어도 샘플비 적용 가능. 생산이 바쁘면 작업이 어려울 수 있음. 본 발주 시 샘플비 차감은 고정 정책 없이 건별 결정.
