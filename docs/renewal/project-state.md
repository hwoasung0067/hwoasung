- **2026-10-14 새로 재검토(D-022):** GSC에서 확인되는 검색어는 일반 편직/공장 탐색 비중이 눈에 띄며 클릭은 홈페이지 루트에 집중. GA4는 제품별 접근·문의 전환을 구분할 수 있는 이벤트가 부족. Gmail Tally 표본에는 주력 밖 소재/개발형 문의가 혼재. 검색어 익명화와 편의 표본 한계 주의.

- React의 상태 기반 뷰 전환, 모달형 제품 상세, Firebase 제품 로딩.
- 홈페이지 폼에 주력 외 특수·소량 원단 문의 다수 포함; 적합 사례도 존재.
