- **공급 경로별 최소량 정정(D-019):** '신규 생산 500yd 이상이면 가능' 해석 폐기. 완제품 재고는 조건부 절 단위 공급. 보유 생지 후가공은 색상·가공의 공정 최소량에 따름. 신규 편직은 세팅 변경 시 소량 수주가 대체로 어렵고 기존 세팅이어도 상당한 작업량 필요. 신규 원사 구매는 기계 단위 원사 투입량이 필요.

- **2026-10-14 사용자 승인(D-023):** A(보유 완제품·기존 생지 직접 공급형) 유효 문의를 1차 영업 성과로 우선. B(조건부 신규 샘플·사양 개발형)는 별도 성장 성과로 측정. A/B 합산으로 구매 성과를 부풀리지 않으며 문의·실제 발주를 구분.
- **2026-10-14 사용자 확인(D-024):** 첫 거래의 대량 주문과 개별 물량은 작더라도 지속되는 반복 주문이 **둘 다 중요**. 대량 거래는 제조/단가 효율, 반복 거래는 공장 가동·회전율에 의미. 샘플 후 실질 진행이 없거나, 공급 무관/높은 기술 부담과 소량·일회성이 겹치면 영업 가치가 낮음. 단일 사유로 자동 거절하지 않음.
- **2026-10-16 사용자 확인(D-025):** 홈페이지 폼 접수는 전용 이메일에만 누적되며, 블로그/톡톡/카카오비즈니스는 각 대화창만 남는다. 온라인 신규 문의부터 견적·샘플·발주·종결까지 통합 기록/후속 관리는 현재 없음. 실제 발주 시 ERP 송장에 기록되는지 및 문의와 거래처 연결 여부는 확인하지 못함.
- **2026-10-16 사용자 확인/운영 방향 승인(D-026):** 신규 발주 성사 시 기존 ERP의 거래처 등록·작업의뢰서·원단 송장으로 관리. 별도 CRM·외부 관리표 사용을 원하지 않고 **ERP 내부 영업문의 페이지 추가**를 선택. 실발주·재발주는 기존 ERP에 축적된 데이터를 활용해 파악하는 방향. ERP 내부 화면과 데이터 연동 구현은 아직 미착수.
- **2026-10-16 D-027 사용자 우려/조사:** 메일·네이버 톡톡·카카오비즈니스·전화로 문의가 나뉘어 자동화에 대한 누락 우려와 수작업 재입력 부담이 있음. 메일 연계 후보 가능, 네이버 톡톡은 챗봇 웹훅이 있어도 현재 일반 상담 전체 자동 수집은 미확인. 카카오 일반 채널 API는 1:1 대화 조회를 제공하지 않으며 공식 상담톡 딜러 연동은 별도 검토 필요. 일반 전화 자동 기록도 현재 인프라에서 미확인.
### 객관적 조사 결과
- **2026-10-14 새로 재검토(D-022):** GSC에서 확인되는 검색어는 일반 편직/공장 탐색 비중이 눈에 띄며 클릭은 홈페이지 루트에 집중. GA4는 제품별 접근·문의 전환을 구분할 수 있는 이벤트가 부족. Gmail Tally 표본에는 주력 밖 소재/개발형 문의가 혼재. 검색어 익명화와 편의 표본 한계 주의.
- GA4 이벤트 수집은 작동하나 제품별 페이지/문의 계측 불충분.
- React의 상태 기반 뷰 전환, 모달형 제품 상세, Firebase 제품 로딩.
- 홈페이지 폼에 주력 외 특수·소량 원단 문의 다수 포함; 적합 사례도 존재.
