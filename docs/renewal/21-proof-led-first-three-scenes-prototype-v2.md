## 2. 왜 새로운 시안인가
**16 v1 브랜드 탈락 원인:** 회사·원단·제조·문의라는 기업 홍보 목차를 디자인만 바꿔 반복. 실제 바이어의 기존 거래처 대비 화성섬유 평가 이유 없음.
**이번 v2의 핵심 변화:** **한 구매자의 구체적 원단 의문 → 실제 사양 판단에 필요한 항목 → 공급 가능성을 나누는 화성섬유의 운영 방식**을 콘텐츠 순서로 드러냄. 각 화면이 독립 회사 홍보가 아니라 직전 화면에서 생긴 질문의 답이 되게 구성.
- 사용자에게 '브랜딩은 설득'이므로 '홍보 문구 → 증거 없는 이미지'라는 형식은 실패임을 인정. 화면 시연에 사실 확인·미확보 지점을 명시.

## 3. 실제 제작한 세 장면 상세

### 01 HERO / Why Hwoasung?
- 시작 질문: **'이미 거래처가 있는데 왜 여기에도 문의할 이유가 있는가?'**
- 제안 카피(미승인): **“원단은 비슷할 수 있습니다. 거래의 과정까지 같지는 않습니다.”** / “원단의 이름만으로 발주를 끝낼 수 없다는 것을 압니다. 원사·편직·가공·공급 조건을 함께 살펴보는 환편 원단 제조·공급사 화성섬유입니다.”
- 시각: 짙은 청록의 절제된 큰 타이틀, 제공된 실제 공장 외관을 어둡게 톤 보정해 한쪽에 배치. 사용자가 기획해 둔 향후 **환편 실제 영상 슬롯**을 염두에 두되 히어로 영상 제작 보류 D-036 유지. 첫 프레임에도 제조·원단 사업을 명확하게 설명.
- 행동: **'우리가 확인하는 것'** → 장면 02; **'원단부터 살펴보기'** → 최하단 실제 제품 연결 자리로 점프. 고의도 바이어가 억지로 스토리를 끝까지 안 읽어도 됨.
- **주의:** 카피가 아무 제조사나 할 수 있는 보편 주장처럼 들릴 위험은 남아있음. 반드시 두 번째 장면의 자사 실물 증거와 세 번째 장면의 실제 판단 과정을 확보해 정당화해야 함. 문구는 확정 아님.

### 02 THE QUESTION / 본딩용 인타록 요청의 숨은 조건
- 보이는 가상 바이어 상황: “본딩 바닥지로 인타록 원단을 찾고 있습니다.” **실제 고객 발언 인용이 아닌 설명용 가상 질문**으로 표시.
- 왼쪽: 고객 문의 장면을 큰 타이포, 작은 텍스트로 답해야 하는 문제를 제기.
- 오른쪽: 같은 원단명보다 **폭(원통폭/가공폭), 가공 상태(생지/가공지), 후속 공정(본딩 상대 원단/결과)**가 중요하다는 설명. 세 탭에서 내용 변경; 원단 실물 A/B 영역은 서로 다른 CSS 패턴이고 **'실제 화성섬유 제품 사진·사양이 아님'**을 화면에 명시.
- **설득 목표:** 바이어가 '여기는 사양을 제대로 확인하는 제조사이겠구나'라고 판단. 단지 스펙 교육하는 블로그 글 복사로 끝나지 않게 다음 섹션에서 실제 행동으로 연결.
- 실제로 교체할 증거 P0: 화성섬유 보유 인타록 **실물 두 샘플**의 사진과 출처/원사·조직·중량·폭·가공 상태 등 해당 사례에서 검증 가능한 1~2개 구체적 차이. 실제 비교가 되는 조합인지 확인 전 숫자/결과 생성 금지.

### 03 THE RESPONSE / 가능한 공급 경로의 실제 분기
- 질문: '그럼 어떻게 공급 가능한지, 무엇을 보고 결정하나?'
- 카피(미승인): **“가능하다고 답하기 전에, 무엇이 가능한지 살펴봅니다.”**
- 실무 운영 기반 3개의 클릭 가능한 카드:
  1. **보유 완제품 확인:** 품명·폭·중량·색상·수량·가공 상태 실제 가용성 확인. 상시 재고/즉시출고 보장 아님.
  2. **보유 생지 후가공 검토:** 실제 생지 가용성, 협력 업체 염색·가공·MOQ·일정 확인. **자가염색/기모 공장처럼 표현 금지**.
  3. **신규 편직 가능성 검토:** 원사/편직기 세팅·필요 수량·공정/가공·납기 확인. 무제한 신제품/소량 맞춤 보장 금지.
- 카드 클릭 시 아래 상세 설명이 해당 경로로 교체되고 ARIA `aria-pressed` 갱신. 오토 견적·실재 주문/재고 조회 아님.
- 결론은 '제품명만 아니라 **사용 조건에서 상담을 시작**', 실제 주력 4종+보드레는 다음 단계(제품 상세 및 상담 페이지)로 안내만 제안.
- **현재 핵심 한계:** '우리가 이렇게 실제로 판단했다'는 익명화된 특정 건/실물 조건의 증거가 아직 없음. 그러므로 범용 업계 프로세스 안내에 머무를 위험이 있음. 실제 자사 상황을 붙이기 전 브랜드/해자 완성으로 말하면 안 됨.

## 4. 편집/UX 방향
- **Tintex:** 명료하고 라이트한 몸통(섹션 02 밝은 종이색, 섹션 03 연한 녹청), 명확한 버튼·제품 진입.
- **Arville:** 실제 제조 현장(현재는 외관 한 장, 향후 환편기·제품 실물 3~5컷), 큰 사진과 짧은 문구로 제조 신뢰.
- **Camira:** 굵고 적은 히어로 타이포와 유의미한 화면 대비. 심한 마우스 강제 스크롤·장식적 패럴랙스 남발 배제.
- **Yitai:** 장면 실제성. AI 생성 설비/가짜 원단을 화성섬유 제품으로 표시하지 않음.
- PC는 메인 히어로에서 제조 정체성을 유지, 장면 2는 **구매자 문의 vs 실제 확인 항목** 2열, 장면 3은 **세 공급 분기**를 3열로 보이게.
- 모바일은 가독성 최우선으로 2열·3열을 단일 열로 변경. 모바일 접이식 메뉴/장면 앵커, 실제 텍스트 오버레이, 스크롤 모션 절제, reduced-motion 대응.
- 본 영상은 아직 없고 최하단 링크는 **데모 전용**. 결제/즉시주문/상담 전송/CRM 기록 기능 없음.

## 5. 직접 실행한 QA — 기능의 범위를 정확히 표현
- Chromium Playwright 내에서 단일 파일 HTML을 읽어 `set_content` 기반 렌더(보안 환경상 `file://` 직접 탐색이 제한됨).
- 뷰포트: **1440×900 / 390×844 / 768×1024**, 문서의 `scrollWidth === innerWidth` 확인, 가로 넘침 없음.
- 390px 모바일 메뉴 열림·닫힘 확인, 폭/가공 상태/후공정 탭 내용 전환 확인, 세 공급 경로 중 신규 편직 클릭→아래 상세 내용 전환 확인.
- JS pageerror 없음.
- **확인 범위:** 시안 코드와 위 기능 테스트. 실제 사용자 테스트·LCP/이미지 실제 로딩·키보드/스크린리더 전체 접근성 평가·실제 Firebase/Tally/CRM/구매 전환 테스트 등은 하지 않음.
- 인터랙션은 브랜드 메시지 이해에 기여하는지 사용자 리뷰 후 조정할 수 있으며, 버튼을 더 늘리려고 추가한 것이 아님.

## 6. 이번 시안이 아직 완성된 브랜딩이 아닌 이유
1. 원단 비교는 **임시 CSS 시각화**라 아직 화성섬유 실물 기술력 증거가 아니다.
2. '공급 경로를 나눈다'는 것만으로 업계 독점 해자가 아니며, 실제 특정 거래에서 어떤 제약을 어떻게 검토했는지 보여줘야 차별화된다.
3. 기존 공장 사진은 외관이라 제조 내용 증명이 약하다. 실제 편직기/원사/원단 사진과 고객 사양 검토 방식의 연결이 필요.
4. 초기 히어로 슬로건도 여전히 범용 슬로건으로 읽힐 수 있으므로 **다음 두 증거 장면의 실제 자료를 확인한 뒤** 평가해야 한다.
5. 고객에게 더 저렴·빠른 납기·불량 0 등 검증 불가능한 결과를 약속할 수 없다.
6. 장기 관계/반복 거래, 실제 제품 상세/적합성·사용처·최종 상담 화면은 **후속 설계 트랙**이고 이번 세 장면에 모두 넣지 않았다.

## 7. 다음 작업 제안 — 사용자 시안 검토 후
- 시안을 보고 **‘공급 검토까지 읽으면 화성섬유와 연락할 이유가 생기는지’** 먼저 피드백 받는다. 단순 화면 톤이나 카드 크기보다 설득 내용이 우선.
- 동의되면 실물 인타록 샘플 2종의 사진/실제 다른 조건 1~2개, 실제 공개 가능한 공급 판단 사례 1건을 확인하고 화면에 실제 자료 삽입.
- 이어서 현장 증거/반복 거래/실제 제품 상세 및 조건부 상담 UX까지 서사를 확장하고, 전체 PC·모바일 시안의 정합성 검토.
- **현재 사용자 지시 범위:** 시안 제작/기록만, 본 홈페이지 리뉴얼 앱 개발·배포/영상 제작·블로그 기존 문서 변경은 별도 승인 전 시행하지 않음.
