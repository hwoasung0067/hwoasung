### 확정한 표현 원칙과 기존 전략의 관계
- **비언어적 신뢰 = 말 대신 실제 현장·실제 원단·여백·타이포·편집·움직임이 회사를 이야기하는 것.** 설명형 Why Hwoasung, 긴 설득 문단, 고객 불안 자극, '품질/신뢰/납기' 슬로건 반복 제거.
- **설득을 버리는 게 아니라 방법을 전환:** 임팩트→관심→현장/제품의 실재감→쓰임/경험→호기심→자발적인 제품 상세/문의. CTA도 강요하지 않음.
- 글은 **히어로 큰 카피 1개 + 필요하다면 여정 중 브랜드를 각인시키는 문장 1개**에 집중. 나머지는 제품명/현장 캡션/메뉴·최소 설명만. 'Why' 독립 긴 텍스트 섹션 폐기.
- 시각의 기준: Tintex의 라이트/여백/정돈된 원단 브랜딩 + Arville의 강한 현장 영상/품질 높은 실제 공정 사진 + Camira 절제된 타이포/움직임 + Yitai 자사 설비/사람/원단의 실사. 콘텐츠 양/영상 제작비의 격차를 인정하고 정지 이미지로도 성립하게 구성.
- **화성섬유 고유성은 명사를 바꿀 수 있는 강점 문구가 아니라, 실제 화성섬유 기계·원사·원단·납품 경험·고유한 편집 미감의 결합**으로 나타나야 함.
- B2B 구매자가 제품·용도를 쉽게 발견하게 하는 기능은 유지. 미학 때문에 기능 가리는 불투명 내비게이션/스크롤 강제·고성능 영상으로 인한 느린 페이지 금지.

## 2. 메인에서 남기고 싶은 감정 변화
`첫인상(감각) → 취급 원단 이해(명료) → 직접 생산 실재감(신뢰) → 사용처 연결(관련성) → 전문성·사람의 흔적(호기심) → 부담 없는 접근(기회)`.
- **메인 페이지 단독 방문만으로** '실제 원단을 직접 편직하는 제조 기반 공급처, 주요 원단/사용 분야, 일하는 회사의 분위기'가 전달되어야 함. 상세 정보를 읽지 않아도 긍정적 브랜드 기억이 남아야 함.
- 반면 한 눈에 거래 가능/확정 재고/단가/납기/전 품목 맞춤을 약속하는 것은 금지. 실제 공급은 상담.
- 메인 이탈이 많다는 기존 사용자 관찰을 브랜딩 전략상 중요하게 보되 실제 이탈률/이유·유입 세그먼트·스크롤 깊이는 아직 미검증. 이후 메인 CTA/제품 클릭·스크롤·문의 성과로 검증.

## 4. 짧은 브랜드 문구 기획(모두 후보/미승인)
**한 문장에 집중하고 '무슨 회사인가'는 보조 설명으로 명확히 한다.**
- **A(브랜드 성격 / 추천 첫 테스트):** `원단을 만드는 기술. 거래를 이어가는 태도.`
  - 자사 직접 편직의 실체 + 유연한 장기 파트너십. 단, 문구 자체는 보편적이므로 홈페이지 실제 화성섬유 현장 사진·원단과 함께 일관된 인상이 나야 함.
- **B(제조/사용처 연결):** `편직에서 시작해, 쓰임까지 생각합니다.`
  - 본딩·누빔·담요 등 고객의 다음 공정을 염두에 둔 점과 자연 연결. 자사가 모든 후가공을 직접 운영한다고 오해하지 않게 보조 설명 필요.
- **C(좀 더 감각/정체성):** `원단의 시작은 편직. 그 뒤에는 사람이 있습니다.`
  - 실제 현장 사람·협력 관계를 표현할 경우. 사진/브랜드 톤이 맞지 않으면 감성만 앞설 수 있음.
- 상단 보조 한 줄의 방향(예시): `직접 편직하는 환편 원단 제조·공급사 · 폴라폴리스 / 인타록 / 싱글 원단`.
- **사용자 확인 없이 슬로건 채택 금지.** 헤드라인은 길지 않고, 홈페이지 다른 모든 섹션에서 '신뢰/품질/납기'를 반복 강조하지 않는다.
- 카피 확정 시 'B2B 도매·가공 바이어의 손에 들어오는 원단 공급' 맥락과 30년+경력/약속의 증거 적합성 검토.

## 5. 제품/용도/파트너의 역할을 화면에 맞게 배분
- 메인(경험/취급 범주) ≠ 쇼핑몰(정확한 SKU/재고·가격·결제) ≠ 단일 상담 프로세스 안내 페이지(가상 인타록 예시를 전체 홈에 깔지 않음).
- 전문 구매자의 첫 번째 행동: **제품 상세 빠른 접근**. 원단명/사용처/실제 회사 소개는 상단 내비게이션에서 언제든 열람 가능. 상단/하단 문의 CTA는 실제 사양/색상/가공/수량/납기 확인형.
- 메인 제품은 **품목군/대표 사용 분야/이동**까지만, 규격·구매 전 확인 항목은 제품 상세/용도 페이지/블로그 지식으로 분리.
- 실제 영업 상 경계: 주력 4종의 일부 사양만 선별 보유, 보드레는 별도 기회, 신규/샘플은 공정 MOQ·원사 투입·일정·비용 협의, 색상·규격/가공 가능성 상담 필요. 메인에서 무조건 빠른 재고/단가 보장 금지.

## 6. 미디어/인터랙션 디렉션(구현 아닌 채택 기준)
- **정적 사진만으로 먼저 성립할 것.** D-036 히어로 영상 실제 제작 보류. 영상은 실제 자사 편직 장면을 확보한 뒤 포스터 영역으로 교체할 수 있도록만 설계.
- 기존 홈페이지 공장/환편 장면·블로그 자산부터 **실사 여부, 기계·제품 대응** 확인. 필요한 신규 촬영은 최소 핵심 컷으로, 향후 홈페이지와 블로그가 같이 쓰는 제조 사진 라이브러리.
- 인터랙션 3개 원칙: (1) pointer/scroll은 **원단 질감·현장 장면을 더 잘 보이게 하는 데 사용** (2) 방문자가 클릭/드래그하지 않아도 핵심 메시지·제품 이름 확인 가능 (3) 모바일/성능/접근성/모션 축소 설정에서 동일한 내용 이해 가능.
- 후보: 사진 위 미세한 시차, 스크롤 이미지 마스킹 해제, 제품 이미지 포인터 줌/크로스페이드, 짧은 슬라이드 전환. 초대형 WebGL/무거운 무한 영상/강제 스크롤/포인터 추적 장식은 브랜드보다 UI가 돋보일 위험 있어 배제.
- 실제 세부 채택은 추후 P3 디자인 디렉션 단계에서 **Arville / Tintex 실제 효과를 세부 관찰하고 성능·예산 대비 효과를 검토**한 뒤 결정. 지금 확정된 것은 ‘움직임이 인상 형성에 중요’라는 사용자 방향뿐.
- 글자가 없어도 감을 잡을 수 있지만 **명확한 업종/제품명/탐색 경로**는 반드시 남겨 SEO·접근성·문의 질 저해 금지.

## 8. 이 설계가 계속 지켜야 할 점
- D-043는 **말로 매달리지 않는 브랜드 경험 방향을 확정**한 것이지 **이 6장면/색상/카피/세부 효과가 승인됐다는 뜻이 아니다**.
- 구 시안 16/21은 사용자 거부. 설득 스크롤 17/20은 브랜드 내부 사고의 참고이지, 홈에 반드시 여섯 단계 설득 글을 표시하라는 UI 요구가 아니다. 사용자 최신 비언어적 방향이 우선.
- 브랜드 구성의 성공 테스트: 홈페이지 끝까지 내려가면 **어떤 화성섬유인가**를 이미지와 구성에서 느끼며, 적어도 하나의 원단군/실제 제조 장면/사용 맥락이 기억나고, 궁금하면 바로 상세 정보를 볼 수 있는가. 회사 이름을 타사로 바꾸어도 똑같이 어울리는 추상적 홍보 이미지/문구만 남으면 실패.
