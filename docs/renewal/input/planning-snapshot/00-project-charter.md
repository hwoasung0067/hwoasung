# 00. 프로젝트 정의서 — 작업 초안
작성: 2026-10-13 / 최근 사실 반영: 2026-10-20 / 상태: 사업 운영 사실 및 브랜드 방향(D-030) 확인, 최종 통합 프로젝트 정의서 미승인

## North Star
화성섬유의 실제로 공급 가능한 원단, 특히 기존 생산 생지를 활용한 후가공 완료 원단의 신규 B2B 판매처를 확보하고, 동일 제품의 반복 공급 기회를 확대하는 홈페이지.

## 세 가지 목적
1. 주력 원단 구매 전환: 폴라폴리스, 인타록, T/R 싱글, DTY 싱글의 실제 취급·공급 가능한 사양을 찾고 문의할 수 있게 한다. 보드레는 생지·원사 보유를 활용한 추가 판로 검토 제품이다(D-012~D-015).
2. 조건부 신규 수요: 고객이 원단 용어를 몰라도 기존 샘플·용도·사진·사용 물량으로 초기 검토할 수 있게 하되, 생산 범위/MOQ/기존 생지/후가공 적합성을 분별한다.
3. 제조 신뢰: 자체 환편·생지 편직, 장기 협력사 통한 염색·기모·후가공, 품질·소통·납기 대응의 실질적 역량을 증명한다.

## 비즈니스 범위: 반드시 사실대로
- 자체 제조: 폴리에스테르 중심 원사를 조달하고 원단을 직접 편직.
- 후가공: 협력사 염색·기모 등, 자체 보유 후가공 설비로 표현 금지.
- 구매 가능 여부: 품목별 기존 생지 보유·사양·색상·수량·가공·납기에 좌우됨.
- 현재 모든 종류의 원단을 취급/조달/복제할 수 있는 것처럼 말하지 않는다.
- 다른 공장 제품 중개·조달 확대는 장기 아이디어, 지금의 주력 제공 서비스로 광고하지 않는다.
- 공급 가능 MOQ를 하나의 숫자로 단정하지 않고 **가용 완제품 재고·기존 생지 후가공·신규 편직·신규 원사 구매**의 최소 수량과 부담을 구분한다. '신규 생산 500yd부터 가능'은 잘못된 해석으로 폐기(D-019).
- 근거 없는 숫자(불량률·누적 거래처·절대적 납기·무한 사양 대응)는 외부 공개 금지.
- B2B 소싱·제품 제조 담당자 우선. 지식 수준이 낮은 잠재 구매자를 배제하지 않음.
- 신규 샘플 작업은 생산 가능성·원사 기본 투입량·설비 세팅·작업 일정·샘플비를 검토한다. 비용을 지급해도 제작 수락/성공이 보장되지 않고 본 발주 시 비용 차감도 건별 협의(D-016~D-018).
- 대량 첫 주문과 꾸준한 반복 주문 모두 가치 있는 거래 형태다. 기존 제품과 무관하고 일회성·소량·고부담이 결합된 문의는 선별한다(D-024).

## 브랜드 포지셔닝 원칙 (2026-10-20 D-030 사용자 승인)
- '프리미엄 원단'·럭셔리 소재 공급사라는 포지셔닝은 선택하지 않는다. 제품의 고가·고급·최고 품질을 암시하는 비검증 홍보 금지.
- **제조 기술·공장 전문성 × 현대적이고 유연한 파트너십**. 제조 경험과 실물 편직 기반을 명료하고 신뢰감 있게 보여주고, 전문 용어를 모르는 잠재 바이어도 구매 목적·샘플·용도로 상담을 시작할 수 있게 한다.
- 30대 2세 운영자가 갖는 유연함은 개인 소개나 나이 강조가 아닌 브랜드 분위기·설명 방식·사용자 경험·실제 대응으로 간접적으로 나타낸다.
- 메인 최상단에 4개 제품군을 크게 진열한다는 결정은 없음. 브랜드 소개/제품 탐색/용도 상담의 구체 우선순위·메인 비주얼·슬로건·메뉴는 UX·디자인 단계에서 확정한다.
- 영업 목적은 여전히 주력 원단 직접 공급형 우선(D-023), 제품군 4종과 보드레·사용처 상담(D-029)은 그대로 유지한다.

## 홈페이지 역할
- 1차: 제품 탐색 및 실제 원단 구매 상담.
- 2차: 샘플·사양 기반 공급 적합성 검토.
- 3차: 자체 편직 공장의 신뢰와 공급 과정 설명.
- 4차: 검색에서 검색의도별 독립 제품/공급 정보 제공.
- 네이버 블로그는 정보·현장 설명, 홈페이지는 제품·조건·상담/브랜드의 권위 있는 원본.

## 결과 지표 (A 우선/B 분리 방향 확정, 세부 정의는 미확정)
- **A 기존 원단 직접 공급형 유효 문의를 핵심 성과**, **B 조건부 신규 개발 문의는 별도 성장 지표**로 관리한다(D-023). 성공한 실발주와 단순 접수는 구분한다.
- 품목별 유효 신규 구매 문의 수 / 문의 적합률.
- 같은 제품의 신규 구매처 수 / 후속 발주 수.
- 기존 원단 문의 vs 샘플 검토 문의 → 샘플/견적/거래 진행 단계.
- 제품 상세 페이지 도달, 제품코드 포함 상담 시작, 문의 완료.
- 자연검색/네이버 파워링크/직접/블로그·외부 추천 유입을 별도 측정.
- AI 검색의 확인 가능한 노출·출처 인용/추천 유입 (전체 AI 인용 추정 금지).

## 아직 결정하지 않은 것
- **우선 제품군 4종과 기본 공급/샘플 제한은 확인 완료.** 미정은 대표 SKU·사양·가용 재고의 표현 및 실제 제품 사진.
- 도매/유통과 가공/제조공장은 선호 고객으로 확인 완료. **온라인에서 어떤 고객 유형이 실제 유효한지는 아직 검증 전**이며, 상세 상담 경로·공개 문구는 미승인.
- 브랜드 디자인 방향, 콘텐츠 양, 상세 URL 구조/기술 프레임워크.
- 실제 측정 KPI 목표치 및 검증 기간.
- 전면 재구축인지 기존 코드 개선인지.

## 성공 기준
디자인이 예쁘다는 평가만으로 완료하지 않는다. 각 페이지에서 사용자 경험·내용 정확성·검색 접근성·모바일 성능·유입 분류·영업 행동 측정·관리자 운영 가능성·기존 기능 보존을 검증한다.
