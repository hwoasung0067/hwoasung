## 사용자가 명시한 운영 원칙
- 새로운 홈페이지는 **리뉴얼**이므로 현재 홈페이지에 들어가 있는 영상, 이미지 및 기존 브랜드·제품 콘텐츠를 먼저 검토하고 재사용 가능한 것은 활용한다.
- 히어로 영상, 제조 신뢰 섹션, 제품별 카드, 공장 소개 등 각 섹터에서 **기존 → 재편집·최적화 → 부족한 컷만 새 촬영·제작** 순으로 진행한다.
- 기존 파일이 저장소에 있다고 즉시 새 페이지에 쓰지는 않는다. 품질·실제 화성섬유 관련성·현재 공급 제품과 연결·화면 비율·이용 권한·웹 성능을 검수한다. 데이터/원본은 손상시키지 않는다.
- **AI 생성 공장 영상이나 타사 공장 이미지**를 화성섬유 실제 장면처럼 재사용하지 않는다.

## 재활용 판단 기준
1. **사실성:** 실제 화성섬유 시설·원단이 맞고, 해당 섹터 문구가 사실인지.
2. **품질:** 가로/세로 비율, 선명도, 흔들림, 조명·색감, 편집 가능 컷, 현장 청결/소음 등.
3. **브랜드 적합성:** Yitai식 실제 공정 신뢰 + Camira식 정돈된 표현에 맞는가.
4. **웹 성능:** 히어로 첫 화면에서 LCP/모바일·저속망 영향, WebM/MP4/포스터·지연로드·반복재생 제어.
5. **권리/보안:** 자사 촬영·사용권, 타인 초상권, 고객 주문/사양·현장 영업비밀 노출 여부.
6. **유지관리:** 같은 파일의 중복 게시·기존 제품 데이터 파손 없이 새 편집본을 사용하고 원본을 보존.

## 2026-10-20 사용자가 제시한 공장 소개 장면의 시각 평가
- 사용자는 기존 '회사 소개 GIF'라며 공장 외부가 보이는 960×540 화면을 첨부하고 **길이가 짧아 부족하다는 의견**을 전달함.
- **접근 검증:** 이번 대화에 마운트된 첨부 파일명은 .gif지만 실제 파일 시그니처가 **PNG 정지 이미지 960×540, 1프레임(약 0.83MB)**. 따라서 원본 GIF 전체의 프레임 수/재생시간/모션 품질을 이 첨부로 측정·검증할 수 없음. GitHub에 확인된 **47,703,434 B GIF 원본과 동일한 영상 파일이라고 단정하지 않는다**. 양자를 혼동 금지.
- **보이는 장면:** 화성섬유 공장 건물 외관(흰 공장동/파란 하늘), 현장 규모·실재성이 드러나는 장점. 다만 전선·주변 시설물로 시각적 초점이 분산되고 회사 간판/사업 내용이 눈에 잘 띄지 않음. 환편·원단 제조 공정을 즉시 이해하기도 어려움.
- **초기 활용 판단:** 외관 컷 하나를 영상 히어로의 주인공으로 삼기보다는 회사 소개/제조 역량 섹터 보조 자산 또는 짧은 장소 소개 컷으로 검토. **영상 첫 프레임은 기계가 실제 작동하는 현장 컷을 더 우선적으로 비교**, 외관은 촬영 내용·화질에 따라 도입부 일부로 쓸 수 있음.
- **필요한 보완:** 기존 GIF/촬영 원본 MP4 및 환편기·원사 공급·원단 롤/조업·작업자 동영상이 이미 있는지 확인한 다음, 부족한 컷만 추가 촬영. 영상 길이만 늘리려고 어색하게 정지 사진/반복 컷을 늘리지 않는다.
- **상태:** 사용자 제공 화면에 대한 정성적 평가. 영상 원본 검증·영상 재편집·모바일 성능 검증·시안 제작/승인 완료를 의미하지 않음.
