# 화성섬유 홈페이지 리뉴얼 — 실사례 기반 디자인 레퍼런스 보드 v1
작성: 2026-10-20
상태: **1차 외부 레퍼런스 조사 / 사용자 선택·최종 디자인 승인 전**
연결: D-030 브랜드 정체성 / D-031 일괄 리뷰 / D-032 상담의 사실관계 / D-033 레퍼런스 우선 디자인 워크플로

## 1. 선행 원칙
- 화성섬유는 **원단을 즉시 결제하는 전자상거래 업체가 아니다**. **보유 원단 제품명으로 접근하든, 원단의 용도·샘플로 접근하든 공급 가능 사양·폭·중량·가공·수량·납기를 확인하는 상담을 거친다.** 상담 뒤 보유 완제품·보유 생지 후가공·신규 편직 검토 등의 공급 경로를 판단한다. 기존 원단이 있다고 동일 사양·즉시 공급을 약속하지 않는다.
- 브랜드: 실제 편직 제조 전문성 × 현대적이고 유연한 파트너십. '프리미엄 원단' 브랜딩·과장된 성능·고가·럭셔리 강조 제외.
- 디자인은 AI의 임의 생성 화면에서 출발하지 않고 **실존 사이트/사례 실제 화면을 먼저 조사 → 장점 추출 → 톤&무드/레이아웃/사진/탐색 UX 레퍼런스 보드로 사용자 검토 → 검토 의견으로 화성섬유 전용 시안 구성** 순서.
- 벤치마크는 **원칙/레이아웃/정보 위계/사진 방식만**. 타 업체 사이트의 원문 카피·이미지/로고·컴포넌트를 무단 복제하지 않는다. 레퍼런스 이미지는 출처 표시의 연구용이며 화성섬유 제품·공장 사진으로 사용하지 않는다.
- **하나의 사이트 전체 복제 금지.** 메인 히어로, 탐색/카탈로그, 기술/공장 설명, 제품 상세, 상담 CTA 등 섹터별로 다른 사례의 장점을 결합.

## 2. 보드 A — 제조 현장 다큐멘터리형
- **느낌:** 실제 기계/공정/작업장의 정직함, 현실적인 신뢰. 흰색·공업 회색·차콜 계열, 기술적인 작은 정보.
- **히어로 참고:** 실제 환편기 전체/니들부·원사 공급부를 일정한 스타일의 실사로 촬영하고 짧은 한국어 설명과 연락 접근 제공. 첫 화면부터 업체가 무엇을 만드는지 드러낼 것.
- **섹터 구성:** 제조 사진 → 실제 편직이 강점인 이유 → 원단군 카드 → 작업 의뢰·사양 상담.
- **레퍼런스 1:** Delcotex 실제 생산 현장/회사 소개 사진 및 공장 설명 https://delcotex.de/de/ueber-uns (사진 참조: https://delcotex.de/fileadmin/webmaschine-07-2019-07-25-104502-w1200-q70.jpg). **주의:** 직물 직기이며 화성섬유는 환편 공장! 화성섬유의 설비처럼 보이게 사용 금지. 공장 실사 접근법만 참고.
- **레퍼런스 2:** Yitai Knitting 실제 환편기 작업 사진 https://www.yitaifabrics.com/about/company-profile.html (이미지: https://www.yitaifabrics.com/chinayogafabric/2021/08/19/4.jpg). 업종 촬영 방향만 참고.
- **장점:** 제조사 신뢰와 실제 공장 전문성이 빠르게 전달. 
- **단점:** 사진 톤이 들쭉날쭉하면 구형 공장 웹사이트처럼 보이거나 기술 설명이 무거워질 수 있다.
- **선택할 요소:** 공정·설비 실사, 가독성 좋은 현장 설명, 과장 없는 기술 정보. **비선택:** 인증·장비 숫자·실적을 다른 기업 수준처럼 과장.

## 3. 보드 B — 산업 에디토리얼·타이포그래피형
- **느낌:** 독특한 구성, 여백, 강한 한글 제목, 원단 텍스처·공정 디테일로 시선을 끄는 현대적인 공장 브랜딩. 다크/밝은 색의 명확한 대비. 디자인 완성도는 높이되 프리미엄 상품이라고 표방하지 않음.
- **히어로 참고:** 커다란 간결한 제목과 한 장의 공정/원단 실사, 명확한 CTA. 실제 콘텐츠가 늘어나도 편집형 그리드를 유지.
- **섹터 구성:** 원단 디테일 확대 → 제조 이미지/설명 → 본딩/누빔/담요 등 목적 카드 → 공급 사양/상담.
- **레퍼런스 1:** Camira Fabric 'New Heritage' 과거 홈페이지 재설계 사례 https://www.unrvld.com/work/camira-fabrics (화면 이미지: https://assets.website-files.com/60c7755784a1a5b342e0f2da/62eba968f5b5cfa009ab97e7_Camira-Homepage.jpg). **현재 실사이트 최신 화면이 아니라 디자인 에이전시 사례 이미지**로 참조한다.
- **레퍼런스 2:** Corporate Fabrics GmbH 업체 웹 화면 이미지/Techtextil 기업 정보 https://techtextil.messefrankfurt.com/frankfurt/en/exhibitor-search.detail.html/corporate-fabrics-gmbh.html (사진/웹 이미지 출처는 해당 박람회 페이지). 밝음·어두움 패널과 원단 클로즈업 병치 참고. 해당 소재의 방수/고기능 성능을 화성섬유가 제공하는 것처럼 인용 금지.
- **장점:** 오래된 공장 홈페이지와 다르게 보임. 제조 기술과 젊은 분위기 결합.
- **단점:** 디자인만 커지면 본문·제품 검색·상담 입구가 묻힐 수 있다. 한글 글씨·모바일 가독성 검증 필수.
- **선택할 요소:** 명확한 계층의 큰 타이포, 소재 클로즈업, 비대칭 편집 레이아웃 일부. **비선택:** 과도한 다크 히어로, 카탈로그 숨김, 럭셔리 카피.

## 4. 보드 C — 친절한 원단 탐색·상담 정보형
- **느낌:** 밝은 화면, 정렬된 원단 사진·제품 카드, 명료한 사용처 탐색/사양 확인, 상담으로 직결되는 UX.
- **히어로 참고:** 간결한 제조 문구 뒤 '원단명으로 상담/용도·샘플로 상담' 두 경로를 쉽게 선택하고 실제 원단 설명을 펼치는 방식.
- **섹터 구성:** 원단/용도 2경로 → 4개 주력 원단+보드레 → 대표 사양·특성 → 공급 조건 안내 → 상담.
- **레퍼런스 1:** Camira Fabrics 제품 탐색 화면 https://www.enjoy-digital.co.uk/work/turning-a-website-rebuild-into-a-growth-model/ (사이트 사례 캡처: https://www.enjoy-digital.co.uk/media/uwep4ncq/camira-growth-model-case-study-3.jpg?v=1dc7e5539dce4d0). 상세 탐색 필터·카드 구조 참고. Camira의 즉시 샘플 주문/직접 구매/수량·컬러 다양성은 화성섬유와 다름; 해당 구매 기능 모방하지 않음.
- **레퍼런스 2:** Dickson Constant 웹사이트 설계 사례 https://www.dity.fr/cas-clients/dickson-constant/ (이미지: https://www.dity.fr/uploads/2024/02/HP_dickson-1024x996.jpg). 사용처별 카드와 간결한 메뉴·정보 위계 참고.
- **참고 서비스 사례:** Sioen Industries는 기술 섬유 제품군과 적용 시장을 구분 https://sioen.com/en/products; 사용처와 제품 계층의 구분 관찰용. 브랜드 규모·인증/개발 역량과 동일시 금지.
- **장점:** 제품명이 익숙하지 않은 바이어도 쉽게 들어오고, 실제 B2B 상담 안내가 명확.
- **단점:** 상품 카드가 너무 많거나 일반 쇼핑몰처럼 설계되면 화성섬유 공급 사양의 상담 필요성이 가려짐.
- **선택할 요소:** 검색·제품명/사용처 구분, 사진·사양 카드, 상담 CTA. **비선택:** 실시간 결제·쇼핑 장바구니·무료 샘플 보장.

## 5. 종합 추천 (선택 전 가설)
**보드 A의 제조 실사 근거 + B의 절제된 편집형 시각 언어 + C의 쉬운 원단 탐색과 상담 UX**를 혼합.
- 홈 히어로: A+B의 공장·원단 실사 + 현대적 제목 구성
- 홈 2차 섹터: C의 두 가지 진입 방법(둘 다 상담)
- 원단 목록·상세: C의 명료한 카드/사양 정보 + A의 실제 공정/공급 신뢰
- 회사 소개: A의 실제 편직과 협력 가공 구분 + B의 편집 디자인
- 상담: C의 부담 없는 폼, 항상 건별 적합성 확인
- **사용자에게 선택받을 것:** A/B/C 중 주인상이 마음에 드는 것(또는 A+B+C의 요소별 조합), 참고하고 싶은 화면/요소. 브랜드 색상·UI 최종 결정 아님.
- 디자인 표본의 화면 그대로 복제하지 않는다. **실제 화성섬유 설비/제품 실사**를 확보한 뒤 독립된 화면·그래픽 언어로 확장한다.

## 2026-10-20 사용자 피드백에 따른 조사 후보 선정 (D-034)
- **우선 심화할 레퍼런스:** [Yitai Knitting](https://www.yitaifabrics.com/about/company-profile.html)의 실제 제조·시설·작업자·원단 실사와 적은 글, [Camira/UNRVLD 과거 디자인 사례](https://www.unrvld.com/work/camira-fabrics)의 히어로 집중도·여백·타이포·절제된 상호작용.
- **유지할 UX 요소:** 보드 C의 친절한 원단·용도 탐색/사양 상담 경로는 사용성 레이어로 유지하지만 현재 우선 시각 레퍼런스는 Yitai + Camira.
- **금지/개선:** Yitai의 어색한 플레이어형 첫 화면과 주력 사업/상품 파악 어려움; Camira의 실제 제조/제품 부재와 디자인 스튜디오 같은 추상성/과도한 트렌드 표현.
- **권장 다음 단계:** 촬영 스타일과 첫 화면의 시각적 정보 위계부터 세밀하게 해부하고, 화성섬유의 자체 편직 공정·제품·상담 동선에 적용한 **전용 히어로 2안 및 홈 섹터 구조**로 확장. 실제 실사 확보 계획 우선. 추가 결정 기록은 [11-selected-reference-design-direction-v1.md](11-selected-reference-design-direction-v1.md).
- **상태:** 사용자의 레퍼런스 선호는 확인, 실제 디자인 시안·색상·문구·영상 정책은 미승인.

## 6. 다음 산출물
1. 사용자가 참고 사례 중 마음에 드는 보드와 화면을 지목.
2. 원단 제품·현장 실사 및 현재 회사 그래픽 자산을 조사해 같은 톤에서 가능한 소재를 구분.
3. 선택한 사례에서 색상·타이포·레이아웃·이미지 처리·카드/CTA 등의 요소를 뽑아 **화성섬유 적용판 무드보드**와 실제 메인·제품·상담 와이어프레임/시안을 제작.
4. 사용자에게 세부 색상·레이아웃 모두 재질문하는 대신 시안으로 검토받고 수정 내용만 반영. 기능·데이터·권한/개발·배포 등은 별도 안전 검증·명시적 승인.
