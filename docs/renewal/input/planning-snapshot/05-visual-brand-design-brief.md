# 05. 비주얼·브랜드 디자인 독립 설계 브리프
상태: RESEARCH BRIEF. 컬러·폰트·레이아웃·최종 시안 미승인.

## 디자인은 별도 핵심 과제
정보 구조 후에 색만 입히는 작업이 아니다. 제품 인식/브랜드 신뢰/시각적 위계/사용성/모바일 완성도를 다룬다. 충분한 레퍼런스 조사, 방향 비교, 디자인 시스템, 실제 시안 비교와 승인 과정이 필요하다.

## 사용자 승인 브랜드 방향 — D-030 (2026-10-20)
**기본 방향 확정: 직접 편직하는 제조 전문성 × 현대적·유연한 파트너십.** 기존 2번(기술·공장 전문성)과 3번(현대적 제조 파트너)의 장점을 결합한다.
- **제외:** '프리미엄 원단 브랜드'로 포지셔닝하거나 고급/럭셔리 소재·고가/고성능 원단을 암시하는 디자인 방향은 현재 사업 준비 상태와 불일치. 프리미엄이라는 단어 대신 제조에 대한 **신뢰, 일하는 방식의 차이, 소통의 편리함**을 드러낸다.
- **제조 근거:** 실제 편직기·공정·원단 조직·생지, 공장 운영 경험, 납품 대응의 현실적 근거를 보여준다. 자체 편직과 협력업체 염색/기모/후가공을 혼동하지 않는다.
- **파트너 인상:** 이해하기 쉬운 설명, 명료한 정보 배치, 용도·샘플 기반 상담 접근, 답변과 검토가 수월한 구매 경험. 젊은 2세 운영자의 강점을 나이/인물 사진/2세 구호 대신 브랜드 UI와 실제 소통 경험으로 드러낸다.
- **디자인 연구 내 선택지:** 승인된 하나의 방향 안에서 ① 공정·제조 비주얼 강조형 ② 전문성과 사람 중심 소통을 균형 있게 드러내는 편집형 ③ 차분한 산업 그래픽·명료한 데이터 중심형 등을 비교할 수 있다. **최종 컬러·폰트·시안은 미승인**.
- **메인 메시지 범위:** 처음부터 제품 네 장으로 히어로를 채워야 한다는 승인 없음. 제조 신뢰와 상담 접근성이 한 화면 안에서 명료히 느껴지도록 검토하면서, 빠른 제품 찾기/사용처·샘플 상담 경로 모두 제공한다. 원단 판매가 1차 목표라는 사실은 유지.

## 기존 방향 비교 및 변경 이력
- 기존 A '프리미엄 소재·질감 중심' 후보는 **D-030에 의해 브랜드 포지셔닝 후보에서 제외**.
- 기존 B '제조 기술·공장 전문성' + 기존 C '소재·제조 신뢰 및 현대적 파트너십' 요소를 **결합 채택**. 다만 이전 C의 '제품을 맨 먼저 보여준다'는 히어로 순서는 확정하지 않는다.


## 2026-10-20 브랜드 인상 재검토 (검토 배경 기록, 방향은 D-030에 따라 확정)
- 사용자는 전형적인 낡은 공장 웹사이트나 원단 진열장과 다른, **현대적이면서 제조업의 신뢰를 지키는 인상**을 원함. 본인은 가족 공장의 30대 2세 경영자로서 상대적으로 유연한 소통·대응 가능성이 장점이라고 인식하나 **인물/나이/2세라는 문구를 메인에서 강조하는 것은 원하지 않음**.
- 이 가치는 실제 원단·편직 현장 이미지, 절제된 편집형 타이포그래피, 여백, 정제된 정보 UI, 쉽게 이해할 수 있는 제품/상담 동선, 확인된 공급 범위의 명확함 등을 통해 간접 표현하는 가설로 평가.
- **메인 UX 탐색안:** ① 전면 상품 카탈로그형 ② 상담·샘플 우선형 ③ 제조 기반 공급 파트너 메시지 + 원단명/용도·샘플 이중 탐색형 비교 이력. 브랜드의 '제조 전문성 + 현대적 파트너십'은 D-030 승인, 메인 화면의 정확한 동선/배치는 후속 UX 승인 대상.
- '젊은 감각' = 과한 애니메이션·3D·영어 슬로건·AI로 만든 공장/사람 이미지가 아니라 현대적인 사용성과 신뢰도. 원단·공장 **실제 시각 자료** 우선.
- P3에는 **프리미엄 포지셔닝 없이** 제조 신뢰·현대적 파트너십을 공통 조건으로 삼는 색상/타이포/레이아웃 시안 2~3개를 비교하며, 독창성이 실제 공급사 신뢰와 탐색성을 해치지 않는지 검증.
- **구분:** 기존 디자인 방향 C의 '제품을 먼저 보여주고 제조 신뢰로 이어준다'는 순서는 재검토 가설이다. 주력 4종을 전면 최상단에 보여주는 것은 사용자 승인 사실이 아니며, 제품은 첫 화면 또는 초기 스크롤에서 접근 가능하게 유지하는 방향 검토.

## 2026-10-20 참고 사례 중심 디자인 프로세스 승인 — D-033
- **순서 확정:** 홈페이지 섹터별 역할·정보구조 계획 → **실제 존재하는 관련 업계/타 업계 우수 사례 조사** → 출처·화면·채택할 요소·배제할 요소를 담은 **디자인 레퍼런스 보드 2~3개** → 사용자 보드별 선택/요소 혼합 → 화성섬유 공장·원단 실사/한글 콘텐츠를 사용해 **고유한 UI 디자인** → PC/모바일 상세 검토.
- **1차 조사된 실제 사례 보드:** [10-design-reference-boards-v1.md](10-design-reference-boards-v1.md). A 공장 실사·제조 다큐형 / B 산업 에디토리얼·타이포형 / C 친절한 제품·사용처 탐색형. **아직 보드 선택·최종 무드보드·시안은 미승인**.
- 실제 홈페이지 캡처, 디자인 에이전시의 과거 캡처, 순수 촬영/제품 레퍼런스는 각각 **출처 유형을 구분**. 관련 기업의 포지셔닝·품질/성능/공장 규모를 화성섬유에 그대로 적용하지 않는다.
- 디자인은 무조건 새로운 발명을 지향할 필요 없음. **레퍼런스의 작동 원리를 추출하고 섹터마다 맥락에 맞춰 결합**하되 타사의 로고/이미지/카피/디자인 코드·레이아웃을 무단 복제하지 않는다.
- 실제 환편기 사진과 원단 이미지 확보가 중요하며 직물 직기 사진을 환편기 공정처럼 설명/사용하지 않는다.

## 2026-10-20 사용자가 평가한 두 실제 사례 기반 디자인 방향 (D-034)
- **사용자 선호:** Yitai Knitting 회사 소개의 실제 시설·작업자·제품 사진이 주는 명확한 제조 신뢰, 짧은 글로 직관적인 회사 이해. Camira/UNRVLD 과거 히어로의 세련된 정리, 집중도, 과하지 않은 움직임과 인터랙션.
- **사용자가 피하고 싶은 점:** Yitai 첫 화면의 조잡한 임베드/유튜브 플레이어처럼 보이는 영상 UI, 첫 화면에서 주력 사업·제품을 즉시 이해하지 못하는 구성. Camira에 실제 공장·제품 사진이 적어 디자인 전문 스튜디오처럼 보이는 느낌, 지나친 트렌디함·추상성.
- **권장 조합(시안 전 가설):** **Yitai가 무엇을 보여줄지(편직 현장·사람·원단)를 정하고, Camira가 어떻게 보여줄지(히어로·타이포·여백·절제된 움직임)를 결정하도록** 함. 핵심은 공장을 실사로 증명하고 회사를 한눈에 이해시키는 것. 두 사이트의 원본 사진/이미지·고유 디자인을 복제하지 않는다.
- **비주얼 우선:** 실제 환편기 공장과 조업 장면·원단별 서로 다른 실사 촬영부터 계획. 인물은 홍보용 모델이 아니라 실제 현장 작업 기록, 초상권/정보보안 준수. 협력 후가공을 자체 설비처럼 보이게 하지 않는다.
- **영상:** 자동/수동 영상 자체를 금지하는 것이 아니라 **어색한 플레이어 삽입을 피한다**. 필요하면 완성도 있는 짧은 음소거 영상과 대체 정지 사진을 비교하되 현재 출발안은 실사 히어로. 모바일·성능·reduced motion 준수.
- **다음 디자인 검토:** 정돈된 실사 사진을 사용한 '분할 히어로' 대 '사진 전면형 히어로' 등 최소 2가지 레이아웃을 브랜드 메시지와 함께 비교. 두 안 모두 첫 화면에서 원단 직접 편직·공급사의 정체성과 상담 경로가 명확해야 한다. 최종 문구·색상·실제 사진·효과·화면 승인 전.
- 사용자 세부 의견과 권장 구조/촬영 브리프는 [11-selected-reference-design-direction-v1.md](11-selected-reference-design-direction-v1.md) 참조.

## 2026-10-20 후속 히어로 방향 질문 (사용자 선호 확인, 최종 시안 미승인)
- 사용자는 Camira처럼 **영상과 한글 타이틀이 결합된 인상적 히어로**를 선호. 평범한 타이포+공장 사진만으로는 기존 제조사 사이트와 차별화하기 어렵다는 관점. 정적 히어로 우선 추천을 **재검토할 것을 요청**.
- **디렉터 판단:** 실제 화성섬유 환편기·원사·원단 생산·현장 장면을 8~12초 전후로 정교하게 편집한 **영상 히어로를 1차 비교안**으로 검토하되, 초기 프레임·고정 텍스트에서 무엇을 직접 제조·공급하는 회사인지 이해되도록. 유튜브 삽입 플레이어 프레임형 첫 화면은 제외.
- 실촬영 소스의 퀄리티·제작비/인력·모바일 성능을 고려한 **정적 사진 대안**도 함께 테스트. 영상 자체가 '차별화'라는 주장은 하지 않는다. 타사 영상/실사 도용/원단 고급 등급 오인 금지.
- UI·구현 요건 후보: 무음/비침습적 자동재생, 정적 포스터와 플레이백 실패 대체, 텍스트와 CTA 지속 노출, 동작 줄이기 지원, 사용자 일시정지 기능, 성능/LCP 테스트.
- 자세한 비디오 콘셉트 및 리스크와 추천 시안은 [11-selected-reference-design-direction-v1.md](11-selected-reference-design-direction-v1.md). **아직 영상 제작·확정/코드 배포 승인 전**.

## 2026-10-22 핵심 레퍼런스 선택 — D-037
- **사용자가 직접 확인하고 선택:** Arville과 Tintex 모두 좋음. 더 이상 양자택일/선호 반복 질문하지 않는다.
- **Arville에서 원하는 것:** 고품질의 실제 공장·공정 사진과 다량의 영상이 만들어 내는 믿음직한 제조사 이미지. 단, 현재 화성섬유가 동일한 양과 수준을 바로 찍고 제작하기는 부담된다는 현실적 우려. 촬영한 자료는 홈페이지와 블로그 콘텐츠에 모두 활용 가능하다는 기회.
- **Tintex에서 원하는 것:** 더 라이트하고 깔끔한 표현, 환편/원단 업종 유사성. 화성섬유에 현실적으로 적용할 **초기 디자인 톤/정보 밀도 기본형**으로 검토.
- **추천 디자인 조합:** Tintex의 시원한 레이아웃/명료한 정보 구성 + Arville의 현장·제조 사실을 보여주는 미디어 퀄리티 + Camira의 절제된 히어로/타이포 + Yitai의 실제 공장·사람·원단 사진. Arville의 방대한 영상·촬영량을 오픈 필수조건으로 두지 않는다.
- **촬영·운영 설계:** 기존 사진/GIF/Cloudinary 제품 이미지 선별 재활용 → 최소한의 신규 핵심 컷 제작 → 홈페이지·네이버 블로그에 공용 활용 가능한 촬영 및 메타정보 관리 → 나중에 미디어 확장. 제조 실사(자사 현장/제품 사양 일치)만 실제 화성섬유 생산 증거로 사용.
- **상태 구분:** 레퍼런스 선택은 승인되었으나 본문 섹터 구성·사진 비율/색/타이포/영상 구현·웹 개발은 최종 미승인. D-036의 히어로 영상 **제작 보류 지속**.
- 자세한 선택 이유 및 각 사이트별/섹터별 채택 요소는 [15-verified-website-design-references-v1.md](15-verified-website-design-references-v1.md).

## 디자인 연구 과정
1. 섹터별 역할과 브랜딩 톤앤무드를 정의한 뒤 **실제 사이트/케이스 스터디의 확인 가능한 화면을 수집**(유행성·오용·저작권 주의).
2. 화성섬유 현재 브랜드 자산(로고, 사진, 공장/원단 실사, 사업 표기) 재고 조사.
3. 2~3개 **실사례 레퍼런스 보드**를 사진/타이포/그리드/제품 탐색/상담 섹터 단위로 비교하고 화성섬유 적합성·제외 요소 평가. 사용자 선택 후 적용 무드보드 결정.
4. 컬러/타이포/그리드/여백/버튼/폼/카드/표/상태 컴포넌트 디자인 시스템.
5. 홈·제품 목록·제품 상세·문의 핵심 화면 PC/모바일 비교 시안.
6. 클릭 가능한 프로토타입, 최소 사용자 과제 검증.
7. 승인 시안을 코드로 구현할 컴포넌트·상호작용 명세로 변환.

## D-035 리뉴얼 자산 활용 기준 (2026-10-20)
- 디자인 레퍼런스를 고른 다음 처음부터 모든 이미지를 새로 만들지 않고 **기존 홈페이지의 사진·GIF/영상·제품 Cloudinary 이미지·로고**를 선행 조사하고 시안의 섹터와 연결한다.
- 확인된 정적 자산 및 사용 위치/확인 한계는 [12-existing-media-asset-audit-v1.md](12-existing-media-asset-audit-v1.md). 영상 히어로는 기존 회사 소개 GIF/가능한 원본 동영상부터 검토하되, 47.7MB GIF 원파일을 무거운 히어로로 직사용하지 않는다.
- 확인된 파일 존재만으로 실제 품질·자체 촬영/사용권·제품/현장 일치가 검증된 것은 아니다. 결과를 `그대로 활용 / 재편집 / 보조 자료 / 신규 촬영 필요`로 나눠 사용자에게 제시한다.
- **Yitai식 실제 제조 현장 실사**를 확보하고 **Camira식 타이포·정보 위계·절제된 움직임**으로 재구성. 타사 사진/영상으로 자사 현장을 대체하지 않는다.
- 기존 자산/원본은 보존, 편집본을 별도로 만들어 회귀 테스트. Cloudinary/Firestore 등록 제품 데이터는 승인 전 수정 금지.
