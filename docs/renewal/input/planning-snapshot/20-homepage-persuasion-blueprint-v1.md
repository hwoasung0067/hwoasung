## 1. 이번 단계의 결과물과 다음 결정
- **현재 작업:** 홈페이지 브랜드의 관점/핵심 고객 불확실성, 1개의 핵심 증거 장면, 스크롤 단계별 의미, 필요한 실제 자료의 우선순위를 정리.
- **다음 사용자 검토:** 문구 자체보다 구매자에게 남길 **'왜 화성섬유를 검토할 가치가 있는가'**의 논리가 맞는지 보고 수정한다. 상세 문구·화면 디자인은 미승인.
- **그다음:** 2~3개 핵심 설득 장면의 PC·모바일 와이어프레임 → 증거 실사진/익명화된 사례 확보 → 실제 비주얼 시안 순. 구 시안과 색상/이미지 교체만 하지 않는다.

## 2. 구매자에게 제안할 선택 이유 — 내부 전략 정의
가설: **원단을 사양으로 이해하고 직접 편직할 수 있는 기반 위에서, 선택적 보유 완제품·기존 생지 및 협력 가공·조건부 신규 편직을 검토하고, 반복 거래에서 고객별 공급 맥락을 축적하는 제조 기반 공급 파트너**.
- '품질·납기·신뢰'는 기본 기대치, 브랜드를 구별할 구체적 증거 없는 차별화 구호가 아님.
- **기술 판단 → 현실적인 공급 경로 → 관계의 축적**을 한 번의 이야기에 연결하는 것이 현재 검증할 **운영 방식의 해자 후보**.
- 모든 소재·사양에 대응한다거나 당일 출고 가능, 최저가, 오차 없는 생산, 완벽한 납기를 보장하지 않는다.
- 기존 거래처를 무조건 대체시키려는 이야기가 아닌 **새 사양/대체 공급처/두 번째 공급선/반복 거래 파트너로 상담을 시작할 합리적 이유**도 설계한다.
- 기술 설명이 길어지면 도매·유통 바이어는 이탈할 수 있음. 기술적 깊이는 구체 사진/짧은 캡션으로 전달하고, 제품 바로가기는 첫 화면에서 제공한다.

## 3. 창의적 방향을 구별하는 세 가지 제안
| 후보 | 후킹 관점 | 강점 | 한계 | 판단 |
|---|---|---|---|---|
| **A. '같은 원단 이름만으로는 부족하다'** | 원단의 실제 조건을 확인해야 한다 | 기술 전문성을 직관적으로 증명 가능, 블로그와 연결 | B2B 가공사에 편중돼 도매 바이어의 공급 동기가 약할 수 있음 | 핵심 첫 스크롤의 시각 증거로 사용 |
| **B. '원단은 비슷해도 거래 과정까지 같지 않다'** | 요구 사양과 실제 공급 방식·관계를 통합해서 이야기 | 도매/가공 모두 포괄, 기존 거래처 대비 검토 유인, 장기 거래 브랜딩과 조화 | 카피만으로는 흔한 추상문장이므로 실제 사례와 운영 방식이 반드시 뒤따라야 함 | **전체 메인 메시지의 1순위 테스트 가설** |
| **C. '작지 한 장으로 통하는 관계'** | 반복 거래의 사양 이해·소통 장벽 감소 | 실무 경험을 바탕으로 기억에 남는 이야기 가능 | 처음 방문한 바이어의 현재 수급 문제와 바로 연결되지 않을 위험; 실제 고객 사례 외부 공개 검증 필요 | 후반 '관계' 섹터의 강한 증거로 사용 |

**추천 조합:** B를 전체 브랜드 서사, A를 **실제 기술 차이 시연**, C를 **장기적 거래 편익**으로 쓴다. 이 혼합이 '공장 소개/제품 리스트/문의'라는 순환을 탈피할 가능성이 가장 높음. **전체 서사는 미승인 가설**.

## 4. 새 메인 홈페이지의 6단계 구매자 심리·장면 연결
| 단계 | 구매자의 생각 | 화면의 한 문장/의도 (모두 카피 미승인) | 실제 보여줄 콘텐츠 | 고객 행동/다음 스크롤 이유 |
|---|---|---|---|---|
| **01 히어로 / 이유** | '현재 공급처도 있는데 왜 이 공장을 봐야 하나?' | **‘원단은 비슷할 수 있습니다. 거래의 과정까지 같지는 않습니다.’** + '직접 편직하는 환편 원단 제조·공급사 HWOASUNG' | 기존 실제 현장 정적 포스터. 추후 자사 실제 제조 영상 교체 슬롯 + 명료한 제품군·상담 바로가기 | '무엇이 다르다는 거지?' → 다음 증거로 유도 |
| **02 기술 시연 / 제품명의 함정** | '내가 찾는 같은 제품명이라도 정확한 사양이 맞을까?' | ‘같은 인타록이라고 같은 조건일까요?’ | 자사 실제 인타록 샘플 두 개를 **검증된 차이 하나**(가공 전/후 폭 또는 조직/중량 등)를 따라 크게 비교. 마우스/스크롤 시 ‘무엇이 다른가’ 캡션 등장. 실제 해당 샘플 검증 전 임시 그래픽은 증거로 쓰지 않음 | ‘여기는 편직·후가공 조건을 구분할 줄 아는구나’ |
| **03 공급 의사결정 시연 / 방법의 차이** | '그럼 내 원하는 규격/수량/납기에 어떻게 대응하나?' | ‘원단명보다, 실제 가능한 공급 경로를 먼저 확인합니다.’ | 요청 조건 카드 → `보유 완제품 확인` · `보유 생지 협력 후가공 검토` · `별도 편직 가능성 검토` 3경로. **자동 견적·모두 가능이라는 표시 금지**. 각 경로는 재고·공정 MOQ·원사/편직 스케줄 조건 확인 필요 | ‘매뉴얼대로 될 수 있는지 검토하는 공장이구나’ |
| **04 제조 증거 / 사실의 무게** | '이런 판단을 할 수 있는 근거는?' | ‘원사를 살펴보고, 직접 편직하는 현장에서 답합니다.’ | 실사 환편기/실제 생지/기존 보유 가공지/원사 + 자사 편직 vs 협력사 가공 역할 구분. 사진은 Arville식 편집, 정보 밀도는 Tintex식 짧음 | '직접 운영하는 실체가 있다' |
| **05 관계의 증거 / 재주문** | '한 번 상담해도 결국 거래에서 또 골치 아픈 일 생기나?' | ‘처음엔 확인할 것이 많습니다. 거래가 이어지면 서로 아는 것도 많아집니다.’ | 고객 비식별 처리 후 공개 허락받은 실제 반복 거래/작지 흐름. 사용자 과거 회고 '작지 한 장' 이야기 **게시 전 정확성/범위 재확인**. 빈 후기/가짜 추천사 불가 | ‘첫 주문 이후도 함께 일할 가치가 있을 수 있겠네’ |
| **06 제품·CTA / 맞춤 판단** | '내가 필요한 원단도 취급하나? 어떻게 확인하지?' | ‘찾는 원단의 조건을 알려주세요.’ | 폴라폴리스, 인타록, T/R 싱글, DTY 싱글·보드레 / 용도 본딩·누빔·PU코팅·담요 / 제품명 사양 상담 및 용도·샘플 상담 두 경로 | **사양·수량·색상/가공·일정에 대한 조건 검토** 시작 |
- **빠른 경로는 필수:** 전용 제품 링크·메뉴·상단 CTA를 첫 화면부터 제공하여 B2B 전문가가 긴 스토리를 읽지 않아도 제품/상담으로 이동.
- 같은 원단 기술 설명, 공급 경로, 사진 증거가 각각 '추상적 전문성'만 반복하지 않고 질문을 하나씩 해결해야 한다.

## 5. 핵심 차별화 연출: '한 건의 주문을 이해하는 과정' (실제 사례 확인 전 데모 프레임)
단순 원단 카드보다 **해당 공장만의 판단 과정**이 드러나는 시연을 추천. 유사 업체도 모방할 수 있는 UI이므로 **실제 자사 원단/실사/판단**이 반드시 있어야 차별화.
1. 바이어가 던지는 예시: `“본딩 바닥지로 인타록을 찾습니다.”` (설명용 가상 질문이며 실재 고객 대화 인용 아님).
2. 제품명 외 확인: 실제 샘플/기존 사용 원단, 가공지인지 생지인지, 목표 중량·가공폭, 상대 원단과 본딩 후 상태, 색상/수량/일정 등 **조건을 알 수 있는 만큼** 확인.
3. 실제 화성섬유 쪽에서 확인 가능한 경로: 일부 취급 완제품/기존 생지/가공·편직 가능성의 각 조건. 이 예시를 특정 판매 가능한 SKU·재고·약속된 일정처럼 표현하지 않음.
4. 실제 두 원단 사진(전후/서로 다른 사양) + 자사 공정 사진 + 분기 선택의 짧은 텍스트.
5. `'같은 인타록'만으로 발주 판단을 끝내지 않는다`는 **행동을 보여주면**, 사용자는 회사의 판단 수준을 스스로 평가 가능.
6. 이 장면이 완성되면 제품 상세·본딩 관련 블로그 글과도 이어져 여러 채널에서 같은 브랜드 약속을 실증한다.

## 7. PC·모바일 UX 방향 (디자인 작업 전)
- PC: 강한 현장 히어로+짧은 주장 → **실물 비교**를 크게 보이는 스크롤 장면 → supply decision 경로 도식 → 자사 사진/짧은 캡션 → 익명 반복거래 증거 → 실제 원단/조건 문의.
- Mobile: 실물 원단 2장 비율 크고 자막 제한, 3경로 설명 한 열로, 스크롤 중 읽기 방해하는 패럴랙스 과용 금지. 제품/문의는 상단 메뉴에서 빠르게 접근.
- **시각 레퍼런스는 Arville/Tintex 그대로 유지:** 화성섬유 촬영 수량의 현실성 및 미디어 슬롯 고려, Camira 효과는 내용이 바뀌는 순간에 절제해서 적용. 외관/현장 사진 중복, 실사 아닌 원단 그래픽을 사진처럼 사용 금지.

## 8. 이전 시안과의 차이 검증
- 옛 v1: 섹션 수만 바뀌는 '원단/제조/상담' 정보 진열 → 사용자 D-038 거부.
- 새 제안: **바이어의 의심이 변하는 근거 있는 순서**를 설계하고 특정 인타록/본딩 발주를 시연하는 시그니처 장면 1개를 핵심으로 둔다.
- 구별 테스트: 화성섬유 이름을 가린 뒤 02/03/04/05가 **자사 실제 원단·실제 공정·진짜 거래 판단**을 증거로 담았는가? 없다면 여전히 범용 템플릿. 실제 자료 추가 전 '해자 확정'이라고 부르지 않는다.
- 브랜드 메시지 후보 B(A/C 보완)는 **아직 사용자 승인 전**. 사용자가 직관적으로 '왜 거래 검토할까?'를 느끼지 못하면 슬로건뿐 아니라 증거 순서를 다시 검토.
