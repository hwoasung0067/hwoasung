## 5. 홈페이지 브랜딩으로 가져올 '원리'와 카피 가설
### 기존 17 설계의 보완
'구매자의 위험→우리가 검토한다'는 업계의 범용 문장만으로는 여전히 약하다. **블로그에서 입증하려고 해온 차별화는 다음의 결합**:
**원단의 느낌·용도를 기술적 조건으로 해석 → 원사·편직을 직접 이해 → 보유 완제품/생지·가공 경로의 현실적인 선택을 설명 → 반복 주문의 예측 가능성·업무 편의를 위한 관계를 쌓음.**

해당 흐름은 다른 제조사도 주장할 수 있으므로 차별성을 입증할 **실제 화성섬유의 특정 제품/특정 상황에 대한 사양 판단 예시·결과** 필요.
브랜드 방향 카피 후보(사용자 승인 전):
1. ‘**원단의 조건을 아는 제조사, 공급의 다음 단계까지 생각합니다.**’ (보수적)
2. ‘**원단을 묻는 질문에, 생산과 공급의 조건으로 답합니다.**’ (실무형)
3. ‘**같은 원단명보다, 실제 사용할 수 있는 사양이 중요합니다.**’ (문제 제기형)
4. ‘**느낌을 스펙으로. 사양을 실제 공급으로.**’ (기존 블로그 슬로건 연결형; 다소 추상적/실현 능력 오해 여부 검증)

### 가장 강한 2가지 시각 증거 후보
- **'보이는 차이' 실제 원단 두 샘플:** 같은 원단군이라도 원사/조직/중량/폭/기모 등 확인 조건에 따라 무엇이 달라지는지, 실제 동일 회사 제품 두 점을 보여주는 사진 + 사양 차이/비교 기준.
- **'공급 선택' 같은 요청의 현실적 분기:** 특정 실제 원단·일정·수량 요구를 기준으로 '보유 완제품 확인 / 기존 생지 가공 상담 / 신규 편직 검토'의 차이가 왜 발생하는지 **허용된 범위의 실재 예시** + 직원의 확인 행위.
이 두 장면이 확보되면 기존 17의 문제→해결이 **화성섬유 고유 판단을 보여주는 설득**으로 달라질 수 있음.

1. **히어로:** 브랜드 편익/태도 + 무엇을 편직·공급하는 회사인지 짧고 명확하게, 영상은 D-036 제작 보류·교체형 슬롯 유지.
2. **첫 설득 스크롤:** ‘같은 폴리에스테르/같은 인타록이라도 요구 조건이 다르다’는 **실제 원단 샘플 비교**(DTY/FDY, 인타록 가공 전후 등 실제 자료)로 문제를 눈으로 보여줌. 블로그 지식 재서술로 장문 채우지 않음.
3. **둘째:** 고객 샘플/사용처에서 확인한 조건→완제품/생지 후가공/편직 가능성의 **사실 기반 상담 프로세스**. 불가능할 수 있는 경우까지 솔직하게 구분.
4. **셋째:** 실제 자체 편직·보유 제품·협력 가공 운영(Arville의 증거 사진 접근, Tintex의 라이트한 편집).
5. **넷째:** 실존·익명화 가능한 반복거래 상황 1건/재주문을 위한 공급 확인. 실증 전 문구 확정·가상 고객 후기 생성 금지.
6. **마지막:** 폴라폴리스/인타록/T/R 싱글/DTY 싱글·보드레로 구체적인 원단에 접근 → 해당 용도/공급 조건을 알고 있는 정보만 가지고 실제 상담(모든 경로 상담 필수).
7. **블로그와 홈페이지 역할 분리:** 블로그는 구매 전 사양 질문의 자세한 답/기술 근거와 검색 유입, 홈페이지는 실제 취급 제품·제조 행위/사례·선택 가치/사양 상담 전환. **관련 글 링크는 증거와 맥락이 있을 때만**. 웹 SEO는 카탈로그·제품 상세의 고유 텍스트, 블로그 본문 통복제 금지.

## 7. 아직 확보되지 않은 근거와 승인 경계
- 현재 blog-agent 글은 회사의 **마케팅 메시지와 독자 설득 원칙**을 강하게 보여주지만, 이를 뒷받침할 설비·LOT·고객별 객관적 실제 사례가 전부 갖춰졌다는 뜻은 아님.
- 과거 #21 TR 납기 대응, #23/#24 담요 제작 등 좋은 서사라도 고객사·작업지/출고 기록/당사자 확인을 거쳐서만 실 사례로 홈페이지 메인 배치.
- AI로 만든 이미지/도식은 디자인·설명 자료로는 활용 가능하지만 실제 제조·납품 '증거'로 사용 불가.
- 레퍼런스 Arville/Tintex D-037 유지; 실제 영상 제작 D-036 보류 유지; 16 구 시안 D-038 브랜드 부적합 유지.
- **사용자 확인이 필요한 것:** 홈페이지 서사 축(사양을 이해하는 편직사→공급 경로를 함께 판단하는 공급사→반복 거래 파트너)이 실제 화성섬유가 원하는 고객 선택 이유와 일치하는지, 공개 가능한 제조/사양/반복거래 사례를 무엇으로 채울지. 별도 설문·인터뷰 항목 반복하지 않고 **한 번에 설득 보드로 제안**해 수정 요청 받기.
- **현재 작업은 리서치/설계 기록**이며 실제 운영 코드·콘텐츠 게시·GitHub blog-agent 문서 수정·배포는 하지 않음.
