# 입력 자료 보존

이 폴더는 원문/스냅샷의 보존 영역이다. 관례상 읽기 전용이며 OS 권한/훅이 설치된 것은 아니다. 새 자료는 새 ID로 추가하고 기존 자료를 요약본으로 덮어쓰지 않는다.

- `planning-snapshot/`: 이번 구조화 직전의 GitHub 번호 문서와 결정/인계 스냅샷. manifest에 커밋·SHA256 기록.
- `feedback/`: 이 채팅에서 사용자가 제공한 피드백의 정확한 발췌. 이전 전체 세션 원문 확보와 구분.
- `source-register.md`: 외부 매뉴얼·출처. PDF 원본은 외부 폴더에 보존하고 공개 저장소에 복제하지 않음.

원본 수정이 필요한 정정은 새 correction 기록으로 원본을 참조한다. 잘못 유입된 민감정보의 제거는 일반 피드백 보존과 별도 절차다.
