## 2026-10-22 확정 — D-044 브랜드 기본 방향
사용자가 다음 제안에 **“제안한 방향 마음에 들어”**라고 명확히 답함:
- **브랜드 중심 성격:** **“전문성이 있어서 믿음직한데, 막상 이야기를 나눠보면 어렵지 않고 말이 통하는 회사.”**
- **핵심 두 축:** 실제 원사·편직·원단 사양을 이해하는 **제조의 전문성** × 상담·거래 과정의 심리적 거리감을 줄이는 **가까운 소통/유연한 태도**.
- **긴 브랜드 내러티브(내부 설명용):** “제조의 문턱을 낮춘다”는 무료·초소량·무제한 맞춤을 뜻하는 것이 아니라, 실제 공급 가능한 원단/사양/일정·MOQ의 제약을 이해하기 쉽게 확인하고 대화하는 태도.
- **구분해서 기록:** 사용자가 승인한 것은 **브랜드 기본 방향**이며, 문구 A `제조는 전문적으로. 소통은 가깝게.`, B `원단 제조를, 더 가깝게.`, C `원단을 아는 공장. 말이 통하는 관계.` 가운데 **특정 슬로건이나 히어로 문구 채택은 아니다**. 이전 히어로 문구에 불만을 표현한 사실도 유지.
- **최신 홈페이지 표현 원칙 D-043 유지:** 메인에서 긴 자기설명·압박성 영업/‘Why Hwoasung’ 반복 금지; 짧은 핵심 타이포+실제 제조/원단 사진·영상/여백·마이크로인터랙션으로 시각적 신뢰 전달. 영상 제작 D-036 보류.
- **다음:** 승인된 2축을 바탕으로 히어로 문구의 톤(상징적/직관적/브랜드 서명형)과 고유 표현을 비교 검토하되, 사용자 결정 전 임의 시안 구현/기획 확정 금지.

## 1. 회사 브랜드의 유력한 긴장 관계
**편직 제조의 실체와 전문성** + **접근하고 대화하기 쉬운 업무 관계**.
- 양쪽 모두 존재해야 한다. '가까움'만 강조하면 동네 친절한 소량/맞춤 제작 대행·모든 샘플 수락처럼 오인될 위험.
- '기술'만 강조하면 다른 환편공장의 홈페이지와 구별되지 않는 장비/30년 경력/품질 자체 평가가 된다.
- 최신 실제 사업은 완제품 원단 공급 우선, 직접 생지를 짜는 제조기반 + 협력 가공, 일부 주력 사양의 선재고. 홈페이지에서 **편직 의뢰 서비스만이 주력인 것처럼** 말하지 않는다.
- 도매·유통·가공 바이어는 이미 산업 전문성이 있을 수 있으므로 '우리가 어려운 제조를 교육해서 가깝게 만들어 준다'는 어린이용 안내/무조건 낮은 진입 장벽 같은 메시지 금지. **소통의 거리, 사양을 이해해주고 실무 대화가 통하는 태도**가 핵심.
- 제조역량의 증거는 실제 사진·원단·사양과 합리적 공급 경로. 가까움의 증거는 응답/판단 과정·고객이 정보를 찾기 쉬운 홈페이지/반복 거래의 사양 이해 및 실제 확인 가능한 사례. 가짜 후기/숫자/무조건적 결과 보장 금지.

## 2. 브랜드 방향 3가지(비교/미승인)
| 후보 | 관점 | 대표 후보 문구 | 매력 | 주의 |
|---|---|---|---|---|
| **A. 전문성을 가깝게 (우선 탐색 추천)** | 제조의 깊이와 대화의 접근성 | **‘제조는 전문적으로. 소통은 가깝게.’** / **‘편직은 깊이 있게. 소통은 가깝게.’** | 두 핵심 성격을 동시에 간결하게 기억시킴. B2B 제조사답고 구호 과하지 않음 | 아직 일반 제조사도 쓸 수 있는 메시지이므로 자사 환편 사진·실물·명료한 UX가 붙어야 차별화. '제조는 전문적으로'가 구체 편직을 가리지 않게 보조 업종 설명 |
| **B. 제조의 문턱을 낮추다** | 고객과 공장의 심리적 거리 해소 | **‘원단 제조를, 더 가깝게.’** / **‘더 가까운 제조.’** | 짧고 시각 디자인하기 좋은 브랜드 선언, 사용자 본인의 원래 생각과 연결 | 원단 구매보다 주문자생산/초소량 커스텀/무료 상담을 보장하는 듯 오인 가능. 반드시 핵심 원단 공급·상담 조건을 명확히 |
| **C. 실무에서 말이 통하는 편직사** | 원단을 실제로 이해하는 사람들과 일하는 편안함 | **‘원단을 아는 공장. 말이 통하는 관계.’** / **‘원단을 아는 사람과, 더 가까이.’** | 한국 제조업 거래 실무의 현장감/인간적 브랜드 인격 | 원단명/구체 제조 자산 없는 일반 ‘소통 잘함’ 자기평가처럼 보일 수 있음, 디자인의 절제/실제 현장 증거가 필수 |

**브랜드 선언/히어로 카피는 같아야 할 필요가 없다.**
- 회사 내부 브랜드 정의(브랜드 플랫폼): `‘원단의 사양과 제조를 아는 전문성을 바탕으로, 고객과 거리를 두지 않고 실제 공급 조건을 함께 판단하는 제조 기반 공급사’`.
- 히어로 타이틀은 이 내부 정의를 과하게 길게 복사하지 않고 5~12자 내외의 강렬한 메시지 + 1줄 업종/제품 분류가 될 수 있다. 문구의 장단·길이는 타이포/미디어 고려해 후속 디자인 검토.
- 설명문은 B2B 실무 전문성을 지킬 정도로만, '원단 공급 가능 여부는 실제 사양/수량/가공/일정 조건 확인' 경계 하위 UX로 노출.

## 3. 사용자에게 제안할 후보 카피의 사용 맥락(확정 X)
- **히어로 중심 추천 탐색:** `제조는 전문적으로. 소통은 가깝게.`
  - 작은 라벨: `HWOASUNG / CIRCULAR KNIT FABRICS`(업종 라벨 한영 표기 검토), 1줄: `폴라폴리스·인타록·싱글 원단을 직접 편직하는 기반에서 공급합니다.` (실제 완제품 공급/협력 후가공 맥락 추가 조정)
- **간결한 이미지형:** `원단 제조를, 더 가깝게.` + `직접 편직하는 화성섬유. 필요한 원단의 사양과 공급 조건을 함께 확인합니다.`
- **진짜 한국 공장 말투:** `원단을 아는 공장. 말이 통하는 관계.` + 구체 제품/원사/공정 사진.
- 기존 `느낌을 스펙으로`는 블로그에서 고객의 감각/샘플을 사양으로 해석한다는 정체성을 설명하는 표현. 히어로에 굳이 전부 집어넣지 않고 **제품 상세/원단 검토 스토리**에서 기술 전문성의 증거로 활용 가능.
- 히어로 한 가지를 세게 쓰고 메인 전체에서 설명형 설득 반복 금지(D-043).

## 4. 브랜드 방향 판단 질문
1. 사용자가 바이어에게 남기고 싶은 가장 우선하는 인상은 **'(실제로 편직·사양을 아는 제조사)' vs '(문턱 낮고 말이 통하는 제조사)'** 중 어떤 조합/강도인가? 둘은 상반되지 않으나 상대적 강조 선택 필요.
2. 한 문장만 봤을 때 친절한 소량 주문공장/무료 원단 개발처럼 오해될 여지가 있는가?
3. 기존 거래처가 있는 도매/가공 바이어에게도 과장/거창한 주장 없이 매력적인가?
4. 브랜드 표현에 어울리는 실사 환편기·원단·사람의 움직임·짧은 캡션으로 문구가 입증되는가?
5. Tintex(밝고 정돈된 편집)와 Arville(실제 제조 현장의 품격)에서 받은 좋은 인상을 사진·타이포·미세한 스크롤 인터랙션이 완성해주는가?
6. 각 문구는 실제 사이트 Hero 문구로 억지로 확정하지 않고, 사용자 선택 이후 적절한 시각/한글 표현 검증과 수정 과정을 거친다.
