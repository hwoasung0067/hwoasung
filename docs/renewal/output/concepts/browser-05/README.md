## 이미지와 글자
assets/cobalt-knit.png와 assets/ivory-yarn.png는 built-in imagegen으로 생성한 연출 이미지. 실제 공급 품목·표면·혼용·원사 사진이 아니며 모든 안의 검토 바와 이미지 캡션/비교 화면에서 구분한다. 생성된 조직은 실제 주력 원단의 세부 조직과 일치한다고 주장하지 않는다. 채택 시 실제 제품에 맞는 사진으로 교체해야 한다. source/해시/원문 프롬프트/저장 경로는 asset-manifest.json.
