사용자 요청: “전에 만들어준건 폐기하고 다시 새롭게 만들어봐”. 이전 browser-03은 반려/채택 제외 이력으로 보존하며 기본 미리보기에서 제외했다. 기존 브랜드 철학과 5장면은 유지, 이전 화면 구도/팔레트를 재사용하지 않음.

## 디자인
쿨화이트/잉크블루/절제된 코발트. 사진과 문구가 겹치는 Hero, 크기와 여백을 달리한 소재 갤러리, 큰 제조 장면, 편집형 기록, 문의로 이어진다. A(기본)는 밝은 분할 에디토리얼, B는 같은 사진과 메시지의 미디어 중심 도입. 상단 버튼으로 전환. 5장면 전체를 새로 제작했다.

## 실행과 보관
이 파일들은 검토용 소스 스냅샷이다. 실행 위치는 src/concepts/browser04/Browser04.jsx, browser04.css. ../../assets/knitting_unit.jpg는 src/assets 기존 이미지다. main.jsx에서 ?preview=renewal일 때만 Browser04를 lazy import해 렌더한다. 기본 App은 유지한다. 기존 프로젝트에서 npm run dev 후 http://127.0.0.1:5173/?preview=renewal 로 확인. localhost는 영구 배포 URL이 아니다. 이 디렉터리 자체가 단독 실행 앱은 아니다.

## 미확정
원단 그래픽/블로그 그림은 CSS 개념 그래픽이며 실제 품목/공정 촬영이 아니다. 제조 사진은 기존 편직 이미지로 촬영 원본 확인 전. 작업 슬로건/색/타입/시안은 최종 승인 전. 문의는 mailto 제목 연동이며 실제 접수 서버/발송 테스트가 아니다. 영상은 사용하지 않음. 운영 main/DB/ERP/배포 미변경.
