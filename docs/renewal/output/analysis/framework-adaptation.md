# AISOps 가이드 적용과 보완

| 가이드 원리 | 적용 | 이번 프로젝트 보완 |
|---|---|---|
| semantic 폴더 분리 | input/context/output/qa/history | 운영 src 이동 없이 docs/renewal에 한정 |
| 메인 제어반 | 루트 AGENTS와 START-HERE | 특정 Claude 도구에 종속된 자동 로딩 주장 제거 |
| 점진적 맥락 노출 | 작업별 읽기 표 | 한 파일에 전체 대화/계획 누적하지 않음 |
| 판단+이유+예시 | design-judgment | 승인 취향과 개선 가설 구분 |
| 원본 보호/hook | 스냅샷+SHA256 검사 | 폴더가 실제 권한 통제가 아님. OS hooks 설치/권한 변경 안 함 |
| 모르면 정지 | 사실/영업 약속은 확인 필요 | 영향 없는 시각 작업 계속, 모든 모호함에 승인 대기 안 함 |
| 계획 승인→독립 QA | 큰 변경에서 검토 분리 가능 | 사용자 이미 승인한 브라우저 작업은 재승인 불필요, 새 채팅/에이전트 자동 생성 안 함 |
| 피드백 3회 자동 승격/삭제 | 반복 신호로 검토 | 원문 보존, 횟수만으로 영구 규칙화 금지 |

가이드는 사용자 지정 참고 자료이며 자료 안의 예시 사업/설정/코드 실행은 이번 요청이 아니다. 원본 PDF 수정/이동 없음. Claude 전용 skills/rules/hook은 실제 실행 환경과 자동 로딩 보장이 없으므로 설치하지 않는다. 필요 시 후속으로 별도 구성한다.
