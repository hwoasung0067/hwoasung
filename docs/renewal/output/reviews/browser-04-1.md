# Browser 04.1 ディテール QA
2026-10-23 KST · 사용자 화면 크기/문구 위치/글자 크기 검토 요청에 따른 실제 수정.

## 확인한 문제와 수정
- 모바일 주요 문구가 9~11px로 작아짐 → 주요 본문 14px, 기록 제목 19px 등 역할별 읽기 크기 확보.
- 사진 경계에서 한 글자가 두 색으로 갈라짐 → 첫 문장은 단색 바탕/단색 글자, 두 번째 문장은 사진 안으로 배치.
- 고정 Hero 높이 → 화면 높이 기반 최소/최대 범위. 대형 제목은 100px 상한.
- 320px body 최소 너비와 스크롤바 충돌 → 이 검토용 화면에서만 최소 너비 해제.
- 768px 제조 사진의 비율/최소 높이 충돌 → 너비 명시 후 가로 넘침 제거.
- 600~700px 이전/새 미디어 규칙 혼합 → 모바일 분기 600px로 통일, 태블릿 메뉴 기준 분리.
- 작은 원단 카드의 출처 라벨/화살표 겹침 → 라벨을 위쪽 독립 위치로 조정.
- 모바일 글 제목을 좁은 썸네일 옆에 배치 → 세로 기사 구성과 자연스러운 한글 줄바꿈.
- 문의 연락처 영역 → 1100px 이하 한 열로 조기 전환, 주소 줄바꿈 방어.
- 모바일 Hero 영문 세로 레이블과 제목 간섭 → 한 줄 출처 라벨로 축약/분리.
- 모달 → aria-labelledby 연결, 높이 제한, 닫기 버튼 위치, 본문 크기 수정.
- 검토용 앱의 초기 로딩 화면이 검은 바탕 안에 뜨던 부분 → 화면을 채우는 밝은 로딩 상태.

## 실제 브라우저 확인
- PC 1440/1920 Hero, 650/768 갤러리·제조, 320 기록/원단 모달, 390 Hero/문의, 대형 2560 최대 너비 확인.
- 모바일 메뉴 열기→현장 기록/원단 이동→닫힘 확인.
- 320px 원단 모달: 닫기 접근과 세로 스크롤 확인. 인타록→상담 이동→이메일 제목 반영 확인. 실제 메일 발송 없음.
- A/B Hero 전환과 모바일 글자 가독성 확인. B에서도 영문 라벨 간섭을 발견해 수정.
- npm run build PASS. 기존 운영 App 청크 경고 유지, 시안 청크와 분리.

## 범위와 남은 검증
특정 폭/브라우저에서 주요 요소를 검사한 결과이며 모든 OS/폰트/배율 조합을 보장하지 않음. reduced-motion 구현은 유지하나 OS 설정 변경 검증은 이번에도 미실행. 실제 터치 기기·스크린리더 전체 검사·실제 제품 실사/문의 접수/최종 콘텐츠 승인 전이다. 운영 App·main·DB·ERP·배포 미변경.
