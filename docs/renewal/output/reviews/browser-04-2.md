# Browser 04.2 — 흐름·화면 QA
2026-10-24 KST

## 판단 근거
사용자가 초기 상품 노출의 설득 효과를 질문했고, 간결한 원단/사용처 확인 후 제조로 연결하는 추천에 동의했다. 사업상 적합성(무슨 원단을 공급하는가)을 먼저 짧게 확인한 뒤 제조 역량의 근거를 보는 구조다. 제품 우선이 항상 우월하거나 실제 문의 전환이 높아졌다는 주장은 하지 않는다.

이전 답변에서 참고한 [NN/g B2B/B2C 비교](https://www.nngroup.com/articles/b2b-vs-b2c/)와 [B2B 보고서 소개](https://www.nngroup.com/reports/b2b-websites-usability/)는 B2B 정보·의사결정 지원의 참고다. 유료 보고서 전체나 이 회사의 고정 섹션 순서를 검증한 연구로 제시하지 않는다.

## 실제 비교
동일 브라우저, 원단 섹션 자체의 DOM 높이를 비교. 화면 높이에 따른 Hero 변화와 분리해 측정했다. 반올림 값이다.

| 화면 너비 | 04.1 | 04.2 | 변화 |
|---|---|---|---|
| 1440px | 1930px | 709px | 약 63% 축소 |
| 390px | 1676px | 907px | 약 46% 축소 |

이는 스크롤 길이 변화이며 전환율 효과 측정이 아니다. 모바일에서는 원단 장면이 여전히 약 한 화면 이상이며 현장 사진을 같은 첫 화면에 억지로 넣지 않는다.

## 확인 결과
- 320/390/650/768/1024/1440/1920px 실제 렌더 검사: 문서 scrollWidth=clientWidth, 주요 제목/원단명/연락처 클리핑 없음. 주요 원단 안내·사용처·보드레·제조 이동 컨트롤 높이 모두 44px 이상.
- 본문 14px(작은 화면)/15px(PC). 작은 영문/임시 이미지 캡션은 보조 라벨이며 원단명은 18px 이상.
- PC 1440×1100에서 원단 전체와 다음 제조 장면 진입을 캡처. 모바일 390×844에서 실제 표시 캡처.
- 인타록 안내→상담: 이메일 subject에 인타록 원단 문의 반영. PU코팅 선택→문의: PU코팅 용도 원단 문의 반영. 실제 메일 발송 없음.
- 보드레 안내 열기→Escape 닫기: 선택 버튼에 초점 복귀, body 스크롤 복구. 초기 검사에서 마우스로 연 버튼에 초점이 복귀하지 않아 실행 요소를 명시적으로 보존하도록 수정 후 재확인.
- 원단을 만드는 현장으로 링크: #b4-work 이동 확인.
- npm run build PASS. 기존 App 청크 크기 경고 유지. 운영 App 기능 수정 없음.

구조 검사: python3 docs/renewal/tools/check_structure.py PASS, 기존 기획 스냅샷 41개 해시 및 새 링크 검사 통과.

## 한계
새 구조의 전환율 실험·실기기 터치·전체 스크린리더·다른 OS/폰트 검증은 수행하지 않았다. 미디어 쿼리/모달 범위 검증이며 접근성 인증이 아니다. 실제 원단 사진·최종 카피·색·타이포·최종 디자인은 미확정. 운영 main 커밋/푸시·DB·ERP·배포 없음.
