# Hero 영상 기획 v1 — 소재를 가까이, 제조는 정확하게
2026-10-27 KST · F-019/020 · AI 제안, 최종 채택 전

## 추천 방향
전체 회사 소개 영상 대신 소재를 가까이 보는 12초/3장면/무음 반복 영상. 원단을 깊이 아는 제조사라는 사실은 간결한 한글 라벨/문구로 항상 표시한다. 실제 제품 사진을 시작 프레임으로 사용하고, AI는 카메라·빛·작은 움직임 연출에 한정하는 것을 우선 추천한다. 생성 후 조직·색·형태 변형을 검사하며 실제 공장·공정·작업자를 생성해 현장 증거로 제시하지 않는다.

| 시간 | 장면 | 움직임/촬영 기준 | 연결 |
|---|---|---|---|
| 0~4초 | 실제 원단 표면의 가까운 컷 | 고정 또는 아주 느린 카메라 이동. 조직이 변형되지 않는지 확인 | 첫 화면의 촉감과 깊이 |
| 4~8초 | 같은 원단의 주름/접힌 면을 조금 넓게 | 빛의 변화 또는 느린 좌우 이동. 큰 펄럭임/급격한 변형 배제 | 소재를 하나의 물성으로 느낌 |
| 8~12초 | 같은 원단을 다시 가까이 보며 마무리 | 시작과 비슷한 구도·명암으로 돌아가 편집에서 반복 연결 | 끊김을 줄이는 루프 |

원사 콘/실제 편직 컷은 좋은 촬영이 확보되면 일부 장면을 대체하는 보조안이다. 현재 아카이브의 원본 해상도 한계가 있으므로 반드시 Hero에 넣지 않고 Manufacturing 장면에서 보여줄 수 있다. 기존 생성 이미지의 큰 루프 조직을 실제 폴라폴리스/인타록 등과 일치한다고 주장하지 않는다.

## 길이 판단
- 1순위 10~15초 범위, 첫 시험 12초. 2~3장면을 차분하게 연결한다.
- 20~30초도 가능하지만 소재 컷을 억지로 늘릴 필요는 없다. 길이보다 파일 크기·비트레이트·초반 재생 데이터·첫 화면 처리·동시 작업이 로딩에 영향을 준다.
- 긴 회사 소개/공정 전체 설명은 별도의 클릭 재생 콘텐츠로 검토한다. Hero 문구는 영상 속 생성 글자가 아니라 웹 텍스트로 따로 배치한다.

## 파일과 재생의 초기 제작 목표 (보장값/실제 결과 아님)
| 용도 | 목표 |
|---|---|
| PC | 1080p/24fps 전후, 무음 MP4(H.264), 필요 시 WebM 추가. 12초 약 2~4MB부터 화질 검토 |
| 모바일 | 별도 크롭과 720p 전후 버전. 약 1~2MB부터 화질 검토 |
| 첫 화면 정지 이미지 | 첫 영상 장면과 같은 구도의 WebP/AVIF 또는 JPEG. 약 100~200KB부터 선명도 검토 |

실제 원단 질감은 고주파 정보가 많아 압축 흔적이 두드러질 수 있다. 용량만으로 합격시키지 않고 조직·노이즈·색상·텍스트 가독성을 실제 화면에서 비교한다. 데스크톱 4K 파일을 모든 기기에 보내지 않는다. 마지막 파일 규격은 디바이스/브라우저 테스트 후 결정한다.

## 로딩/재생 설계
1. HTML·문구·고정 크기의 Hero와 가벼운 첫 이미지를 먼저 표시. 영상 전체 다운로드를 기다리는 인트로 로딩 화면은 두지 않는다.
2. 첫 이미지는 우선 로드하고 Hero 영상은 재생에 필요한 데이터가 준비되면 자연스럽게 표시한다. Hero를 일반 하단 콘텐츠처럼 lazy-load하지 않는다.
3. 무음/인라인/반복 재생. 자동 재생이 막히거나 느린 환경에서도 첫 이미지가 유효한 화면으로 남는다.
4. 하단 이미지/영상은 지연 로딩. 화면 밖·비활성 탭 영상은 멈추고 움직임 줄이기 설정에는 정지 이미지 제공. 일시정지 동작도 준비한다.
5. HTTP Range, CDN 캐시, MP4 시작 메타데이터(fast start) 지원 확인. 이는 현행 호스팅이 모두 지원한다고 확인한 결과가 아니라 구현 체크 항목이다.
6. 콜드 캐시/모바일 제한 네트워크/실제 기기에서 첫 화면 표시·영상 첫 재생·버퍼링·스크롤 반응을 각각 측정한다.

## 현재 도구와 다음 산출물
현재 직접 연결된 도구는 정지 이미지 생성이며 영상 생성 도구는 확인되지 않았다. 이미지/콘티/프롬프트는 이 대화에서 제작 가능, 실제 영상 생성은 Runway/Firefly 등 영상 도구를 거쳐 검수·압축·히어로 통합하는 경로를 제안한다. 결제/유료 생성/계정 변경을 수행하지 않았다. 영상 자체는 아직 미제작이다.
