# 레퍼런스 확장 — Arville / Tintex에서 출발한 추가 8곳
조사: 2026-10-24–25 KST. 최신 사용자 요청 F-017. 기존 시안/브랜드 방향을 최종 확정하는 문서가 아니다.

## 먼저 보는 화면
[8곳 비교 보드](reference-board.jpg). 개별 원본은 각 항목의 캡처 링크로 확인한다. 링크는 공식 사이트이며 현재 화면은 변경될 수 있다. 타사 화면은 연구용 참고이고 화성섬유 시안에 제품/공장 사진으로 전용하지 않는다.

## 사용자 감상과 이번 해석
사용자는 04.2를 보고 느낌이 잘 오지 않는다고 했고, 좋아했던 Arville과 Tintex를 바탕으로 다양한 레퍼런스를 요청했다. 04.2를 승인하거나 명시적으로 폐기한 발언은 아니다. 기존 5장면은 유지하되, 이제 섹션 길이/배치뿐 아니라 사진의 크기·촬영 시점·질감·사람·미디어와 글자의 관계를 비교한다.

실제 두 사이트를 다시 보니 Arville은 큰 현장 미디어와 명확한 타이포가, Tintex는 화면을 채우는 미디어와 아래 밝은 사용처 사진 구간이 인상을 만든다. '밝은 에디토리얼'을 연한 배경+얌전한 정보 배치로만 좁힌 04.2는 이 감각을 충분히 검증하기 어렵다는 AI 판단이다. 감각 부족의 원인을 사용자 취향/보편 법칙으로 단정하지 않는다.

기준 화면: [Arville](https://arville.com/) / [캡처](captures/00-arville.png), [Tintex](https://www.tintextextiles.com/) / [캡처](captures/01-tintex.png).

## 추가 8곳 — 실제 관찰 / 적용 가설 / 제외 요소

### 01. Kvadrat — 추천 1순위 / 소재의 크기와 여백
[공식 사이트](https://www.kvadrat.dk/en) · [실제 캡처](captures/02-kvadrat.png)

- 관찰: 흰 바탕 위에 파란 원단의 주름·질감을 화면 크게 배치한다. 다음 구간은 짧은 설명과 쿠션/커튼 이미지로 이어진다.
- 화성섬유 적용 가설: Tintex에서 선호한 밝은 편집을 사진의 크기·색·질감으로 구체화. 메인 원단을 카드 여러 개로 줄이기 전에, 하나의 큰 촉각적 장면으로 보여줄 수 있다.
- 그대로 가져오지 않을 것 / 한계: 인테리어·디자이너 협업 포지셔닝이나 전체 대형 카탈로그를 복제하지 않는다. 홈페이지 첫 화면을 로고/제조 라벨 없는 장식 사진으로만 만들지 않는다.

### 02. Burel Factory — 추천 2순위 / 사람이 있는 제조 현장
[공식 사이트](https://burelfactory.com/pages/visit-burel-factory) · [실제 캡처](captures/04-burel-factory.png)

- 관찰: 공장 소개 첫 화면에 원사 콘 사이 통로와 사람이 함께 보이며, 중앙에 간결한 이름을 놓는다. 홈에서는 양모의 출발점과 제품을 연결한다.
- 화성섬유 적용 가설: Arville의 현장감에 사람의 거리감을 보완. 정지된 환편기 전경만 반복하기보다 원사 거는 손·설비를 살피는 사람·생지가 나오는 지점을 촬영하는 아이디어.
- 그대로 가져오지 않을 것 / 한계: 양모 산지/장인 전통/자사 직조 공정을 화성섬유 사실로 전용하지 않는다. 포르투갈 사이트는 한국 지역 사이트로 자동 전환되는 현상을 관찰했다. 보드에는 전환 전 공식 공장 페이지와 URL을 함께 확인한 캡처를 쓴다.

### 03. Albini Group — 추천 3순위 / 제조 요소를 엮은 첫 장면
[공식 사이트](https://www.albinigroup.com/en/) · [실제 캡처](captures/07-albini.png)

- 관찰: 밝은 바탕에 원사 콘, 원단, 인물, 설비 등 서로 다른 크기의 이미지를 콜라주로 엮고 짧은 중심 문구를 겹친다.
- 화성섬유 적용 가설: 기존 시안의 사진 한 장+큰 문구 구도에서 벗어나는 대안. 원사→편직→원단을 3~4개 요소로 엮으면 영상 없이도 제조 정체성과 시각적 밀도를 만들 수 있다는 가설.
- 그대로 가져오지 않을 것 / 한계: 사진을 많이 모은다고 완성도가 높아지지는 않는다. 모바일 겹침·문구 가독성·시선 분산을 별도 설계해야 한다. 면화·자가 가공·태양광 등 타사 소재/설비 주장을 가져오지 않는다.

### 04. Dedar — 강한 보조 / 원단과 쓰임의 관계
[공식 사이트](https://dedar.com/) · [실제 캡처](captures/06-dedar.png)

- 관찰: 화면을 크게 나눈 두 이미지에 짧은 컬렉션명을 얹는다. 아래는 실제 적용 장면/원단 이미지와 짧은 종류명으로 제품 탐색을 만든다.
- 화성섬유 적용 가설: 원단 확대 컷과 실제 사용처 컷을 짝지어 소재가 쓰이는 모습을 연결한다. 품목 설명을 길게 읽기 전 이미지로 관심을 만들 수 있다.
- 그대로 가져오지 않을 것 / 한계: 고급 인테리어·장식 패턴·럭셔리 이미지를 그대로 따르면 사업 정체성이 흐려진다. 화성섬유가 실제 공급한 원단/사용처의 사진과 공개 권한이 확인돼야 한다.

### 05. rohi — 부분 참고 / 조직과 주름의 확대
[공식 사이트](https://www.rohi.com/en/) · [실제 캡처](captures/03-rohi.png)

- 관찰: 초기 산 풍경 장면에서 큰 원단 질감 장면으로 바뀌는 슬라이드를 관찰했다. 원단 위 로고·짧은 글자의 배치가 절제돼 있다.
- 화성섬유 적용 가설: 원단의 표면을 실제로 들여다보는 가까운 거리의 촬영. 색보다 조직·주름·빛의 방향으로 인상을 만드는 참고.
- 그대로 가져오지 않을 것 / 한계: 풍경이 길면 원단 업체임을 늦게 인지할 수 있다. 보이지 않는 자동 슬라이드에 필수 품목/업종 정보를 의존하지 않는다. 기존 본문의 긴 자기소개는 채택 대상 아님.

### 06. FENIX — 업종 확장 / 소재의 사용 맥락
[공식 사이트](https://www.fenixforinteriors.com/en) · [실제 캡처](captures/08-fenix.png)

- 관찰: 큰 인테리어 사진으로 사용된 소재를 보여주고, 밝은 구간과 어두운 materials 구간의 대비를 확인했다. 공식 홈페이지는 재료와 applications 경로도 구분한다.
- 화성섬유 적용 가설: 원단 자체의 모습과 사용처 탐색을 서로 다른 정보 층으로 다룬다. 밝은 메인에서 제조 장면으로 넘어갈 때 색·이미지 밀도 대비를 검토할 수 있다.
- 그대로 가져오지 않을 것 / 한계: 화성섬유는 주방/가구 소재 업체가 아니다. 무료 샘플·제품 기술 성능·수직 통합 공급 약속은 가져오지 않는다. 전체 사용처 인터랙션은 조작 검증하지 않았다.

### 07. mafi — 업종 확장 / 재료에서 경험으로
[공식 사이트](https://mafi.com/en) · [실제 캡처](captures/09-mafi.png)

- 관찰: 목재가 사용된 공간 위에 큰 타이포를 얹고, 아래에 제품·적용 사례·관리 등 이미지 탐색을 비대칭 높이로 배열한다.
- 화성섬유 적용 가설: 소재를 납작한 견본으로만 보이지 않게 하는 사진 구도와 장면 크기의 변화. 단조로운 동일 카드 반복을 피하는 참고.
- 그대로 가져오지 않을 것 / 한계: 첫 화면 글자가 매우 크고 전체 어두운 톤이 강하다. 화성섬유의 밝은 방향과 한국어 문구에는 그대로 적용하기 어렵다. 긴 Why 구성도 복제하지 않는다.

### 08. GF Smith — 발상 확장 / 명확한 시각적 기억
[공식 사이트](https://www.gfsmith.com/) · [실제 캡처](captures/05-gfsmith.png)

- 관찰: 초록과 분홍의 강한 대비, 큰 굵은 타이포, 다채로운 다음 구간을 관찰했다. 종이라는 B2B 소재를 뚜렷한 그래픽 언어로 다룬다.
- 화성섬유 적용 가설: 원단도 소재 업체라는 이유로 무채색·기계 사진·정보 카드만 써야 하는 것은 아니라는 발상 확장. 한 개의 제한된 포인트 색/큰 메시지 사용을 검토할 수 있다.
- 그대로 가져오지 않을 것 / 한계: 이 색 조합·장문의 큰 문구·강한 에너지는 화성섬유 취향과 차이가 크다. 전체 톤의 1순위가 아니라 부분 발상 참고다. 환경 수치/인증/서비스는 이식하지 않는다.

## 이번 추천과 다음 시안의 비교 축
1순위는 **Kvadrat의 소재를 크게 보여주는 밝은 편집**. 사용자의 Tintex 선호와 가장 자연스럽게 이어지고, 제품을 카탈로그 나열로 축소하지 않는 근거가 된다. 2순위 Burel의 사람과 현장, 3순위 Albini의 콜라주는 서로 다른 목적의 참고다. 여러 회사 특징을 한 화면에 전부 섞지는 않는다.

다음 제작이 필요할 때는 전체 페이지를 미세 수정하기 전에 같은 작업 문구/같은 사업 라벨로 첫 두 장면만 비교하는 것을 추천한다. 아래는 AI 제안이며 사용자 결정 전이다.

| 방향 | 핵심 이미지 | 장점 | 부담/위험 |
|---|---|---|---|
| A. 소재의 가까운 장면 (1순위) | 실제 원단 매크로 1장 크게, 간결한 품목 진입 | 밝음·촉감·브랜드 기억 | 실제 제품 조직/표면 사진이 필요 |
| B. 사람이 있는 제조 | 원사·환편기·작업자의 손/움직임 | 전문성과 접근성을 함께 전달 | 공장 촬영 구도와 인물 공개 확인 필요 |
| C. 원사에서 원단까지 | 원사·편직·원단 3~4개의 절제된 콜라주 | 정지 이미지로도 다른 첫인상 제안 | 합성 완성도·모바일 정렬·시선 분산 위험 |

다섯 장면/최종 미확정 슬로건/자체 편직과 협력 후가공 경계는 유지한다. 기존 04.2의 짧은 원단 진입 결정이 원단 사진을 항상 작은 썸네일로 제한한다는 뜻은 아니다. 큰 소재 이미지를 한 장면으로 써도 품목 정보와 긴 설명은 짧게 유지할 수 있다. 기존 결정과 이 제안을 분리해 후속 검토한다.

## 실제 조사 범위와 한계
- 공식 사이트 웹 본문과 데스크톱 브라우저 첫 화면/일부 스크롤 구간을 읽고 봤다. 8곳 모두 렌더 화면을 확인했다. 캡처 크기는 references.json에 저장했다.
- Arville/Tintex/Burel의 미디어 장면, rohi/Dedar의 슬라이드 변화 등은 관찰했으나 재생 전체·상세 타이밍·포인터/모바일 전 동작·접근성·성능을 검사하지 않았다.
- Albini는 초기 0% 로딩 이후 실제 콜라주 화면까지 확인 후 캡처했다. 로딩 화면을 디자인으로 오인하지 않았다.
- Burel은 공식 .com에서 한국 .co.kr로 자동 전환되는 것을 확인. 최종 보드는 공식 공장 페이지 URL과 화면을 한 호출에서 함께 확인해 저장한 캡처를 사용한다. 이 환경에서의 전환 원인은 확정하지 않는다.
- GF Smith 등 쿠키 안내가 덮인 임시 캡처는 최종 보드에서 제외/교체했다. 비교 보드는 실제 스크린샷 축소·정렬이며 가상 사이트 화면이 아니다.
- Arpa corporate는 웹 읽기 도구로 접근 불가해 직접 추천 후보에서 제외했다. VBC는 텍스트 후보 검색만 했고 시각 추천 8곳에 넣지 않았다.
- 신규 화성섬유 시안·배포는 이번에 만들지 않았다. 실제 미디어 확보/화면 최종 승인/전환율 검증은 별도다.
