## 1. 이번에 실제 만든 결과물
- 디자인 검토용 **단일 HTML 파일**: `화성섬유_홈페이지_메인시안_v1.html`, PC/모바일 캡처 `화성섬유_홈페이지_desktop_시안_v1.png`, `화성섬유_홈페이지_mobile_시안_v1.png`, 히어로 톤 비교 `화성섬유_홈페이지_밝은톤_히어로_v1.png`.
- 위 HTML/PNG는 **이 대화에서 생성된 다운로드 가능한 컨테이너 산출물**이고, **GitHub에 바이너리/HTML까지 업로드했다고 주장하지 않는다**. 후속 세션은 이 문서를 설계 상태의 지속 기록으로 사용. 실제 프로토타입 소스/캡처를 GitHub에 보존하려면 별도 업로드 절차 필요.
- React/Firebase 기존 앱이 아닌 **순수 HTML/CSS/JS standalone 시연용**. 실제 문의 전송·제품 재고 조회·서버 데이터 연동 없음.
- 사용자가 제공한 기존 공장 외관 정지 이미지(파일명 .gif이나 실제 PNG, 960×540)를 시안에 색감 정제하여 삽입. **실제 영상 장면은 아직 없고 히어로 제작 보류를 유지**.
- 원단 4종의 CSS 질감 패턴은 **사진이 아닌 위치·분위기 확인용 추상 그래픽**이며, 실제 원단 조직/사진인 것처럼 안내하지 않았다. 실제 공개 제품 자료와 1:1 매칭/실사 교체 전.

## 2. 핵심 크리에이티브 방향
**한 문장:** **Tintex의 가볍고 여유 있는 본문 구성 위에 Arville의 제조 현장 실재감을 담는다.**
- 밝은 오프화이트 톤·여백·원단별 구분이 쉬운 사진 카드가 본문의 주역.
- 히어로는 실제 제조 현장 사진 또는 추후 영상 + 굵지만 짧은 한글 헤드라인 + 취급 범주 안내. 방문 후 5초 안에 원단 편직/공급사임이 이해되어야 함.
- 카피 후보: **“원단을 직접 만드는 화성섬유입니다.”** + “폴라폴리스 · 인타록 · T/R 싱글 · DTY 싱글 등 / 생산 현장에서 시작해, 필요한 원단의 공급을 함께 고민합니다.”
- 사용자가 원한 차별점은 ‘프리미엄 원단’이 아니라 **직접 편직하는 제조 역량 + 깔끔하고 유연한 소통 경험**. 30대 2세 홍보를 전면 배치하지 않음.
- Arville처럼 영상·사진을 많은 양 생산하는 것이 1차 의무가 아님. 기존 자료 우선 활용, 부족한 최소 핵심 컷만 단계적으로 확보.

## 4. 반응형 PC/모바일 차이
- **PC 1440px:** 큰 전체 히어로, 원단명/사용처 선택 나란히, 원단 카드 2열, 제조 실사·설명 2열, 공급 방식 3열, 상담 섹터 2열.
- **모바일 390px:** 한 화면에서 사업 정체성/CTA 보이게 제목 조정, 메뉴 접기, 선택 카드·원단 카드 세로 쌓기, 제조·상담 모두 세로 구조. 스크롤 중 임의 팝업 없음.
- 브라우저 시안 QA: Playwright에서 390·768·1440px 문서 가로 넘침 없음. 사용자 작업 시뮬레이션: 제품명 선택→문의 분류/제품명 전달, 사용처 선택→용도·샘플 문의 분류/용도 전달, 모바일 메뉴 토글, 톤 변경 확인. JS 에러 없이 동작.
- 성능/접근성은 **프로토타입 수준 점검만**. 실제 히어로 영상 삽입 이후 LCP·reduced motion·폼 접근성·검색 색인 등 본 구현 QA 필요.

## 5. 정직하게 표시한 부족한 부분과 교체 우선순위
1. **히어로는 사용자의 실제 외관 사진을 임시로 씀.** 사용자는 최종적으로 영상+타이틀을 선호하지만 AI 편집 제작은 D-036 보류. 현재 시안의 사진+타이틀이 **영상 히어로를 최종 대체한다는 결정이 아니다**.
2. **공장 외관 사진이 히어로와 제조 섹터에서 두 번 등장한다.** 사용자가 기존 사이트의 중복 사진 문제를 지적했으므로 **최종 디자인에서는 반드시 서로 다른 장면**을 사용해야 한다. 제조 섹터는 실제 환편기 작동·작업자 점검·원단 컷 등으로 교체할 것.
3. **제품 카드 이미지 4개는 설명용 CSS 패턴이다.** 실제 폴라폴리스/인타록/T/R 싱글/DTY 싱글 및 보드레의 실사/사양을 확보한 뒤 각기 다른 사진으로 대체. 없는 원단 정보/폭/중량/상시 재고를 임의로 채우지 않음.
4. 5개 품목은 각각 상품군/대표 실사/제품 상세로 연결될 수 있게 설계하되, 현재 시안의 제품 클릭은 폼 입력 사전 채움만 제공. **독립 제품 상세 페이지의 실제 SEO/UX는 별도 설계**.
5. 기존 홈페이지 Spline·GIF·Cloudinary 사진 등은 12 자산 감사 문서를 따라 재검토, 필요 최소 소스부터 재사용/정제. Arville식 수십 장의 사진과 여러 영상을 출시의 필수조건으로 만들지 않는다.
6. 본딩 등 사용처에서 특정 원단의 적합성을 보장하지 않고, 가공/중량·폭/LOT·최소수량/납기 등은 상담에서 확인. 협력 염색·가공을 자체 생산처럼 보이지 않음.

## 6. 사용자에게 한 번에 받을 리뷰
- **A. 큰 톤:** 기본 다크 제조 히어로 + 라이트 본문이 맞는지, HTML의 '밝은 톤' 쪽이 더 좋은지.
- **B. 본문 흐름:** 먼저 '원단명/용도·샘플 찾기' → 제품 소개 → 실제 제조 역량 → 공급 조건 → 상담이 자연스러운지; 제조 섹터를 앞으로 당길지.
- **C. 이미지·제품 비중:** 원단 제품 카드가 너무 크거나 많게 보이지 않는지, 보드레를 어떻게 함께 보여줄지(정식 품목은 유지).
- **D. 꼭 지킬 원칙:** 화성섬유 느낌의 전문성/현대성은 살리되 프리미엄 원단 업체로 보이거나 반대로 그냥 쇼핑몰처럼 보이지 않을 것.
