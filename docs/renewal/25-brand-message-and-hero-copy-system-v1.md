## 1. 브랜드 체계를 4개 층으로 분리
**① 내부 브랜드 핵심(사용자 승인됨):** 원사·편직·실무 사양을 아는 제조의 전문성은 깊고, 고객과의 상담·거래·소통의 거리는 가깝다. 전문적인데 실제로는 이해하기 쉽고 말이 통하는 제조 기반 원단 공급사.
**② 외부 고객이 경험으로 알게 될 증거:** 직접 편직하는 실제 환편기/원사/생지, 주력 제품의 실물, 필요 조건을 이해하는 사양 설명과 공급 경로, 유연하게 대화되는 제품 탐색/상담 UX. 후가공은 협력사. 일부 선택된 사양만 재고 보유, 모든 요청 대응 보장 아님.
**③ 브랜드 선언(추후 선택):** 위 핵심을 과장 없이 짧고 기억에 남는 말로 압축. 브랜드 선언과 특정 페이지의 히어로 헤드라인은 같은 문구여야 할 필요 없음.
**④ 히어로와 UI 문구(추후 선택):** 헤드라인 한 개(1~2줄), 무엇을 취급하는지 알려주는 사실 라벨 한 개, 의미 있는 CTA(원단 살펴보기/회사 알아보기 등). 다른 섹션에는 긴 Why Hwoasung/강점 4개 자기평가를 반복하지 않음.

## 2. 히어로에서 반드시 충족할 6가지
- **정체성 인식:** 영문 HWOASUNG만으로 섬유/환편공장 여부를 이해하기 어려우므로 **원단·편직·공급** 중 핵심 설명 1개는 한글로 분명히.
- **브랜드 성격:** 실체 없는 '가깝다' 감성으로 끝나지 말고 제조 전문성과 자연스럽게 연결.
- **표현의 절제:** 홈페이지 전체에 슬로건 반복하지 않고, 히어로 문구를 가장 강조. '30년·최고·100%·원스톱' 식 자기찬양 금지.
- **오독 방지:** '누구나 원하는 원단 주문 제작/소량부터 개발·무료 견적/기계 직영 염색·기모' 뉘앙스 제거.
- **미디어 호흡:** 실제 환편기/원단 이미지 위에서 한글 타이포로 읽기 쉬운 짧은 문구. 영상이 없어도 정적 사진으로 온전하게 이해되어야 함.
- **다른 공장 이름으로 바꿔도 그대로인 문구**라면 배경·실사·편집이 화성섬유 고유 증거를 제공하는지 재검토. 카피가 특별한 업계 독점 주장을 해야 하는 것은 아님.

## 3. 세 가지 표현 *전략* — 카피는 모두 제안
| 전략 | 외부에 주는 인상 | 히어로 1차 후보 | 보조 라벨/문장 예시 | 강점/리스크 |
|---|---|---|---|---|
| **A. 직접적인 브랜드 선언형** | 가장 간결하고 오래 기억될 철학 | **‘제조의 깊이를, 더 가깝게.’** | `화성섬유 · 환편 원단 제조·공급` / `폴라폴리스·인타록·싱글 원단` | 짧고 세련되며 승인된 양축에 부합. 추상적이므로 직접 제조 실사와 실제 취급 품목의 빠른 접근 필수. '제조=초소량 맞춤' 오독 관리 |
| **B. 사람과 기술의 대비형** | 믿음직하고 말이 통하는 제조사 | **‘원단은 깊이 이해하고, 고객과는 가까이.’** | `원사에서 편직까지 직접, 가공은 협력사와 함께`는 설명을 깊은 페이지에만 | 읽는 순간 뜻이 명확함. 그러나 조금 일반적인 기업 슬로건/상대적으로 긴 글이라는 위험 |
| **C. 제조 기반 정체성형** | 실제 편직 기술과 관계를 함께 가진 공장 | **‘편직을 아는 제조. 이야기가 통하는 관계.’** | `폴라폴리스 · 인타록 · T/R·DTY 싱글` | 섬유 공장 고유 단서를 갖고 있음. 문장 리듬이 다소 다듬어져야 하고 카피가 지나치게 장황해질 위험 |
- **실제 평가 전제:** 사용자는 이전 `원단을 만드는 기술. 거래를 이어가는 태도.` 등 첫 후보들에 불만을 표시했음. 위는 최종안이 아니라 **3개 전략을 분리해서 검토하기 위한 새로운 편집 후보**다. 사용자가 모두 거부해도 브랜드 철학 D-044은 유효.
- 기존 `제조는 전문적으로. 소통은 가깝게.`, `원단 제조를, 더 가깝게.`는 24의 초기 후보로 남기고 여기의 카피와 A/B 테스트한 후 필요하면 재작성.
- 블로그의 `느낌을 스펙으로`는 필요 시 제품/공정의 구체적 기술 콘텐츠 헤딩으로 활용하고, 히어로의 브랜드 선언을 복잡하게 만들지 않는다.

## 4. 상단·중간·하단의 언어 배치(시안 이전)
- **상단 브랜드 선언 1번:** 강한 문구 1개 + 실제 취급업종 보조 설명 + 원단 탐색 첫 경로.
- **제품 갤러리:** `OUR FABRICS / 화성섬유가 다루는 원단` + 정확한 원단명 중심. '특별한 품질/최고의 감촉' 수식어 금지.
- **제조 실사:** `OUR WORK / 우리가 만드는 과정` + `자사 환편 편직`, `염색·후가공은 협력업체` 사실 캡션. 히어로 슬로건 재등장 금지.
- **사용처:** 본딩·누빔·담요·PU코팅 등 이름 + 실제 증명된 이미지/연계 제품. '맞춤 최적화' 같은 근거 없는 동사 금지.
- **인사이트:** 실제 발행 글의 원래 제목 또는 축약 제목 + 블로그 출처/링크. 과한 광고 문구 없음.
- **하단:** 약속 과잉/긴 철학 독백 대신 **상담의 문턱이 낮다는 경험을 확인시키는 간결한 문구**, 예: `찾는 원단의 조건을 알려주세요.` 또는 `원단을 찾는 일부터, 대화는 편하게.`는 검토 후보. '소량도 OK/맞춤 즉시' 금지.

## 5. 히어로 카피 검토 점수표(다음 사용자 디자인/문구 결정 시)
각 0~2점, 합계 12점. 수치는 기획자의 정성 평가일 뿐 사용자 반응 예측 점수가 아님.
1. 단독으로 읽고 **환편 원단 제조 기반 B2B 회사의 성격**이 유추되나?
2. **제조 전문성×가까운 소통** 중 최소 하나를 강하게 전달하고 다른 하나와 충돌하지 않나?
3. 감각적으로 **짧고 한국어로 자연스러우며** 기억될 만한가?
4. 실제 환편 현장/원단 사진과 함께 봤을 때 **진정성**이 높아지나?
5. 의미가 너무 넓거나 **아무 제조사도 쓸 수 있는** 빈 문장이 아닌가?
6. **소량·무료·무제한 커스텀** 보장/기존 사업 오해가 발생하지 않나?
- 후보 간 선택/이탈 기준은 **사용자에게 최종 판단을 요청해야 하는 단계**. 아직 사용자에게 다시 일일이 의견을 묻거나 이미지 시안 제작하지 않는다.
