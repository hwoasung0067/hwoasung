## 0. 가장 먼저 다시 읽을 것: 사용자가 요구한 브랜딩의 정의

> **“브랜딩은 설득이라고 생각하고 특히 후킹페이지(홈페이지)는 설득의 끝판왕이어야 한다.”**
>
> 단순 **공장 소개 → 원단 소개 → 문의**로 끝나는, 로고와 이름을 다른 섬유공장으로 바꾸면 구별되지 않는 홈페이지는 원하지 않는다.
>
> 반드시 **타깃의 니즈와 어려움, 거래처를 바꿀/추가할 동기, 스크롤하면서 차곡차곡 생기는 신뢰와 설득, 화성섬유를 선택할 이유(해자)**를 깊이 고려할 것.

**중요한 해석**
1. **브랜드는 자화자찬하는 문구가 아니라 구매자의 판단을 실제로 변화시키는 경험**이다. 예쁜 사진·애니메이션·제품 목록만으로는 목적 달성 불가.
2. 방문자가 '어디나 똑같은 공장'이 아니라 **'내 거래에 어떤 도움이 되는 회사인가'**를 이해해야 한다.
3. **좋아 보인다 → 업무를 이해한다 → 실제로 할 수 있다 → 한번 비교/문의할 이유가 있다**라는 신뢰의 변화를 스크롤/섹션/제품 탐색의 전체 연결에서 유도한다.
4. 선택 이유는 **사실·운영 방식·제품·실사·반복 거래 경험**으로 증명해야 한다. '업계 유일', '납기 100%', '클레임 0' 같은 과장 주장 금지.
5. 사용자가 **바이어의 시각에서 사이트를 처음부터 끝까지 읽으며 스스로 질문할 때** 모든 주요 지점에 실제 답이 있어야 한다.
6. 브랜드 디자인은 Tintex의 가볍고 깔끔한 인상 + Arville의 실제 제조·사진 신뢰(현실적 콘텐츠 제작 범위 고려), Camira의 절제된 히어로/타이포, Yitai의 현장 이미지 품질을 참고한다. 이것은 **표현 레퍼런스이지 화성섬유 고유 가치의 대체품이 아니다**.

## 1. 미래 브랜드 회의의 핵심 질문 12개 (빠른 점검표)

|---|---|---|
| **① 누구에게 설득하는가 — 타깃** | 정확히 어떤 구매자가 들어오는가? **원단 도매·유통** vs **본딩·누빔·PU코팅·봉제 등의 실제 원단 사용/가공 공장**은 무엇을 다르게 보나? | 1차 타깃 방향 사용자 확인. 온라인 방문객=구매자라는 가정 금지 |
| **② 왜 지금 찾는가 — 트리거** | 기존 거래처 불만/납기 공백/재발주/물량 증가/새 고객 사양/기존 원단 대체 필요 중 무엇 때문에 검색할까? 기존 업체를 유지할 이유와 화성섬유를 추가 검토할 유인이 무엇인가? | 상황별 수요 빈도는 조사 가설. '모두 거래처가 불만' 가정 금지 |
| **③ 무엇이 불안한가 — Pain/Risk** | 가격·MOQ·중량·가공 폭·색/LOT·촉감/조직·본딩/기모 후 결과·생산 일정·문제 발생시 대응 가운데 실제로 구매를 멈추게 하는 위험은? | 구체 바이어 원문/실제 사례 추가 검증 |

| **⑥ 우리 약속은 무엇인가 — Value Proposition** | 어떤 바이어의 어떤 불확실성을 어떤 실제 행동으로 줄여줄 수 있는가? 한 줄 약속을 뒷받침할 현재 능력과 경계가 명료한가? | 슬로건 확정 전. 제품명+공장+신뢰 문구만 나열 금지 |
| **⑦ 화성섬유의 해자 후보** | 직접 원사 매입·환편 생산, 선택적 완제품 선재고, 기존 생지·협력 후가공, 반복 거래 사양 이해가 **실제 거래에서 서로 어떻게 결합**되는가? 그 조합으로 고객은 무엇을 절약하거나 줄이나? | 개별 능력은 타사도 보유 가능. **해자 후보**이지 독점 입증 아님 |
| **⑧ 왜 믿을 수 있나 — Proof** | 말 대신 보여줄 수 있는 실제 편직기·원사·원단 샘플·제조 공정·재고/생지·공개 가능한 익명 실제 대응 사례·전후 비교가 있나? 근거가 어떤 약속을 정확히 뒷받침하나? | 블로그의 AI 도식은 실사 증거 아님, 납기 사례는 검증 전 사용 금지 |
| **⑨ 거래 경험/관계는 어떤가** | 첫 문의부터 발주·사양 확인·조건 불일치 설명·문제 해결·다음 주문까지 어떤 커뮤니케이션이 있나? 현대적이고 유연하다는 인상을 **실제 업무 방식**으로 느끼게 하는가? | 단순한 '친절·소통' 주장 X, 장기 거래 사례는 공개 전 검증 |
| **⑩ 브랜드 인상·언어·시각성** | 3초에 산업/취급 원단이 보이나? 투박한 공장/과한 럭셔리/디자인회사 흉내를 피하나? 현장 실사는 실제이고, 글은 화성섬유가 직접 말하는 것처럼 들리나? | 방향 D-030/034/037 확인, 컬러·카피·시안은 승인 전 |
| **⑪ 스크롤 설득의 순서** | 1번째 화면이 질문을 만들고 다음 화면이 답하는가? **왜 알아봐야 하나 → 내 문제 이해 → 다른 대응 → 증거 → 내 제품/상담**으로 믿음이 쌓이는가? 한 번 더 스크롤할 이유가 있나? | 고의도 B2B 구매자는 바로 상품/상담 접근 가능해야 함 |
| **⑫ 실제 행동과 성과** | 바이어가 무슨 자료를 들고 어디로 문의해야 하나? **원단명·사양 경로 / 용도·샘플 경로** 모두 조건 검토에 이어지나? 좋은 디자인과 실제 유효 문의·재발주를 어떻게 구분해 측정할까? | 기존 원단도 자동 주문 아님. A 실제 공급형 유효 문의 우선, B 신규 개발 별도 |

| **현재 원단을 반복 구매 중인 담당자** | 다음 발주 때 또 처음부터 설명하고 공급을 걱정해야 하나? | 사양 맥락과 원사·생지/가공 일정에 대한 예측·사전 조율 가능성 | 기존 관계를 비식별화한 사양 확인/재주문 단계 스토리 |
| **원단 이름보다 샘플·용도가 먼저인 고객** | 이 샘플/느낌이 어떤 사양인지 모르는데 상담 가능할까? | 샘플/용도를 원사·조직·중량·가공 상태 등 확인할 항목으로 번역해 조건부 대응 여부 검토 | 실제 샘플 분석/기준 원단 비교 + 불가능한 조건도 분명히 안내 |
- **거래 적합성:** 선택적 주력 완제품 공급, 보유 생지 활용, 공정 MOQ/납기/신규 원사 조건에 좌우됨. 소량·무제한 커스텀 모두 수용하는 공장처럼 표현 금지.
- **전환 동기:** 현재 거래처를 당장 교체할 이유만 찾지 말고 **예비 공급처/특정 제품별 비교 공급처로 시험 검토할 이유**도 고려.

## 3. '화성섬유 해자'를 판단하는 사고 구조
해자의 후보를 **네 층**으로 분리해서 말해야 함.

1. **자산**: 실제 보유 기술·자사 원사 매입·환편 설비·주력 제품·기존 생지·선택된 가공지 재고·후가공 협력사.
2. **실행 방식**: 사양/가공 상태·재고·원사/편직과 협력 가공을 확인하여 현실 가능한 공급 방식을 제시, 고객과 조건을 조율.
3. **반복 거래에서 누적되는 자산**: 고객 사양 이해·작지·특정 원단/색상/공급 일정의 맥락, 서로 통하는 소통.
4. **고객 결과**: 불필요한 검토·추가 설명/일정 위험을 줄일 가능성, 후공정에 맞는 원단과 재주문 의사결정의 편의. 실제 고객 결과/수치는 검증된 것만 공개.

**전제:** 개별 항목의 보유만으로 '경쟁사에 없는 유일한 해자'는 아니다. **연결되는 실행 + 반복되는 가치 + 실제 고객 결과**까지 입증돼야 설득 자산이 된다.

### 브랜드 포지셔닝 한 문장으로 압축할 때(확정 아님)
- 회사 내부 설명용 가설: **“원단의 사양을 제조 관점에서 이해하고, 보유 제품과 실제 공정 조건에 맞춰 공급을 검토하며, 거래가 쌓일수록 더 잘 통하는 편직 기반 원단 공급 파트너.”**
- 기존 블로그의 '느낌을 스펙으로'는 **기존 표현 후보**일 뿐, 전체 브랜드의 최종 슬로건으로 확정되지 않았다.
- 진실성을 지키면서도 선택 이유를 회피하지 말 것. '우린 다 친절하다'로 끝내지 않기.

## 4. 스크롤 = 문단/섹션 나열이 아니라 구매자 심리 변화
| 스크롤 목표 | 고객의 머릿속 | 이 단계에서 반드시 답할 것 | 증거 연출(예시·실제 확보 후) |
|---|---|---|---|
| **첫인상/후킹** | '이 공장을 더 살펴볼 이유가 있는가?' | 무엇을 제조/공급하고 **왜 사양·실무를 아는 공급처로 검토할 만한지** 3초 내 명료 | 현장 영상 미래 슬롯 + 짧은 '선택 이유' 텍스트 + 원단/상담 바로가기 |
| **문제 공감** | '이 업체가 우리 상황을 알아듣나?' | 중량/폭/기모/LOT/후공정/납기·수량 등 **실제 구매의 딜레마** | 동일 원단군의 실제 사양·용도 차이/실물 비교 |
| **다른 실행** | '그럼 이 회사는 어떻게 일하지?' | 완제품 재고/보유 생지·후가공/신규 편직 가능성을 현실적으로 검토하는 기준 | 질문에 따라 달라지는 상담·공급 경로 시각화 |
| **증거** | '이 말에 근거가 있나?' | 직접 편직·원사·생지/완제품·협력사 역할이 연결되는 실사, 가능한 실제 거래 사례 | Arville 수준으로 실제 사진·필요 시 작업지 익명 사례(과장 금지) |
| **관계/사람** | '오래 거래해도 괜찮을까?' | 한 번의 판매보다 사양을 축적하고 어려울 때 조율하는 사람/업무 태도 | 반복 거래 사례(실제 확인), 담당자의 판단을 보여주는 짧은 메시지 |
| **제품 적합성과 문의** | '그럼 내가 찾는 조건도 취급하나?' | 취급 원단/사용처/조건과 문의 시 얻을 수 있는 답 | Tintex형 명확한 원단 정보+상담 연결, 제품명·샘플 두 경로 |
- 각 스크롤이 다른 의문에 답해야 하며 **의미 없는 효과·장문·광고 톤** 금지. 스크롤하지 않는 전문 바이어에게는 제품/사양 문의 빠른 길 제공.
- 메인 Hero에 모든 증거를 쏟아붓지 말 것. **강한 후킹 + 구체적인 다음 화면**으로 설득.
- 실제 영상은 **기획만 보관하고 제작은 보류(D-036)**, 영상 없어도 설득 흐름 시안 진행 가능.

## 5. 화성섬유의 브랜드 인격과 시각 기준 (초기 정해진 방향)
- **단순 보수적 공장도, 패션/디자인 스튜디오도, 프리미엄 원단·무제한 맞춤 기업도 아니다.**
- **제조 전문성을 갖추되 유연하고 현대적이고 말이 통하는 공급처**. 젊은 2세의 이미지를 '젊은 사장'이라는 구호로 강매하지 않고 **빠르게 이해되는 설명, 실제 사양을 짚는 질문, 응대의 유연함, 웹 UX**로 보여주기.
- Tintex: 라이트하고 여백/정보 위계가 좋은 **기본 표현**. Arville: 제조 현장 사진·영상을 통한 **신뢰의 질적 기준**(처음부터 수십 컷 촬영 강요 X). Camira: 히어로 타이포/움직임의 절제. Yitai: 실제 사람/제품/설비 사진 품질.
- 로고 HWOASUNG/화성섬유, 폴라폴리스·인타록·T/R 싱글·DTY 싱글 주력, 보드레 포함. 실존품의 사진·사양이 핵심, 본딩/누빔/PU코팅·담요는 **사용처이지 모두 판매 SKU가 아님**.
- 기존 홈페이지 GIF/회사·원단 사진/블로그 자산 먼저 검수하고 새 촬영은 핵심 컷으로 제한. 촬영된 현장 사진은 블로그에도 활용 가능한 콘텐츠 자산으로 누적. **AI 도식/생성 이미지는 자사 현장·자사 제품의 실증 사진으로 사용 금지**.
- 문구의 목소리: 뻔한 '신뢰/품질/납기' 자기평가보다 구체적인 제조·사양·운영 사실, '모르는 조건/못 하는 일도 설명'이라는 신뢰. 블로그 Writing DNA §12 '독자가 스스로 판단하는 설득' 준수.

## 6. 반론·불안·거래 리스크에 미리 답할 질문
- **“이미 거래하는 업체가 있는데 왜 거래처를 늘려야 하죠?”** → 공급 백업·특정 보유 제품/조건 비교 등의 합리적 동기, 실제 공정·경로 기반 답. 경쟁사 비난 금지.
- **“더 싼가요? 납기는 빠른가요?”** → 가격·납기를 추상적으로 약속하지 않고 실제 사양/재고/원사/후가공/물량에 따른 확인 과정 설명.
- **“사진 속 제품을 정말 살 수 있나요?”** → 제품군 취급/선별 재고 보유 vs 개별 색상·폭·중량·가공/LOT 실제 가용성 구분.
- **“우리 공정과 맞는가요?”** → 본딩 상대원단·최종 가공 상태·가공폭 등 확인 질문, 샘플 기준 적합성 검토(보장 X).
- **“품질 문제/납기가 밀리면 누가 대응하나요?”** → 직접 편직 책임 범위 및 협력 후가공 소통을 설명하되 대응 결과를 입증 전 과장하지 않음.
- **“처음부터 모든 스펙을 적어야 하나요?”** → 아는 조건/사진/샘플로 상담 시작 가능하되 신규 샘플/MOQ/비용·설비 조건의 한계 명시.
- **“다음 주문에서도 같은 결과가 나오나요?”** → 원사/LOT·공정/색상·편직·후가공 조건을 검토하고 재주문 가능성을 상담. 무조건 동일 결과 보장 X.

## 7. 실제 브랜드 주장/증거 관리표 (나중에 채우는 템플릿)
| 주장할 수 있는 문장 | 바이어 가치 | 현재 입증 자료 | 상태 | 다음 확인 |
|---|---|---|---|---|
| '원사를 직접 매입하고 자체 공장에서 편직' | 제조 사양/조직 이해 | 회사 인터뷰/실제 공장 확인 및 영상·사진 | **공개 가능 사실, 대표 사진 추가 검수** | 실제 환편기·생지 사진 확보 |
| '일부 주요 원단을 가공 완료 상태로 선별 보유' | 준비된 원단 경로를 검토할 수 있음 | 현재 사업 운영 확인 | **사실, 개별 품목 가용성 변동** | 공개 가능한 대표 사양/사진 |
| '염색·기모는 오래된 협력사와 진행' | 생지부터 가공 완료 공급조건 상담 | 현재 사업 운영 확인 | **공개 가능 사실** | 공정별 역할을 시각적으로 명료화 |
| '반복 거래로 사양 공유가 편해질 수 있음' | 소통 비용 감소 | 사용자 경험/블로그 운영 설명 | **스토리 후보, 실제 사례 외부 공개 전 검증** | 익명화 사례/허락·증빙 |
| '실제 납기 지연 문제를 해결한 경험' | 문제 대응 역량 | 과거 블로그 게시 #21 스토리 | **주장 검증 대기** | 실제 사건/납품 기록·허용 표현 확인 |
| '품질 무결점/납기 100%/업계 최저가' | 강한 비교 이익처럼 보일 수 있음 | **근거 확인되지 않음** | **사용 금지** | 주장 필요성부터 다시 검토 |

**판단 태그:** `관찰·사실` / `구체 사례 확인 필요` / `고객 가설` / `표현·디자인 미승인` / `사용 금지`.
외부 공개 전 자사 설비·제품 사진과 AI 시각화, 고객사 공개 권리, 구체 실적/원가 정보의 공개 가능 범위를 확인한다.

## 8. 브랜드 심화 회의·시안 리뷰의 '반드시 통과할' 10개 검사
1. **고객 이해:** 누구의 어떤 발주/공급/가공 문제를 정확히 이해하고 있는가?
2. **이유:** 바이어가 화성섬유를 '한번 이야기해 볼 회사'로 선택할 이유를 5초 안에 이해하는가?
3. **대안 비교:** 기존 공급사를 쓰거나 다른 공장도 있는데 **지금 화성섬유를 추가로 고려할 합리적 이유**가 있는가?
4. **해자:** 단순 경쟁사의 공통 자산을 넘어 **실제 운영 방식의 결합·축적·사례**가 전달되는가?
5. **근거:** 중요한 주장마다 고객이 직접 보거나 검증할 수 있는 실제 증거가 있는가?
6. **정확성:** 할 수 없는 제품/수량/샘플/납기·자가 가공을 가능한 것으로 암시하지 않았는가?
7. **스크롤 설득:** 한 단계 넘길수록 새로운 질문에 답하고 **신뢰가 실제로 증가**하는가?
8. **비범용성:** **'HWOASUNG'을 다른 공장명으로 바꿨을 때 어색할 만한 화성섬유 고유 장면·행동·사례**가 남는가? 이름만 바꾸면 같은 페이지가 되면 실패.
9. **사용 경험:** 이미 원단을 아는 바이어는 곧바로 제품/상담으로 갈 수 있고, 모르는 바이어도 샘플·용도로 시작할 수 있는가?
10. **일관성과 현실성:** 가볍고 현대적인 톤, 실제 제조 신뢰, 콘텐츠 제작 여건, 블로그 정보·홈페이지 카탈로그·사양 상담이 서로 맞는가?

**사용법:** 위 10개 중 중요한 질문에 답할 자료가 없는 경우, 인터랙션·영상·화려한 타이포로 가리지 말고 자료/사례 수집 과제로 표시한 뒤 기획을 수정한다.

## 9. 다음 브랜딩 회의를 시작할 때 바로 쓸 질문
> 지금 화성섬유 홈페이지를 처음 보는 **원단 도매상 또는 본딩/누빔 공장 담당자**라고 가정하자.
>
> **“이미 거래하는 공장도 있는데, 왜 여기와 얘기해야 하지?”**
>
> 이 질문에 대해 **하나의 구체적인 발주 상황**을 골라,
> **그 사람이 느낄 문제·불안 → 화성섬유가 실제 확인하고 대응하는 방법 → 보여줄 수 있는 증거 → 고객이 얻는 변화 → 상담할 이유**를 한 화면 흐름으로 연결해서 제시하자.
>
> 여기서 경쟁사 대비 우수하다고 증명하지 못한 수치·결과는 쓰지 말고, 기존 블로그의 설득 원칙과 실제 공급 조건을 지키자.
>
> 그런 다음 Arville/Tintex의 시각적 표현을 참고해 PC/모바일 섹터를 시안화하자. **히어로 영상은 제작 보류**, 메인/기존 ERP·DB 수정은 별도 승인 전 하지 않는다.
