# 라이브 레퍼런스 재검토 — 2026-10-23

## 확인 범위
사용자 요청에 따라 기존 11·15 레퍼런스 문서를 GitHub에서 직접 읽고, https://arville.com/ 및 https://www.tintextextiles.com/ 를 실제 브라우저에서 열어 히어로와 첫 본문 구간을 스크롤·스크린샷으로 확인했다. 전체 페이지의 모든 모션·모바일·성능 검증은 하지 않았다.

## 관찰
Arville: 제조 설비를 크게 보여주는 풀블리드 히어로, 사진 위 큰 제목과 밝은 강조색, 별도 영상 진입. 본문 Products/Sectors/Capabilities는 실물 질감·사용 장면·작업자 사진을 구분해 큰 이미지 내비게이션으로 연결한다. 스크롤 후 콘텐츠가 드러나는 전환을 관찰.
Tintex: 히어로는 밝은 빈 화면이 아니라 화면을 채우는 미디어와 흰 큰 제목이며 상단은 간결한 로고/메뉴. 아래는 밝은 배경과 사용 분야별 사진, 좌측 정보/우측 큰 이미지의 비대칭 배치, 어두운 소재 배경 기술 구간으로 대비가 바뀐다. 핵심은 옅은 색상만이 아니라 미디어와 타이포의 관계·밀도 변화다.

## 기존 합의와 연결
브랜드 D-044·5장면 D-050·R2 우선 유지. Tintex의 모든 구조나 Arville의 Why/인증/규모를 복제하지 않는다. 현장 사진·영상의 신뢰, 여백과 큰 활자, 목적 있는 탐색·전환을 화성섬유에 맞게 적용한다. 영상 제작 보류 유지. 다른 회사 미디어를 자사 이미지로 사용하지 않는다.

## 브라우저 03의 한계와 다음 개선
현재 시안은 밝은 톤과 5장면 구조는 맞으나 큰 타이포 아래 사진이 분리되고 균등한 제품 카드 비중이 높아, 레퍼런스의 미디어 중심 첫인상과 장면별 밀도 차이가 약하다. 단순 fade/hover 추가를 레퍼런스 반영 완료로 보지 않는다. 다음 디자인 패스는 (1) 밝은 에디토리얼 틀 내 첫 화면부터 제조 사진 존재감 강화 (2) 제품 갤러리 크기·정렬 변화 (3) 제조/기록/문의의 서로 다른 리듬. 검증된 현장 컷이 제한적이므로 같은 사진을 여러 컷처럼 위장하거나 임시 그래픽을 실사로 제시하지 않는다.

최종 문구·색·타입·실사 승인 아님. 브라우저 제작 전환 승인 D-053 유지. 운영 main·DB·ERP·배포 변경 없음.
