## 1. 지금 승인된 선택의 정확한 범위
사용자는 25의 A **'짧고 상징적인 히어로 문구에 힘을 주고, 바로 아래 어떤 원단을 직접 편직·공급하는 제조사인지 명확히 밝히자'**는 제안을 받고 **'그렇게 진행해'**라고 답했다.
- **확정:** A형 카피 *표현 전략*; 짧고 인상적인 대형 히어로 한 문장 + 작고 구체적 한글 제조 업종/품목 설명, 바로 탐색되는 원단 경로. D-043 비언어적 브랜드 경험·D-044 제조 전문성×가까운 소통.
- **미확정:** A의 예시 문구 `제조의 깊이를, 더 가깝게.` 자체를 최종 슬로건으로 채택한 것 아님. 영문/한글 서열, 폰트·색·디자인안, 실제 사진/움직임 채택, 제품 위치/섹션 순서, 운영 코드 모두 추후 검토.
- **하지 말 것:** 사용자가 A 방향만 승인했는데 하나의 문자열을 브랜드 슬로건으로 고정하거나, 새 Hero 이미지·영상/HTML을 바로 생성.

## 2. 메시지 역할 분리 — 텍스트는 짧고 정확하게
| 계층 | 사용자에게 남기는 것 | 노출 내용 예시(미승인) | 표현 분량 |
|---|---|---|---|
| **Signature / 회사 이름** | 어느 제조사인지 | `HWOASUNG` + `화성섬유` | 상단 브랜드 |
| **Headline / 한 문장** | 기술은 깊고 관계는 가깝다는 인상 | **`제조의 깊이를, 더 가깝게.`** | 1~2줄, 페이지의 가장 큰 활자 |
| **Anchor / 오해를 막는 사실** | 무엇을 직접 하고 어떤 원단을 공급하는지 | **`직접 편직하는 화성섬유, 환편 원단 제조·공급`** | 한 줄, 실제 사진과 연결 |
| **Scope / 바로 알아볼 품목** | 방문자의 구매 맥락 | `폴라폴리스 · 인타록 · T/R 싱글 · DTY 싱글` | 제품명 라벨/첫 원단 섹션. 보드레는 실제 제품 탐색에서 별도 노출 |
| **Action / 부담 없는 진입** | ‘내가 찾는 것이 있나?’를 확인 | `원단 살펴보기` / `화성섬유 알아보기` | 1개 기본 CTA + 1개 보조 가능 |

**주의:** '직접 편직'이라고 썼다고 완제품 염색·기모를 자체 가공한다는 뜻이 아니다. 본문 제조 섹션에서는 **직접 생지 편직 + 협력 후가공**을 분명히 한다.
**중복 차단:** 히어로 헤드라인 아래 다시 `우리는 30년 경력, 모든 고민에 대응합니다, 품질/납기를 책임집니다` 같은 2~3개 영업 문단을 붙이지 않는다.
**독자별 이해:** 전문 바이어는 제품명/업종 즉시 인지. 원단 용어를 모르는 바이어는 실제 실사+상단 제품/용도 경로로 이해. 둘 다 메인 처음부터 문의 강요하지 않음.

## 3. A형 문구의 정밀 편집 후보와 검증
이 문서의 문구는 고르는 게 아니라 **브랜드 한 줄이 지녀야 할 언어적 느낌을 좁히는 검토안**이다.
| 후보 | 문구 | 핵심 뉘앙스 | 평가/리스크 |
|---|---|---|---|
| **A1 · 1순위 기획 테스트** | **제조의 깊이를, 더 가깝게.** | 기술적인 깊이와 가까운 관계를 2개 단어 대비로 간결하게 표현 | 의미 추상·제조 범위 일반적. 한글 사실 라벨+자사 공정 실사 동반 필수. 한글 문장 리듬은 실제 큰 타이포에서 확인 필요 |
| A2 · 제조 명시 강화 | **편직의 깊이를, 더 가깝게.** | 환편 제조를 전면으로 내세워 산업 정체성 구별 | 외부 바이어에게 '편직 의뢰 전용 서비스'처럼 느껴질 위험. 제품 공급 앵커와 병용 |
| A3 · 인식 접근형 | **제조는 깊이 있게, 대화는 가깝게.** | 의미 즉시 전달, 파트너십 명료 | 슬로건이라기보다 방침 설명에 가까워서 히어로 예술성 부족 가능 |
- 디자인 전에 세 문구가 **서로 다르게 보여주는 사진/텍스트 대비**를 계획하고, 최종 사용자는 ‘한 번 읽고 이미지와 함께 기억되는가?’ 기준으로 선택.
- 기존 '느낌을 스펙으로'는 구체 원단/샘플 검사 이야기에서 기술 측면을 보조하는 말. 전체 메인 여러 군데 혼용해 2~3개 슬로건을 양산하지 않음.
- **추천:** A1부터 검토하되 단어 선택은 시각 디렉션에서 취약할 경우 즉시 수정. 이것은 A1 '채택' 확정 아님.

## 4. HERO 화면 구성 논리 — 시안 없이 설계만
**핵심 목표:** 2~3초 안에 `화성섬유 + 직접 환편 제조 기반 원단 공급 + 정돈된 전문/가까움`을 인식, 첫 원단 섹션으로 자연스럽게 연결.

### 권장 레이아웃 원리 R1: 실제 제조 장면 기반 몰입형
- **먼저 화면의 주인공을 선정:** 환편기 바늘·원사·생지의 **실제 자기 공장/자사 원단**이 보이는 이미지나 짧은 실제 공정 컷 하나. 공장 건물 외관만으로는 원단을 짜는 회사라는 직관이 약하므로 도입 대표컷 1순위로 정하지 않음.
- **문구는 바쁜 배경 위를 무조건 덮지 않음:** 사진의 어두운 여백/안전영역을 찾거나 별도의 타이포 영역으로 분리해 실제 사진을 가리지 않는 호흡을 확보.
- **첫 프레임에 있어야 하는 항목:** HWOASUNG 또는 화성섬유 상단 로고/브랜드, 한글 1~2줄 상징 메시지, 제조업종 1줄, 빠른 제품 진입.
- **사진 비율·톤:** 원단/제조 사진을 크롭하면 원사/바늘/편직기가 실제로 무엇인지 분간 못 할 수준의 추상 이미지가 되지 않게. 과도한 어두운 필터·검은 오버레이로 '모든 공장' 같은 이미지 피함.
- **여백/텍스트:** Arville 실사 현장으로 신뢰, Tintex 에디토리얼 정보 밀도/여백으로 접근성. 미디어가 부족하면 아름다운 정적 사진 한 컷과 큰 타입만으로 완성돼야 함.
- **모션:** 배경 공정 영상이 있을 때만 조용한 자연 반복 + 카피가 부드럽게 나타남. 내용이 숨겨지는 오프닝 애니메이션·스크롤 강제/과한 패럴랙스 금지.
- **비디오:** D-036 제작 보류, 기존 GIF(47.7MB)를 그대로 히어로에 걸지 않음. 기존 영상의 실제 프레임/품질 검증 전 영상 재활용 가능이라 단정하지 않음.

### 대안 레이아웃 원리 R2: 에디토리얼 분할형(실제 사진이 전면 텍스트에 적합하지 않을 때)
- **왼쪽/상단:** 충분한 밝은 여백에 두 줄 한글 메세지+업종 설명+원단 보기 CTA.
- **오른쪽/하단:** 큰 실사 환편기 또는 자사 원단 텍스처. 텍스트와 사진 모두 선명, 모바일에서도 쉽게 재배치.
- 강점: Tintex처럼 가볍고 접근 가능한 인상, 열악한 제조 사진이라도 과한 다크필터로 숨기지 않음.
- 위험: 템플릿형 산업 기업 UI가 될 수 있으므로 사진 구도/독특한 활자/다음 섹션과의 이어짐을 반드시 설계.
- **R1/R2 중 어느 것이 브랜드에 맞는지는 아직 선택 전.** 실제 화성섬유 자료가 확인되면 **사진이 레이아웃을 결정하게** 하는 것이 효율적.

## 5. 첫 스크롤은 자기설명이 아니라 실물 원단으로 답한다
사용자가 긴 'Why Hwoasung' 섹션에 부정적이므로, Hero A형 선언을 메인 다음에서 문장으로 또 설명하지 않는다.

**다음 연결:** Hero `제조의 깊이를, 더 가깝게.` → 원단 갤러리 `OUR FABRICS`
- 배경의 공장 설비/원사라는 다소 산업적인 질감에서 **원단의 실제 표면, 롤, 소재가 가진 촉감**으로 자연스러운 화면 전환.
- 다음 섹션은 제조가 아니라 **원단**을 먼저 보여주는 이유: 실제 원단 구매가 1차 목표이므로 방문자는 '무엇을 공급하는지'를 빠르게 알아야 한다. 이후 제조 근거를 깊게 보여준다.
- 첫 원단 진입점: **폴라폴리스/인타록/T/R 싱글/DTY 싱글** 4개에 보드레를 별도 제품군으로 접근 가능. 보드레의 카드 위치·이미지 확정 전.
- 영상/모션 연결 예시(채택 후보): 제조 이미지에서 실제 원단 텍스처가 넓게 펼쳐지는 **자연스러운 컷 전환이나 마스크 리빌**. 실재 원단/공정 장면 없이 효과만을 위한 합성은 금지.
- **스크롤 효과를 트릭으로 만들지 않음:** 최초 콘텐츠가 보이고 한 번의 스크롤로 원단 탐색 가능. 방문자의 스크롤을 묶고 동영상 감상을 강제하지 않는다.
- CTA를 숨기지 말 것: 상단 Fabrics 링크, Hero 제품 보기 클릭, 첫 원단 섹션의 원단 상세 링크 중 최소 2곳에서 빠른 진입.

## 7. 미디어 소스/제작 우선순위와 검증
- **존재 확인:** `src/assets/company_intro.gif` 약47.7MB, `src/assets/knitting_unit.jpg` 약318KB, `src/assets/processed_inventory.jpg` 약259KB, `public/og-image.jpg`; GitHub `main` 미디어 파일(실제 시각 검수·저작/제조 관련성 추가 확인 필요).
- 기존 자산을 바이너리로 바로 확인하려는 시도는 연결 fetch가 UTF-8만 지원하고 컨테이너의 외부 DNS 접근이 제한되어 실패함. **미디어 내용을 확인했다는 주장 금지.**
- **우선 1순위:** 실제 환편기 작동 또는 편직 장면의 정적 대표 사진 1개. 기존 자료에서 확보 가능하면 새 촬영 불필요.
- **2순위:** 원단 표면 비교 가능한 대표 사진 최소 4종+보드레. 동일 원단 재촬영 요구가 아니라 품명과 매칭 검증 우선.
- **3순위:** 기존 GIF/비디오 원본에 실제 원사/환편 장면이 있는지 확인; 장면이 적합하면 별도 영상 계획 승인 단계에서 제작·편집 검토.
- **금지:** 업계 레퍼런스 사진을 자사 실사처럼 보이게 사용, AI 생성 원단 질감을 실제 공급 품목처럼 주장, 직접 염색·기모·본딩 설비 보유 과장.
