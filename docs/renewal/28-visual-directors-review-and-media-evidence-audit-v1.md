## 1. 크리에이티브 방향 한 문장
**'제조 전문성은 깊되, 고객에게는 가까운' 화성섬유를 말로 반복 칭찬하지 않고, 실제 환편 현장→원단 질감→쓰임→현장 기록의 편집 경험으로 기억시킨다.**
- Arville에서: 실제 공정의 전문성과 공간감, 사진의 진정성.
- Tintex에서: 긴 설명 없이 큰 여백·소재 사진·분명한 카테고리/쇼룸 진입.
- 기존 홈에서 버릴 것: 실제 제조와 연관이 약한 인터랙티브 장식, 자기평가 문구/수치적 납기 보장, 제품을 찾아가기 전에 영업 주장부터 이어지는 레이아웃.
- D-043 원칙에 따라 **한 개 후킹 카피 외의 텍스트는 최소/사실 중심**. 사진의 수량만 늘려 주제를 흐리거나 모션을 과시하지 않는다.

### 미확인/현재 차단
- GitHub 연결의 `fetch`는 UTF-8 텍스트만 허용하여 JPEG/GIF 바이너리를 반환하지 않았고, 컨테이너 외부 DNS도 제한되어 원본 JPEG와 47.7MB GIF의 시각 검수에 실패. **파일 존재/사용 경로 확인과 사진 품질 검증을 혼동하지 않는다**.
- Firestore `products`, Cloudinary에 등록된 5개 주력 제품군 대표 이미지 목록/유효 대표 규격/권리; 실제 기계 움직임을 담은 원본 MP4; 실제 본딩/누빔/PU코팅 용도별 자사 고객 실사; 제3자 고객 사례 공개 권리.
- 웹 이미지 검색에서 **유사 회사 이름(예: 현대화섬 등)이 뒤섞일 위험**이 있으므로 공개 웹 검색 사진을 화성섬유 실제 현장이라고 추정하지 않는다.

## 3. 첫 화면의 '왜 이렇게 보여줄 것인가' 보드
### 최우선 공통 헤드라인 시스템(카피 후보 미승인)
- **A형 상징 카피 1개:** `제조의 깊이를, 더 가깝게.` (1순위 검토 문구. 확정 슬로건 아님)
- **실무 사실 라벨:** `HWOASUNG / 화성섬유` + `자체 환편 편직 기반 원단 제조·공급`.
- **취급 경로:** `폴라폴리스 · 인타록 · T/R 싱글 · DTY 싱글`을 상단 원단 메뉴 또는 첫 원단 섹션에서 즉시 인지. 보드레는 정상 제품군으로 별도 접근 가능.
- **다음 행동:** `원단 살펴보기` + 보조 `제조 현장` / 모바일에서 하나의 기본 CTA가 분명하도록 함.
- '깊이·가깝게'를 시각적으로 증명: 기계와 섬유가 가까이 촬영된 실제 디테일/여백이 넓고 읽기 편한 UX/빠른 품목 접근. **많이 친절하다/어떤 사양도 가능**이라는 텍스트 주장을 더하지 않음.

### 레이아웃 R1 — 실제 현장 몰입형
- 실제 움직이는 환편기/바늘/원단 배출을 식별할 수 있는 강한 카메라 구도 1개. 한글 카피는 피사체를 가리지 않는 사진 내 음영 안전 공간에 배치.
- 적합: 자사 현장 소스가 강할 때. 이 경우 Arville의 공정 실재감을 가장 직접적으로 활용.
- 약점: 현재 고품질 실제 자사 HERO 컷 **검증되지 않음**. 외관 사진을 억지 다크 오버레이에 덮으면 구 v2 시안과 같은 실패 가능.
- 임시 확보 불가 시 **R1을 억지로 완성하지 않고 R2로 설계**.

### 레이아웃 R2 — 밝은 에디토리얼 분할형 (현재 자산 품질 불확실할 때 더 현실적)
- 왼쪽(PC)/상단(모바일)에 카피와 작은 한글 업종 라벨, 오른쪽/아래에 원단 또는 편직 현장 사진 큰 한 장. 어두운 타이포/자연스러운 밝은 여백으로 전문적이면서 접근성이 좋은 브랜드 인상.
- 적합: 강한 동영상 컷이 없을 때, 현장 사진이 빽빽해 문구 오버레이와 충돌할 때. Tintex 레퍼런스의 명료한 편집을 차용.
- 약점: 사진·타이포가 흔하면 범용 공급사 템플릿이 됨. **실제 생산·원단 고유 컷**과 다음 섹션의 시각 리듬으로 차별화.
- **기획자 판단:** 현재 시각 검증 가능한 히어로 자사 공정 영상이 없으므로 **R2를 기본 안전안**으로 두고, 실제 환편 소스가 좋으면 R1로 승격시키는 **조건부 설계**를 추천. 디자인 방향의 사용자 승인 아님.

## 5. 모션 기획 기준(확정 가능 원칙 / 효과 자체 미확정)
- **최초 프레임:** 정적 페이지에서도 브랜드/제품명·다음 행동이 모두 읽혀야 함.
- **의미 있는 움직임만:** (a) 실제 편직의 리듬, (b) 원단 촉감의 확대·비교, (c) 다음 섹션의 새로운 시각 전환. 텍스트 읽기 중 불필요한 어둠·속도·레이어 중첩 금지.
- **상호작용 한정:** 큰 Hero intro는 자연스럽게, 제품 hover는 이미지 변화가 작게, 원단 갤러리는 PC 마우스/모바일 터치 양쪽 의미 유지. 강제 드래그/휠 하이재킹 금지.
- **성능/접근:** WebM/MP4 용량 최적화 후 영상 보류 해제시 적용, 별도 포스터, 저속망·모바일·prefers-reduced-motion/키보드 대안.
- **시각 언어:** 섹션마다 화려한 색 변경 금지. 히어로 1번의 큰 타이포, 제품 갤러리의 밝고 넓은 여백, 제조 사진의 질감, 인사이트의 작은 정보 밀도가 리듬이 되게 함.

## 6. 실제 촬영/편집 요구사항의 최소화
우선순위와 업무상 유효한 자료:
- **P0 소스 확보/검증:** 기존 `knitting_unit.jpg`와 `company_intro.gif` 원본의 보이는 장면/실제 자사 여부·가로/세로 비율 확인, Firestore·Cloudinary의 현재 제품 사진이 주력 5군과 일치하는지 확인.
- **P0 필요한 사진 최소선:** 기계가 보여주는 실제 편직 사진 **1장** + 판매 제품군이 식별되는 표면 사진 **5장**. 이미 파일에 있으면 **추가 촬영 0** 가능.
- **P1 있으면 효과적인 사진:** 실을 거는 부분/원사/생지 롤/작업자의 손 등 실제 과정 세부 컷 **2~3장**. 기존 컷 중 크롭 가능하면 재활용.
- **P2 선택 자료:** 본딩·누빔·담요·PU코팅의 실제 사용 사진. 없으면 Applications 독립 섹션을 합침.
- **영상:** 새 촬영/제작은 **현재 확정 업무 범위 밖**, 실제 GIF 원본 영상/휴대폰 클립을 시각 검수한 다음 비용·성능 판단. 빈 콘텐츠를 가리는 AI 제조영상 사용 금지.
- **콘텐츠:** 실제 블로그의 인타록/DTY·FDY/폴라 제조 글 제목·URL은 26에서 확보. 글의 AI 도식 이미지를 실제 제조 사진처럼 붙이지 않는다.

**현재 `src/App.jsx` 코드 확인 기반**:
- `Spline` 3D 인터랙티브 배경: 현재는 원단/편직 실물과 직접 연결되지 않으므로 **메인 히어로 리뉴얼 시 원칙적으로 제외 추천** (사용자 검토 전 운영 제거 X).
- `샘플 한 장이면 딱 맞는 스펙`: 기술적인 복제를 보장하는 듯한 절대적 표현으로 위험, 필요하면 **'샘플과 사용 조건을 바탕으로 사양을 함께 확인'** 수준으로 실제 상담 안내에만.
- `자체 공장 직영으로 통상 납기 대비 20% 빠른 생산 속도 보장`: 측정/비교 모집단/기간/납기 관련 검증이 없어 **새 디자인에 절대 이관 금지**. 운영 사이트의 해당 문구 정정 여부는 별도 범위/권한 승인 전 자동 변경하지 않음.
- `회사 소개 GIF` 47.7MB: 그대로 Hero LCP 이미지로 두지 않음. 영상이 적합해도 리인코딩/포스터/모바일 전략 필수.
- 기존 드래그 제품 캐러셀: UI 재사용은 기본값이 아님. 새 제품 사진·모바일 접근·빠른 제품명 인지를 기준으로 **실사 주도 편집형 갤러리**를 별도 UX 선택지로 평가.

## 8. 지금 시점에서 사용자 선택이 필요한 중요한 안건(문서 결론)
1. **A1 '제조의 깊이를, 더 가깝게.'의 의미/한글 어조 최종 선택**, 대안 A2 '편직의 깊이를, 더 가깝게.' 또는 재작성 가능. **카피 자체는 현재 미승인**.
2. **R1 실제 제조 몰입형 vs R2 밝은 에디토리얼 분할형** 중 기본 디자인 노선. 추천은 **R2 안전 시작 → 실제 환편 공정 사진/영상이 강할 때 R1 확장**. 소스 검증 전 R1을 완성된 히어로로 약속하지 않는다.
3. **04 Applications를 독립 섹션으로 둘지/02에 병합할지**는 실제 제품·사용처 대표 사진과 사용자 선호 확인. 추천은 **이미지 확보 전 '조건부 독립'**.
- **불필요한 질문 줄이기:** 3개를 지금 당장 따로 묻지 않고, 1~2번은 실제 이미지 확보/브랜드 메시지와 함께 한 번의 디자인 검토 보드로 묶는다. 3번은 사진 존재 여부에 따라 설계상 자동 축약 가능.
- **현재 기획 완료 범위:** 방향·근거·선택지/다음 자료 요청까지. 사용자 디자인/카피 결정이 실제 필요한 최종 게이트에 도달했을 때 이 문서를 보여주며 한 번만 검토받는다.
