## 작업 방식
- 설계 변경은 한 분야씩 토론→초안→교차 검토→사용자 승인→상태판 갱신.
- 파일 제목에 없는 사실을 확정하지 않는다. 문서의 '관찰/가설/미결/승인'을 구분한다.
- Codex는 설계 승인 전에 리뉴얼 기능을 임의 구현하지 않는다.
- 기존 main 브랜치와 운영 도메인은 어떠한 자동 수정·배포도 하지 않는다.
- 최종 배포 시 사용자 승인이 필요하다.
