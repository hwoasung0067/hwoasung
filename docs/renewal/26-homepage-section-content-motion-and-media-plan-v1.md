## 1. 구체적인 홈페이지 창작 원칙
**가장 먼저 만들 것은 슬로건을 설명하는 화면이 아니라 브랜드가 자연스럽게 체감되는 전체 리듬이다.**
- **정체성:** 자사 환편 편직 설비를 운영하며 원단 판매(가공 완료 원단 공급 포함)에 집중하는 제조 기반 공급처. 자체 편직 vs 협력사 가공을 정직하게 분리.
- **인상:** 제조사는 믿음직하고 숙련되어 보이되 유통/실무 담당자에게 어렵거나 차갑게 느껴지지 않는, 조용하고 세련된 브랜드.
- **메시지 비율:** 히어로의 한 문장 강조를 제외하고 짧은 제목·원단명·1문장 사실 캡션 중심; 'Why Hwoasung' 장문 독립 섹션 금지.
- **탐색:** 무엇을 취급하는지 첫 화면에서 확인 가능. 상단 `Fabrics`와 `Contact` 진입, 제품명·사양/용도·샘플 기반 상담. 상세/모든 SKU·MOQ 교육은 하위 페이지.
- **스크롤의 인상 변화:** 강한 첫 화면→밝은 원단 촉감→제조 실체→산업 용도→실무 지식/현장 노트→여운/연락. 사진만 번갈아 나오는 포토 에세이가 아니라 각 화면의 **목적과 다음 행동**이 분명해야 함.

## 2. 메인 6장면의 '승인 가능한 기획 카드'(추천, 최종 미확정)
### 01 HERO — HWOASUNG / first impression
- **목적/방문자:** 누구나 2~3초 안에 ‘환편 원단 제조 기반 공급 회사’임을 파악하고 관심.
- **예상 감정:** 차분한 규모감·정돈된 제조 전문가·현대적인 유연성, 영상/텍스트의 과도한 자랑 없이.
- **말:** `HWOASUNG`/한글 회사명 + 25 문서의 한 개 미확정 브랜드 헤드라인 + 짧은 업종/제품 범주 보조 정보. "최고 품질, 빠른 납기" 불필요.
- **사진/영상:** 실제 자사 환편기 또는 작업 중인 원단/원사 컷, 화질이 충분하면 짧은 영상으로 확장. 영상 제작 D-036 보류. 기존 외관 사진은 기업 실존의 보조 컷으로는 쓸 수 있지만 **기계/원단 정보 없는 외관 하나를 히어로 대표로 고정하지 않는다**.
- **모션 후보:** 배경에서 기계/원단의 아주 낮은 속도 움직임/타이포 등장, 사용자 직접 스크롤을 방해하지 않는 전환. **예비안:** 고화질 정적 이미지도 충분해야 함.
- **방문자 행동:** `원단 살펴보기`(실제 Fabrics로) + `제조 현장`(메인 장면/회사 페이지로), 모바일 메뉴·텍스트 가독성.
- **메인에서 증명할 것:** '실제 제조 현장'이지 '고성능 직물 인증, 100% 납기, AI 원단 자동 추천' 아님.
- **자료 상태:** 기존 `src/assets/company_intro.gif` 47.7MB 원본은 **실제 프레임/화질/촬영 여부 미검수**. `knitting_unit.jpg` 318KB 현장 후보. 이전 사용자 올린 '회사소개 gif.gif'는 실제로 한 프레임 PNG로 관찰됐다는 12 감사 주의. 대형 GIF 원본 그대로 배포 금지.

### 02 MATERIALS — our fabrics / 원단 갤러리
- **목적:** 제품 구매자가 '내가 찾는 카테고리가 있네'를 확인. 동시에 일반 산업 원단도 톤 좋게 큐레이션.
- **제품 구조:** 주력 **폴라폴리스 / 인타록 / T/R 싱글 / DTY 싱글** 4개, **보드레**는 추가 제품군에 포함(수출/재고 특수 맥락은 검증 후 상세).
- **말:** 제품명 하나 + 실제 특징/사용처를 한 줄 이내로, 과장된 성능/즉시공급 표현 금지.
- **사진:** 원단별 실제 클로즈업(질감/표면/사이드/롤 일부), 필요하다면 생산 롤/생지·가공지 대조. **네이버 블로그의 AI 생성 질감 이미지를 실물로 사용하지 않음.**
- **인터랙션 후보:** PC hover 시 이미지의 세밀한 크롭/겹친 실물 사진 전환; 기본 상태에서 제품명 보이기(hover를 안 해도 탐색 가능). 모바일은 탭 대신 자연스러운 세로 목록/2열 카드 중 실제 사진 비율과 명료성에 따라 결정.
- **동선:** 각 제품군의 **고유 URL**(추후 SEO·데이터 검증). 색·중량·폭·LOT 가용성은 제품 상세/실제 상담에서 확인.
- **자료 상태:** Firestore의 실제 `products` 데이터/Cloudinary 사진 목록·품목 매칭 아직 미검증. 필수 초기 제품 사진 최소 한 종류씩 5컷, 갤러리 강조 컷 2~3장 더 있으면 좋음.

### 03 THE WORK — 직접 편직하는 근거
- **목적:** '단순 상품 중개가 아니라 직접 제조를 알고 있구나'를 실제 사진으로 체감.
- **말:** `From yarn to greige` 같은 영어는 장식일 뿐, 핵심은 짧은 한글 캡션. 직접: 원사 매입/자사 환편 생지 편직. 이후 염색·기모/후가공은 협력사.
- **사진:** 크게 보이는 자사 환편기 1장 + 실제 작업/원사/생지 롤의 디테일 2~3장. 협력사 사진이면 **허락받은 자료·역할 표시**.
- **인터랙션 후보:** 스크롤 진입 시 큰 실사 영역 노출/작은 부분 확대(같은 사진을 반복 확대한 가짜 무한 갤러리X). '작업의 리듬'이 느껴질 때만 모션 활용.
- **동선:** 제조/회사 상세 페이지, 폴라폴리스 제조 블로그 글과 연결. 기술 강의는 메인에서 하지 않음.
- **자료 상태:** `src/assets/knitting_unit.jpg`가 실제 자사 공정·해상도 적합한지 육안 검수 필요. `processed_inventory.jpg`는 가공지 보유 컷 후보이지만 정확한 상태/촬영 대상 확인 전 단정 금지.
- **사실 경계:** 일반 직기(weaving) 장면을 환편기로 표기 금지, 타사 염색 공정을 자체 보유 기계로 표기 금지.

### 04 APPLICATIONS — 사용처/고객과 연결
- **목적:** 실제 가공·유통 바이어가 자신의 최종 용도와 원단의 연결 가능성을 즉시 상상.
- **실제 적용 후보:** 본딩 바닥지/누빔/담요/PU코팅, 필요시 봉제. **제품군(인타록·싱글·폴라)과 사용처는 다른 분류**로 유지.
- **말:** 사용처 명칭 중심, 실제 상세에는 확인해야 할 중량·가공폭·본딩 상대원단 등 조건 연결.
- **사진:** 실제 해당 공정/샘플·완제품의 사용 권한 있는 컷만. **자사가 본딩/PU코팅/누빔 완제품을 직접 생산하는 듯 오인시키지 말 것.**
- **인터랙션 후보:** 사진 위 짧은 사용처명이 나타나거나 이미지 간 크로스페이드; 사용처 선택→확인된 관련 원단/상담. 화려한 다층 카드·강제 드래그 X.
- **대체 플랜:** 검증 가능한 실제 사용처 사진이 충분하지 않으면 독립 섹션을 만들지 않고 **02 제품 카드 하단의 간결한 사용처 연결 스트립**으로 합쳐 시각적 완성도를 지킨다.
- **자료 상태:** 현재 공개 저장소에서 해당 4가지 실제 현장/납품품 사진은 **별도 확인 안 됨**.

### 06 CLOSING — 브랜드 잔상 + 부담 없는 문의
- **목적:** 구매 압박 없이 회사 이름·성격을 한번 더 각인하고 필요할 때 연락할 길을 제공.

- **모션:** 조용한 페이드와 읽기 쉬운 메뉴·연락처. 애니메이션으로 클릭을 강요하지 않음.
- **동선:** `원단명·사양을 알고 있는 경우` / `용도·샘플부터 시작하는 경우` 두 출발점 모두 **실제 조건 확인 상담**으로 이어짐. 제품이 보유됐다고 즉시 결제/출고 보장 금지.
- **자료 상태:** Tally/이메일/카카오/톡톡 실제 살아있는 경로는 코드 및 운영 확인 필요. 운영 기능은 건드리지 않는다.

- **포인터/스크롤 이펙트는 후보일 뿐 Arville/Tintex에 해당 효과가 실제로 구현됐다고 단정하지 않는다.** 레퍼런스의 디자인 정보 계층은 공식 웹에서 확인했으나 효과의 프레임별 정확한 구현은 브라우저 실감 테스트 별도 필요.

**미확인**

- 본딩/누빔/PU코팅/담요 사용처별 공개 가능한 실제 사용 사진.
- 고객사나 개인을 식별하는 사례·납품 실적. 공개 저장소에 원본 반입 금지.

### 제작 전 콘텐츠 수집 순서(현실적 최솟값)
1. **첫 화면을 바꿀 1장:** 자체 환편기가 작동하는 고품질 사진 또는 유효한 영상 프레임(먼저 기존 GIF/사진 검수).
2. **판매를 연결할 실제 제품 5컷:** 4종 주력 + 보드레의 검증된 대표 사진. 제품 하나에 한 컷부터, 장식용 없는 사진 다량 촬영 금지.
3. **작업을 입증할 2~3컷:** 원사 공급·편직·실제 롤/생지. 1번과 재활용해도 좋지만 똑같은 한 컷 반복 금지.
4. **상황이 허락되면 2~3컷:** 본딩/누빔/담요/PU코팅 실제 사례 (권리/문맥 확인). 부족하면 Applications 병합.
5. **기존 블로그 3개 링크:** 별도 신규 촬영 없이 정보 섹터 구성 가능. 대표 이미지 유형 검증 후 카드 적용.
- **실사 없이 임시 AI 원단/공정 이미지를 자사 사진처럼 꾸미는 것은 금지.**

## 5. 섹션의 최종 승인/개발 전 체크
- **각 스크롤 섹션의 역할이 다른가?** 제품 vs 사용처 vs 제조 vs 인사이트의 메시지가 겹치지 않는가?
- **강한 브랜드 후킹은 한곳에 집중되는가?** 진입을 가로막는 광고식 영업/사양 강의 없음.
- **편직=직접, 후가공=협력**이 오인 없이 표시되는가? **원단 구매 중심**이 분명한가?
- **기본 상태에서 핵심 콘텐츠가 보이는가?** 포인터 호버·드래그를 하지 않으면 아무것도 보이지 않는 UX 금지.
- **모바일에서도 느낌과 탐색이 살아있는가?** PC 영상·hover에만 브랜드 내용 의존 금지.
- **이탈 관찰을 나중에 측정할 방법이 있는가?** 첫 홈 진입, 제품 바로가기, 특정 원단 클릭, 관련 콘텐츠 클릭, 실제 문의 시작/성공을 구분(비공개 개인 데이터 전송 금지).
- **확정 범위는 지켜졌는가?** D-044 브랜드 철학만 승인, 이 문서의 시안·효과·구체 사진/문구·6장면 최종 레이아웃은 사용자 결정 전.
