# 05. 비주얼·브랜드 디자인 독립 설계 브리프
상태: RESEARCH BRIEF. 컬러·폰트·레이아웃·최종 시안 미승인.

## 디자인은 별도 핵심 과제
정보 구조 후에 색만 입히는 작업이 아니다. 제품 인식/브랜드 신뢰/시각적 위계/사용성/모바일 완성도를 다룬다. 충분한 레퍼런스 조사, 방향 비교, 디자인 시스템, 실제 시안 비교와 승인 과정이 필요하다.

## 비교할 디자인 방향
A. 프리미엄 소재·질감 중심: 패브릭 클로즈업, 조용한 컬러, 편집 디자인.
B. 제조 기술·공장 전문성 중심: 실제 설비와 공정, 기술적 정밀함, 정돈된 데이터 UI.
C. 소재 + 제조 신뢰 결합: 구매할 원단을 먼저 보여주고 직접 편직·공급 역량을 이어서 설명.
현 시점 C는 추천 가설일 뿐 최종 결정 아님. 경쟁/참고 사이트 사례와 사용성 시안을 비교하여 결정.

## 디자인 연구 과정
1. 실제 B2B 섬유·원단 판매·제조업 사이트 레퍼런스 비교(유행성·오용/저작권 주의).
2. 화성섬유 현재 브랜드 자산(로고, 사진, 공장/원단 실사, 사업 표기) 재고 조사.
3. 세 가지 무드보드의 장단점 및 화성섬유 적합성 평가.
4. 컬러/타이포/그리드/여백/버튼/폼/카드/표/상태 컴포넌트 디자인 시스템.
5. 홈·제품 목록·제품 상세·문의 핵심 화면 PC/모바일 비교 시안.
6. 클릭 가능한 프로토타입, 최소 사용자 과제 검증.
7. 승인 시안을 코드로 구현할 컴포넌트·상호작용 명세로 변환.

## 콘텐츠 비주얼 규칙
- 공장·원단의 실제 사진 우선. 클로즈업에서 조직/기모면/앞뒤 차이를 사실적으로 보여준다.
- AI 이미지가 실물 제품 사진처럼 오해되면 안 된다. 설명용 그림/도식과 실제 상품 샘플을 구분.
- 어색한 생성 인물 사진·과도한 3D/움직임보다 제품과 데이터 우선.
- 실제 이미지를 어디에 배치할지 콘텐츠 및 촬영 리스트를 먼저 만든다.
- 현재 Spline 3D 배경은 로딩 성능/모바일 조작성/메시지 전달 효과를 재검토(유지 확정 아님).

## 품질 요구
- 모바일 좁은 폭에서 손쉬운 메뉴/제품/문의 조작.
- 명료한 폰트 크기·색 대비·포커스·키보드 접근성.
- 이미지 최적화/레이아웃 이동(CLS)/속도/LCP 등 성능과 디자인 간 균형.
- 실제 원단 정보가 비어 있는 예쁜 목업만으로 디자인 승인 금지.

## 설계 리뷰 항목
브랜드 정체성 / 첫 5초 이해도 / 제품 가시성 / 전문성·친절함 / PC·모바일 가독성 / 제품 사진의 진정성 / 상호작용 / 성능 / 관리 운영성 / 검색 텍스트 노출.

## 산출물
레퍼런스 분석표 → 승인된 무드보드 → 디자인 토큰과 컴포넌트 스펙 → 주요 페이지 시안 → 검증 결과. 최종 구현 담당은 Codex, 사업·디자인 의사결정은 Chat에서 사용자 승인.
