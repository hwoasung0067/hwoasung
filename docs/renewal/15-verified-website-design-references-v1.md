# 화성섬유 홈페이지 리뉴얼 — 실제 사이트 레퍼런스 최종 후보 1차 조사
조사일: 2026-10-22
상태: **2026-10-22 사용자 Arville·Tintex 양쪽 핵심 레퍼런스 선택(D-037) 완료. 구체 화면/컬러/시각 시안·코드 미승인.**
연계: D-030 제조 역량 × 유연한 파트너십 / D-032 보유원단도 상담 / D-033 실제 사례 우선 / D-034 Yitai + Camira / D-035 기존 자산 재사용 / D-036 히어로 영상 제작 보류 / 14 홈 구조 제안.

## 최상위 기준 — 2026-10-22 사용자 선호 확정(D-037)
**앞으로 디자인 대화와 다음 세션에서 잊지 말 것:** **Arville + Tintex 두 사이트를 화성섬유의 핵심 레퍼런스로 유지한다.** 이전에 선정한 Yitai 실사와 Camira 히어로/에디토리얼 표현(D-034)은 배제하지 않고 보조 기준으로 보존한다.

| 실제 사용자의 평가 | 긍정적 이유 | 우려/제약 | 리뉴얼에서 취할 점 |
|---|---|---|---|
| **Arville Technical Textiles** | 실제 제조 현장의 **고품질 사진이 많고 영상 활용이 풍부**. 회사/공정이 믿음직하게 드러나 완성도가 높아 보임 | 이렇게 많은 고품질 영상·사진을 **화성섬유가 현실적으로 구현·확보할 수 있을지 부담**. 제작 자료/비용/노력이 클 수 있음 | '풍부한 실사 = 제조 신뢰'의 **비주얼 기준**으로 사용. 처음부터 수십 건의 촬영을 강요하지 않고 기존 자산을 선별·리터치하고 **핵심 컷 몇 장부터 확장**. 확보한 실사는 홈페이지뿐 아니라 블로그 게시용 이미지/자료로 재활용할 수 있도록 촬영/파일 정리 계획 마련 |
| **Tintex Textiles** | 더 **라이트하고 깔끔한 표현**, 편직·원단이라는 **사업 영역의 유사성**으로 실질적인 화성섬유 적용 가능성이 높아 보임 | 너무 가벼워져 직접 제조하는 업체의 신뢰나 제품 상세 정보가 약해지는 것은 경계(디렉터의 추후 검증 항목) | **초기 구현 시 디자인·톤·정보 밀도의 현실적인 기본형**. 편직업체다운 브랜드 설명·원단 소개·원단명/용도에 따른 상담 UX를 명료하게 구성 |

### 통합 디렉팅 제안(사용자 세부 승인 전)
- **기본 화면의 성격은 Tintex형으로:** 여백과 사진을 살리는 밝고 라이트한 구성, 필요 이상으로 텍스트·영상·애니메이션을 많이 넣지 않음.
- **공장 실사·제조 근거의 깊이는 Arville을 지향:** 영상/사진이 주는 신뢰를 만들되 촬영된 자료의 품질을 양보다 우선. 사이트 초기에 대규모 미디어 제작이 완료돼야 한다는 전제는 두지 않음.
- **차별화의 표현 방식은 Camira식 절제된 히어로/움직임**, 실사 컷의 현장성은 Yitai와 Arville을 참조. 프리미엄 원단 포지셔닝/허위 설비·인증 표현은 배제.
- 실제 방문 흐름은 화성섬유의 **기존 제품명·사양으로 상담 / 용도·샘플로 상담** 2경로(D-032). **구매 결제가 아닌 상담을 통한 공급 가능성 판단**.
- **콘텐츠 자산의 다목적 활용:** 추후 촬영·AI 보조 재편집된 사진/영상은 히어로·제조 섹션·제품 상세·네이버 블로그 등에 반복 활용 가능한 '제조 콘텐츠 라이브러리'로 관리하되, 블로그에서 과도한 동일 이미지 반복·사실/원단 혼용 오인 피하기.
- **단계별 제작량:** 1차는 기존 홈페이지 영상/사진/제품 이미지 재활용(D-035)과 필요 최소 실사, 이후 실제 콘텐츠가 누적될 때 Arville식 제조 사진/공정 콘텐츠를 확장. 히어로 영상 촬영/AI 제작은 D-036에 따라 **현재 보류**.
- 현재는 **참고 사이트 선택 완료** 상태이지 PC/모바일 시안·정확한 메뉴/레이아웃/영업 카피·개발 승인 상태가 아니다.

## 리서치 요약
기존 선택된 Yitai(실제 공장 사진)와 Camira/UNRVLD(세련된 적은 문구·히어로)에 더해 다음을 우선 조사. **Arville과 Tintex가 전체 설계 기준으로 가장 유효한 실사례**. 웹 화면은 실제 사이트에서 보고, 옛 에이전시 포트폴리오는 현재 홈페이지와 구분. 특정 제품/공장 규모/실제 가공 과정·인증을 화성섬유에 그대로 적용하지 않음.

### 1. Arville — **전체 웹 구조 1순위**
- 실제 홈페이지: https://arville.com/
- 실적/화면 소개: https://www.awwwards.com/sites/arville-technical-textiles
- 제작사: https://www.bluestone98.com/work/arville-textiles/
- 영국 기술섬유 제조기업. 실제 현장·사람을 보이는 히어로와 굵은 타이틀, `Capabilities/Products/Sectors` 구분. 제품/사용 산업/제조역량이 연결된 정보 설계, 제품 상세에서 `Enquire Now` 문의 CTA 사례.
- **화성섬유 적용:** 히어로의 제조 현장 기반 첫인상, 하단 모듈 순서, 제품명/사용처 탐색의 이중 진입, 회사 제조 역량과 제품의 분리, 원단별 상담.
- **배제:** Arville의 큰 기업 규모·자가 코팅/직조·군수 등 기능성 인증·제품 기술력, 노란 강조색을 그대로 복제하거나 프리미엄/하이테크 소재라고 표현하지 않는다.
- **확인:** 제작사 기술에는 실제 공장 사진/영상/인터뷰, 디자인·UX·SEO·제품과 산업을 연결하는 구조가 기술됨. 웹 Awwwards 캡처는 당시 화면이며 현재 라이브 UI와 차이가 있을 수 있음.

### 2. Tintex Textiles — **동일 업종+영상 히어로 연계 1순위**
- 실제: https://www.tintextextiles.com/
- 디자인사 현재 사례: https://grutta.pt/work/tintex / 이전 페이지 https://grutta.pt/portfolio/tintex/
- 2026 리뉴얼 소개(2026-09-16): https://knittingindustry.com/portugals-tintex-launches-digital-showroom/
- 포르투갈 **circular-knitted fabric** 제조기업. 최근 홈페이지 리뉴얼에서 업체 영상과 원단의 품질/사양을 찾을 수 있는 Digital Showroom 및 제조 콘텐츠 결합. 초기 화면에서 주력 분야/기술 표현을 명료히 보여주고, 하위에서는 대표 제품과 용도/분야로 이어짐.
- **적용:** 실제 제조업체다운 기업 영상 제작 기획, 공정·사람·원단 실사+브랜드 표현, 상세 스펙/상담 UX, 제품·사업 분야 시각적 계층.
- **배제:** 500+ SKU 쇼룸 규모, 실시간 ERP-홈페이지 동기화, 자가염색/코팅·기능성 인증, 지속가능성·특수 섬유 능력을 화성섬유에 동일 적용 금지. 구축 규모·용량도 다름.
- **중요:** Tintex 사이트 자체 및 신규 디자인 프로젝트를 직접 보면서 영상의 실제 구현 형태/성능은 브라우저에서 추가 시각 확인할 것. 기사/제작사에서 영상 적용 사실은 확인되지만 특정 자동 재생 동작·모바일 UI 기능을 임의로 확정하지 않는다.

## 디렉터 결론 및 다음 승인 대상
- **D-037 사용자 선택 확정: Arville(제조 실사·풍부한 영상/사진·신뢰) + Tintex(라이트하고 정돈된 현실적 기본형, 유사 업종)를 계속 핵심 기준으로 유지한다.** Camira는 히어로의 시각 표현, Yitai는 사진, Dickson은 사용처 UI, Action Stamping은 향후 영상 제작 방식의 보조.
- **레퍼런스 선택은 구현/배포 승인이 아니다.** 색상·서체·동선·미디어 비율·제품 카드 개수·동작은 화성섬유 실사/상품 사양/운영 조건과 대조 후 PC·모바일 시안으로 제시해 사용자 검토.
- **사용자가 Arville·Tintex 둘 다 선호하고 평가까지 제공했으므로 다시 양자택일을 요구하지 않는다.** 2개 사이트의 각 장점을 실제 메인 섹터(14 문서)별로 매핑한 PC/모바일 레이아웃 시안을 보여주고 수정 의견만 받는다.
- D-036: 히어로 동영상은 제작 보류로 계속 유지, 레퍼런스 조사로 제작 지시를 재개하지 않음. 운영 홈페이지/코드/ERP 변경 없음.
