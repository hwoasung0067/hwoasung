# 화성섬유 홈페이지 — 메인 섹션 구조 권장안 v1
작성: 2026-10-20
상태: **전문가 추천 초안, 사용자 승인 전 / 디자인·코드·배포 미착수**
결정 출발: D-023 기존 공급 제품 중심 영업 목표, D-029 제품/용도 분리, D-030 제조 전문성×유연한 소통, D-032 모두 사양 상담, D-033/034 실사례 기반 디자인, D-035 기존 미디어 우선, D-036 히어로 영상 제작 보류.

## 범위·개념
- **히어로 영상은 기획만 남기고 제작 일정이 정해질 때까지 보류**. 스토리보드 13 문서를 보존. 지금은 영상 제작/도구·프롬프트 추가 인터뷰를 하지 않고 **메인 히어로 이후 UX·섹션 연결 구조**를 선행 설계.
- 완성 영상이 없어도 디자인·UX 구성은 '미디어 슬롯/포스터 이미지 + 실제 HTML 타이틀'로 설계할 수 있다. **영상 제작을 전체 홈페이지 리뉴얼의 블로커로 만들지 않는다.**
- 실제 영상이 들어와도 헤더·CTA·텍스트·레이아웃을 다시 개발하지 않도록 배경 미디어 모듈을 교체 가능한 구조로 구상한다(기술 구현은 별도 승인).
- 방문자의 원단 지식 수준이 다르므로 제품을 아는 사람/용도와 샘플만 아는 사람에게 두 경로를 제공. **둘 다 사양·재고/생지/가공·물량·납기 상담을 거쳐 공급**.
- 기존 홈페이지 로고·공장·원단 제품 사진 재사용 우선(실제 제품/사진 일치 확인 전 공개 스펙을 지어내지 않음).
- 페이지가 길어지고 설명이 반복되면 일부 섹션 통합 가능. Yitai의 실사 신뢰와 Camira의 정돈된 시각 위계를 참조, 원문 카피/타사 자료 복제 금지.

## 1차 메인 구성안(6개 섹션) — **순서·구체 CTA·시각 디자인 미승인**
| 순서 | 이름/임무 | 핵심 화면·정보 | 방문자 반응 | UX·브랜드 유의사항 |
|---|---|---|---|---|
| 01 | HERO — 제조 정체성과 첫인상 | 나중에 삽입할 고품질 편직 공정 영상 슬롯, 고정 타이틀(회사명·환편 원단 제조/공급), 짧은 지원 원단군 안내, '원단 살펴보기'/'용도·샘플로 상담' 중 CTA 제안 | 회사가 무엇을 만들며 상담은 어디서 시작하는지 첫 5초에 이해 | **영상 미제작이어도 화면 성립**, 정적 포스터·동작/성능 제어. 상품 즉시 구매 보장 금지 |
| 02 | FIND FABRIC — 두 탐색 경로 | '원단명/사양으로 찾기'와 '용도·샘플로 찾기' 두 카드. 각각 제품 목록/용도 설명 또는 상담으로 연결 | 용어를 아는 구매자·모르는 구매자 모두 시작할 수 있음 | 01 CTA와 중복 설명 최소화; 별도 복잡한 폼 두 개를 반드시 만들지 않음 |
| 03 | OUR FABRICS — 취급 제품 신뢰 | 4개 주력 원단 폴라폴리스·인타록(양면)·T/R 싱글·DTY 싱글, 보드레 공식 추가 제품. 각기 다른 실제 사진·검증된 1줄 특징·제품군 소개/사양 상담 링크 | 어떤 제품을 취급하는 회사인지 명확 | 보드레를 2등급 품질처럼 보이지 않게, 판매 추진 강도만 구분; 모르는 중량·폭/품질·재고 보장 금지. 4개/보드레의 정확한 카드 그리드 미정 |
| 04 | MANUFACTURING — 직접 만드는 근거 | 환편 작업장·설비·작업 과정·원단 실사, 필요한 사실 설명 1~2단락, 자체 편직과 협력 후가공 경계 | 실제 공장의 규모/운영과 전문성에 대한 신뢰 | 히어로 영상과 동일 내용 반복 자제. 실제 직원/설비 사진 우선, 고지식하거나 과장된 인증·추상 이미지 금지 |
| 05 | APPLICATIONS — 용도 기반 방문객 안내 | 본딩 바닥지·누빔·담요·PU코팅 등 **실제 적용 확인 후에만** 사례/관련 원단 또는 사양 상담으로 연결. 한 용도에 복수 원단 연결 가능 | 원단명을 몰라도 내 필요에 맞는 상담 가능 | 사용처가 곧 완제품/SKU 보장 아님. 이미지·자료 확보가 부족하면 축소하거나 02 또는 03에 일부 통합 |
| 06 | CONSULT — 간단한 상담과 공급 조건 | 원단명·사양 상담과 샘플/용도 기반 상담의 공통 결과: 요청 사양 확인·재고 완제품/기존 생지 후가공/신규 편직 가능성 검토. 연락처/폼/카카오·톡톡 등 기존 채널 안내 | 상담을 시작하거나 연락처 확인 | 모든 문의 자동 수주 아님, 최소수량/샘플비/납기는 개별 확인. 폼/기존 연락 채널 유지 검증 |

## 페이지 길이·겹침 통제
- **우선 단순화할 곳:** 02와 05는 모두 '원단 지식 없이 접근 가능'이라는 메시지를 다루므로, 시안 단계에서 '사용처 보조 탐색'을 02 카드 안에 통합할 가능성을 검토. 01과 02의 CTA도 중복하지 않도록 01은 내비 안내, 02는 실제 선택 UI 역할로 구분.
- 04 제조 섹션은 장황한 연혁 대신 실제 사진, 화성섬유가 책임지는 편직/협력사 후가공 역할을 짧게 보여준다. 회사에 대한 풀스토리는 독립 회사 소개 페이지에서 다룬다.
- 03 제품 섹션은 비슷한 사진 중복, 빈 카드, 임의 SKU 생성 방지. 실제 대표 사진과 검증 가능한 내용이 먼저.
- 06 문의는 기존 폼을 파괴하지 않고 상담을 연결. 상담에 필요한 정보와 개인정보를 최소화.
- 모바일에서는 복잡한 영상/가로 카드 대신 첫 화면 메시지·경로 선택·원단 카드·연락 수단 순서를 사용성 검토로 조정.

## 페이지별 역할 구분(홈과 상세의 관계)
- **홈:** 무엇을 만드는 회사인가 + 원단명/사용처로 빠른 진입 + 직접 편직 신뢰 + 상담 시작.
- **제품군 페이지/실제 검증된 대표 사양:** 제품 특성과 사진, 단위가 명확한 사양, 적용 사례, 공급/가공 조건과 상담. 별도 URL SEO 및 실제 자료 관리 연계는 후속 기술 설계에서 검증.
- **사용처 안내:** 실제 사례와 고객 니즈/판단 기준, 원단 적합성은 건별 상담으로 확인.
- **회사/제조 안내:** 더 많은 실제 사진·기계/운영 경험·생지와 협력 후가공 범위.
- **문의:** 소통 채널과 쉬운 사양 확인, 제품명/용도·샘플 출발 정보만 다름.

## 디자인 적용 방식
- 13 영상 스토리보드의 영상 슬롯은 **후일 교체 가능**해야 한다.
- 실제 기존 회사 사진·GIF/Cloudinary 제품 이미지 검수(12 자산 조사 문서) → 03·04 섹션 사진에 재배치. AI 생성 공장을 화성섬유 실제 현장으로 위장하지 않는다.
- Yitai의 실사와 Camira의 공간감·타이포·절제된 스크롤 효과를 페이지 각 섹션에 일관되게 적용.
- 아직 필요한 것은 **PC/모바일 낮은 충실도 와이어프레임 1개와 시각 콘셉트 2안**이며, 새로운 설문/항목별 반복 질문이 아니다. 시안 결과물을 사용자가 보고 수정할 수 있게 한다.

## 추천 결론 및 승인 경계
- **추천:** 01 히어로(영상 보류/슬롯 유지) → 02 쉬운 탐색 → 03 실제 원단 → 04 제조 증거 → 05 용도 → 06 상담. 사용자에게는 이 구조를 간략히 보여주고 승인/부분 수정 받을 것.
- **미승인:** 정확한 메뉴 라벨, 제품 카드 개수/순서, 02·05 합치기, 6개 섹터의 크기/레이아웃/페이지 성능·상세 와이어프레임. 실제 사진이 없는 항목은 빈 카드 대신 신중하게 조정.
- **사용자 이번 결정:** 히어로 영상 제작·AI 컷 만들기는 **사용자 여건상 나중에 다시 진행**. 계획/스토리보드 유지, 제작 보류가 확정. 다른 홈페이지 기획·디자인 작업은 진행해도 됨. 
- **변경 금지:** main 코드/실서비스/ERP·DB 수정, 영상 임의 제작, 개발/배포는 별도 승인 전 금지.
