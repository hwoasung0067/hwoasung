## 2. 가장 추천하는 단일 조합 — 안 P (미승인)
**P = A형 상징 히어로 + R2 밝고 정돈된 에디토리얼 기반 + R1 강한 자사 편직 실사 대비 + **5개 핵심 장면** + 실제 원단 실물 우선 + 절제된 목적형 모션.**

추천 스크롤:
1. **HERO / Brand signature:** `HWOASUNG / 화성섬유`와 짧은 한글 메시지 1개(현 1순위 작업안 `제조의 깊이를, 더 가깝게.`), 사실 앵커 `직접 편직하는 화성섬유 · 환편 원단 제조·공급`, 과한 CTA 대신 `원단 살펴보기`. 실제 공정 사진이 우수하면 전체 비주얼 R1 몰입의 강도를 높이되 **정적 사진만으로 의미가 성립**해야 함.
2. **FABRICS / 원단 소재를 만나는 섹션:** 따뜻하고 밝은 여백, 물성/텍스처가 보이는 자사 실물 사진. **주력 폴라폴리스/인타록/T/R 싱글/DTY 싱글 4개와 보드레 별도**. 제품군과 사용처는 다른 계층, **사용처 본딩·누빔·PU코팅·담요 3~4개는 제품 아래 작은 연동 스트립/링크** (현재 실제 응용 현장 사진 미검증이므로 큰 독립 장면 금지). 제품 클릭은 실제 제품군 상세 URL로.
3. **MANUFACTURING / 실제 편직의 깊이:** 분위기를 바꾸는 큰 현장 실사와 원사·생지 디테일 컷. 아카이브가 충분하면 실제 편직 동영상 짧은 슬로 모션 후보(현재 제작 보류). 직접 하는 것=원사 매입·환편 편직/생지, 협력으로 하는 것=염색·기모/후가공. **낮은 텍스트 밀도, 실제 제조사의 존재감**.
4. **FIELD NOTES / 기술과 현장의 기록:** 다시 밝고 조용한 편집, 실제 블로그 제목 2~3개(본딩용 인타록 발주/DTY·FDY 원사 비교/폴라폴리스 제조 과정). 저작권/AI 도식 여부에 맞는 썸네일, 출처 구분. '품질 최고' 주장 대신 스스로 전문성을 알아보게.
5. **CLOSING / 자연스러운 상담 진입:** 브랜드의 여운 + 제품명·사양 혹은 용도·샘플 기준으로 상담 시작. 정확한 SKU·색/중량/가공/수량/납기는 개별 확인. 가벼운 한 문장과 사업장 연락 경로.
**내비게이션:** `원단`, `사용처`, `제조·공급`, `회사`, `인사이트`, `문의`를 메뉴명 후보로 검토; 복잡한 하위페이지 상세 IA는 별도 문서 04에서 지속 설계. '사용처' 메뉴 진입은 별도로 살아있어 5장면 통합이 사용처 기능을 삭제하는 것이 아님.
**시각 리듬:** 01 큰 타이포/브랜드 도입 (라이트 베이스/강한 공정 사진) → 02 밝은 원단 촉감/여백 → 03 좀 더 깊은 톤·다큐 제조 실사 → 04 여백 있는 지식/소식 → 05 간결한 브랜드 서명·문의. **전체 화면을 카드/UI 컴포넌트로 기계적 반복 금지.**

### P를 가장 추천하는 근거
- 사용자는 **Arville/Tintex의 영문 설명을 다 읽어서가 아니라 영상·사진·포인터/스크롤·톤앤무드**를 좋아함; 'Why Hwoasung' 장문을 오히려 부담스러워함(D-043).
- **원단 판매가 1차 비즈니스**. 특히 가공지 완제품 원단 문의가 중요해, HERO 다음을 **공장 소개보다 자사 원단 갤러리로** 하여 실제 구매자가 적합품을 빨리 찾게 함.
- 제조·실사 사진은 경쟁사의 추상 카피와 달리 '직접 편직한다'는 고유 근거를 보여줌. 협력 가공 경계까지 사실대로.
- 아직 자체 **사용처별 공개 가능한 실사 사진이 미확인**: 근거 없는 별도 4카드 섹션보다 제품 하단의 짧은 사용처 진입이 우선.
- R2 밝은 편집은 원본 고품질 현장 영상 검증 전에도 만들기 쉬운 **안전한 기초**, Arville 실사 강도는 03 제조 장면에서 집중 구현. 다만 적합 실영상 확보되면 R1 가설도 경쟁 시안에 포함.
- 모바일/저속망·SEO/CTA 접근성을 유지. 이미지·인터랙션은 목적 있게 사용하되 스크롤 강제와 성능 손실 없게.
- 독립 홈페이지 방문자가 메인만 보고 떠나더라도 1차 브랜드 인상·원단·현장이라는 핵심 사실이 남는다(실제 이탈 개선 효과는 GA4 계측 후 검증).

## 4. 모션은 디자인 보강 수단이지 주인공이 아님
- **Hero**: 영상 확보 전에는 좋은 실제 사진 + 한 문장 조용한 진입, 영상 있으면 자사 편직기 자연 동작만 루프 후보.
- **Fabrics**: 정교한 포인터 hover에 실물 표면을 더 가까이 보여주거나 **앞면/뒤면·상세 컷 전환**(실제 두 장의 자사 실사가 있을 때만). 모바일은 tap으로 사진을 바꾸거나 정적 컷+상세 페이지에 명료하게 접근.
- **Manufacturing**: 스크롤할 때 큰 공장 장면/세부 장면이 차례로 펼쳐지는 정도, 실제 동작을 왜곡하는 패럴랙스·휠 하이재킹 없음.
- **Field Notes/Closing**: 거의 정적, 호버/포커스 강조 정도. 인터랙션을 모든 섹션에 붙이지 않음.
- reduced motion, mobile performance, keyboard 접근·제품명 기본 표시 필수.

## 5. Figma로 넘어가기 전에 남은 검증·승인 조건
**지금 합의 요청해도 되는 핵심 선택:** H1/H2/H3 히어로 정서와 단어, S1/S2 구성, V1/V2 시각 방향. 사용자에게 **각각 3회 나눠 묻지 말고 '1순위 조합 H1+S1+V1'을 명확히 추천하고 이유/리스크를 제시**한 뒤 '이 조합을 기준으로 Figma 시안 설계 방향을 확정할까요?'라는 한 가지 승인 질문으로 묶을 수 있음. 사용자가 H1 단어만 수정하고 싶으면 S1/V1은 다시 묻지 않고 유지.
**현재 별도 사실 검증 필요(결정 질문 아님):** 기존 `knitting_unit.jpg`/47.7MB GIF 실제 화질, Firestore·Cloudinary 제품 실사 5종과 정확한 실물 품명, 사용자 실사진/영상 소스가 있는지, 연락 경로와 제품 고유 URL. 이들을 확인하지 못하면 **완성된 자사 이미지 기반 실사 시안이라고 주장 금지**.
**승인 범위:** H1 카피 정확 채택과 S1, V1 조합 승인 시 **기획/기본 디자인 디렉션 확정**. 그래도 제품 원본·사진·애니메이션/컬러·폰트·Figma 완성 시안은 이후 실제 시각 검토 대상이며 **홈페이지 코드 개발/배포 권한이 생기는 것은 아님**.
