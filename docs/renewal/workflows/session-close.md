# 작업 마감
1. 이번 변경과 이전 변경을 분리해 diff 확인.
2. 실제 QA 결과와 미실행 검사를 기록.
3. 새 피드백/결정을 연결하고 context에는 승인된 현재 기준만 반영.
4. .ai_history/handoff에 다음 실행 가능한 한 단계와 제약 갱신.
5. 원본 해시·링크 검사. 변경은 기획 브랜치에서만 커밋/푸시.
6. 최종 보고에 경로·완료·미완료·검증 한계를 표시.

독립 검토는 큰 결정/고위험 기능에 유용하지만 모든 문서 수정마다 새 세션을 강제하지 않는다. 외부 가이드의 독립 세션 필수는 이번 작업의 자동 위임/새 채팅 생성 권한으로 해석하지 않는다.
