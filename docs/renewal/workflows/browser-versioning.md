# 브라우저 시안 버전

- 기존 03은 덮어쓰지 않고 output/concepts/INDEX에 보존 경로를 적는다.
- 새 버전은 `output/concepts/browser-04/` 등에 독립 소스/README/변경 이유/QA를 둔다. 실제 실행 가능한 경로와 패키지 의존성·자산 상대경로를 명시한다. 소스 보관만 한 것을 실행 가능 배포로 주장하지 않는다.
- 현재 프로젝트의 src와 미리보기 진입은 변경 전 로컬 diff 확인. 기존 사용자 변경을 삭제하거나 main에서 기획 브랜치로 무단 checkout하지 않음.
- 단계: 가설→DRAFT→검토→사용자 승인/반려. 사용자 승인 없이 APPROVED/APP 표기 금지.
- PC/모바일 각각 검토, 스크린샷은 가능하면 버전 하위 captures에 저장하고 출처를 명시. 원단 실사 대기 상태 유지.
- 검토용 코드 허용과 운영 교체/배포 승인은 별개. 서버 localhost 링크는 영구 호스팅 URL이 아님.
