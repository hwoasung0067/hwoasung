## 1. 가장 중요한 사용자 의도 — 절대로 다시 처음으로 돌아가지 않기
**목표:** HWOASUNG 화성섬유 B2B 원단 제조·공급사 홈페이지를 현대적으로 리뉴얼. 도매/유통 바이어와 원단을 실제 사용하는 가공·제조업체가 직관적으로 제품을 찾도록 하면서, 메인페이지만 보고 떠나도 **좋은 제조사의 느낌과 호기심**이 남도록.

**사용자 핵심 피드백(방향 확정):**
- 방문자에게 장황하게 “우리가 품질·납기·신뢰가 좋다, 거래해달라” 설득하는 페이지는 싫다. 자기자랑·압박성 Why Hwoasung을 반복하면 반감.
- [Arville](https://arville.com/)과 [Tintex](https://www.tintextextiles.com/)를 선호한 것은 **영문 메시지를 해석해서가 아니라**, 실제 제조·원단 사진/영상, 브랜드의 정돈된 톤앤무드, 여백, 타이포, 드래그/포인터/스크롤 상호작용과 전체 분위기 때문.
- 메인에서 **짧은 후킹·브랜드 문장 1개 정도는 크게 강조**하되, 나머지는 실사·원단 질감·실제 일하는 모습·화면 전환으로 신뢰가 느껴지게 할 것.
- 처음부터 HTML·그럴듯한 데모를 성급하게 만들었던 과거 시안 v1/v2는 사용자가 불만족. **그 두 화면을 승인안으로 복원/반복 제작 금지**.
- 사용자는 “**의견을 묻거나 진짜 결정이 필요한 것이 아니면 계속 진행**”을 요청. 결정할 때는 **구체 대안 2~3개 + 내가 가장 추천하는 1순위 + 과거 사용자 선호/사업 조건/자료를 반영한 근거·단점**을 먼저 설명한 뒤 사용자에게 물을 것. 이미 승인된 전략을 다시 확인하지 말 것.
- 차기 디자인은 **Figma 플러그인으로 사용자의 기존 하나의 파일에 시안을 버전별 축적**, 이전 실험을 삭제하지 않음. GitHub=사실과 설계/결정 정본, Figma=편집 가능한 시각 작업 공간. 별도 승인 없이 Codex·코드·ERP/DB·배포를 하지 말 것.

## 2. 회사 사업 사실 — 과장 또는 오인 금지
- 30년 이상 편직 제조 노하우를 가진 **실제 환편 공장**. 자사 원사 사용·환편기에서 생지 직접 편직; **염색·기모 등 후가공은 협력업체**.
- 주 영업 목적은 '맞춤 편직 대행' 유입보다 **실제 기존 제품 기반의 가공 완료 원단 판매·공급 확대**. 자체 편직은 공급 품질과 원단 사양 이해의 근거. 제품군: **폴라폴리스, 인타록(양면), T/R 싱글, DTY 싱글** 주력 4개, **보드레(FDY 인터록)** 별도 품목/주로 수출.
- 대상: 도매·유통업체, 자체 공장 운영/원단 가공업체, 본딩·누빔·PU코팅·담요·봉제 등. 일반 소비자·기성 의류 소매가 핵심 타깃 아님.
- 실제 영업 제약: 선재고는 **일부 사양/색상/수량만**. MOQ, 신규 원사/가공·납기·샘플은 거래·공정·재고 조건에 따라 개별 협의. **모든 원단 대응 / 500yd 어떤 주문도 생산 / 소량 무조건 수락 / 빠른 납기 보장 / 무료 샘플**로 읽히게 하지 말 것.
- 현재 운영 홈페이지 코드에는 **'통상 납기 대비 20% 빠름 보장'** 같은 정량 증거 미확인 문구, 실제 제조 실사가 아닌 Spline 인터랙티브 히어로가 있음. 새 홈페이지로 복사 금지. 운영 코드 수정은 별도 승인 전 금지.
