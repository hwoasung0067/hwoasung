## 1. 사용자 평가의 정확한 기록
### Yitai Knitting
- 참고: https://www.yitaifabrics.com/about/company-profile.html
- **좋은 점:** 시설·작업 현장·사람·제품 실사 사진이 전반적으로 깔끔하고 질이 좋아 기업의 전문성·신뢰가 직관적으로 전달됨. 텍스트가 많지 않아 긴 설명을 읽지 않아도 회사의 모습을 느낄 수 있음.
- **아쉬운 점:** 첫 화면의 영상이 웹 히어로에 일체화된 영상처럼 보이지 않고 유튜브 플레이어 같은 삽입 폼이라 조잡함. 홈페이지 첫 순간에 회사의 주력 사업·상품을 이해하기 어려우며 사용자가 직접 찾아야 함.
- **가져갈 것:** 실제 제조 공장 현장, 실제 인물의 작업 장면(연출된 홍보 인물 이미지가 아닌 작업 기록), 원단 실사, 일관된 밝기/선명도, 짧은 텍스트, 시각적 사실 증명.
- **가져오지 않을 것:** 콘텐츠 식별이 어려운 히어로, 플레이어 프레임/컨트롤이 먼저 보이는 삽입 영상, 화성섬유와 다른 제품군·인증/시험실/인력규모를 따라 보이게 만드는 구성.

### Camira Fabrics / UNRVLD 과거 디자인 사례
- 참고 과거 사례: https://www.unrvld.com/work/camira-fabrics (현재 경로가 다른 업계 사례 목록으로 리디렉션될 수 있음; 과거 공개 UI 이미지로 확인).
- **좋은 점:** 첫 화면 히어로의 집중도/인상적인 구성, 적은 정보와 여백, 세련된 타이포·색면/사진, 절제된 스크롤·드래그 상호작용의 완성도. 잘 만든 사이트가 회사의 업무 전문성까지 긍정적으로 연상되게 함.
- **아쉬운 점:** 실제 회사·현장·제품 사진이 상대적으로 부족하고 디자인 회사와 비슷한 인상을 줌. 화성섬유는 이 디자인 성격을 전체가 아니라 **일부 표현 원리로만** 사용하길 원함.
- **가져갈 것:** 1화면의 명확한 정보 계층, 사진+여백+큰 활자의 균형, 과하지 않은 인터랙션, 완성도 높은 정렬/속도/전환, 불필요한 정보 삭제.
- **가져오지 않을 것:** 추상적 슬로건만 앞세워 공장 정체성이 사라지는 화면, 럭셔리/프리미엄 원단 포지셔닝, 과도한 애니메이션과 사진 적은 디자인 포트폴리오 형태.

### 사용자 통합 의도
- 추구 이미지: **'믿고 상담할 수 있는 제조 공장'이면서 동시에 '고지식하거나 투박하지 않은, 열린 자세로 소통하는 회사'**.
- 사실 관계: 나이/2세 경영자라는 개인 특징을 메인에 직접 광고하지 않고 디자인과 소통의 수준에서 간접적으로 드러냄.
- AI가 임의로 모든 요소를 만들기보다 참조 화면의 원리를 채택·검증하여 실제 회사 자산으로 고유하게 구성.

## 2. 디렉터 권고 — 제조 현장의 진실성을 기본, 캠이라의 디자인은 편집 레이어로
**핵심 원칙:** Yitai의 **무엇을 보여줄 것인가(현장·사람·원단)** + Camira의 **어떻게 보여줄 것인가(첫인상·여백·타이포·제한된 인터랙션)**.
- 비율은 숫자로 고정하지 않는다. 시각 요소의 우선순위는 실제 현장·원단 사진과 정확한 공급 정보가 주역이고, 디자인은 내용을 선명하게 전달하는 조연.
- **프리미엄 원단 브랜드 지향 아님.** 제품 성능/가격의 우월성을 시각적으로 단정하지 않고, 홈페이지의 전문적 완성도를 올리는 목표.
- **사람 사진은 허용하되 실제 작업 장면만**: 작업자가 기계를 점검하거나 실을 다루는 모습 등. 스톡 모델·가짜 직원/가짜 공장 AI 이미지 금지. 작업자 촬영·초상권/안전 배려 필요.

## 3. 홈페이지 첫 화면 권장 (정확한 카피/레이아웃 미승인)
### 첫 5초에 답해야 할 것
1. 우리는 누구인가: 화성섬유, 자체 환편 기반 원단 제조·공급 회사.
2. 무엇을 취급하는가: 폴라폴리스/인타록(양면)/T/R 싱글/DTY 싱글, 보드레 및 실제 적합 용도. **히어로 자체에서 주력 5종을 전부 나열할 필요는 없으나, 첫 화면 또는 첫 스크롤의 짧은 보조 문구/네비로 취급 분야를 파악 가능하게 한다.**
3. 어떻게 시작하는가: '원단명·사양으로 상담' 또는 '용도·샘플로 상담'. 양쪽 모두 동일하게 최종 상담·사양 확인·공급 협의(D-032).

### 권장 레이아웃
- **분할 히어로 또는 고품질 현장 사진 1장을 배경:** 설비의 스케일/실제 편직 현장을 드러내면서 사진이 타이포를 가리지 않게 구성. 가능하면 실제 작업자와 편직기 디테일이 함께 보이는 실사.
- **짧은 분명한 한국어 제목:** 예시 '직접 편직하고, 원단의 공급 가능성을 함께 검토합니다.' (실제 확정 슬로건 아님. 최종 문구는 마케팅 검토).
- **짧은 설명/메뉴:** '폴리에스테르 중심 환편 원단 | 보유 원단 공급·생지 후가공 상담' 등 사실 범위 내 보조 메시지.
- CTA 두 개: '원단·사양 상담' / '용도·샘플 상담' 또는 '원단 살펴보기' / '상담 시작하기'. 복잡한 4개 메뉴를 히어로에 전부 다 넣지 말고 찾기 쉬운 내비는 유지.
- **영상 정책:** 처음부터 유튜브 삽입형 플레이어/큰 재생 버튼을 히어로 중심에 배치하지 않는다. 영상 자체가 필요하다면 자체 편집된 짧고 음소거된 루프나 매끄럽게 통합된 컷을 선택지로 비교. **정적인 고품질 사진을 우선 기본안**으로 두며 영상이 필수라고 정하지 않는다. 모바일·느린 회선 및 reduced motion에서 정적 이미지 대체.

## 4. 아래 섹터의 권장 서사
1. **히어로 — 우리가 무엇을 실제 제조/공급하는가**: 실제 공장/원단 + Camira식 간결한 타이포/여백.
2. **찾는 방식 선택 — 원단명/사양 또는 용도/샘플**: 전문/비전문 구매자 모두 자신의 정보 수준으로 사양 상담 시작.
3. **핵심 공급 제품 — 4개 주력+보드레**: 각 제품의 서로 다른 실사 사진과 간단한 특징/용도. '바로 구매' 버튼 금지, 사양 상담/제품 확인으로 안내.
4. **Manufacturing Proof — 실제 편직과 공급 방식**: 작업장 전경(신뢰), 작업자/기계 디테일(운영 사실), 원단 실사(납품 물성), 협력 후가공 설명(경계 정확성). 긴 회사 연혁보다 진짜 제조 경험을 시각화.
5. **실제 사용처 — 본딩 바닥지·누빔 보드레·담요 등**: 적용 사례로 검증된 용도만 연결하고 사양 상담 유도.
6. **거래 시작 가이드 & 문의**: 보유 완제품/생지 후가공/신규 편직 검토의 차이, 준비할 샘플/요청 내용, 상담 CTA, 실제 연락 방법.
7. **회사 정보**: 공장, 실제 역사·제조 경험, 연락·블로그. 30대/2세를 메인 슬로건으로 반복하지 않는다.

## 5. 상호작용과 정보 밀도 규칙
- Camira식 움직임은 **사용자 행동에 반응하는 목적 있는 변화**로 한정: 사진의 작은 패럴랙스, 텍스트·이미지 순차 등장, 가벼운 호버/스크롤 상태 변환 후보. 모두 미구현·미승인.
- **영상 플레이어 외관 금지**가 목표이지 영상 무조건 금지는 아님. 실제 품질 좋은 영상 소스를 확보하지 못하면 정적 이미지로 시작.
- 첫 화면에서 회사/주력 분야/문의 출발점이 5초 내 이해되는지 확인. 사진만 예쁘고 제품이 무엇인지 모르도록 하면 안 됨.
- 텍스트를 무조건 줄이지 말고 **메인에서 압축 → 관련 제품 상세에서 자세히** 제공. 사진에 정보가 부족하면 짧은 캡션으로 설명.
- 상품 카드의 모든 이미지를 동일한 사진으로 쓰지 않고 실제 샘플별 다르게 촬영.
- 모바일에서 움직임은 더 절제하고 핵심 문구와 두 상담 길을 먼저 보이도록. 성능과 가독성은 디자인 완성도의 일부.

## 6. 실사 촬영 브리프 (사진이 없으면 결과가 나오지 않는 핵심 의존성)
- **필수 1:** 메인 히어로용 실제 환편 공장 전경 (가로, 수평 정리, 작업장 색감 정돈, 텍스트 올릴 여백).
- **필수 2:** 작업자가 설비를 점검하거나 정상 업무하는 자연스러운 장면 (가능한 작업자 동의 확보, 기계 안전·기업 비밀 보호).
- **필수 3:** 바닥실·니들·원사 투입·원단 롤 등 실제 공정/디테일 컷. 장비를 다른 업체의 것으로 대체 금지.
- **필수 4:** 폴라폴리스, 인타록, T/R 싱글, DTY 싱글, 보드레 각각의 다른 실제 원단 근접/두께·표면 컷. 제품별 실제 사양과 사진 매칭.
- **추가:** 보유 생지·원단 출고, 가능하면 제조 공급 흐름 설명에 사용할 작업 장면. 후가공 협력사 사진은 허락과 구분 표기 후에만 검토.
- **촬영 원칙:** 지나친 스튜디오 연출·필터보다 깨끗한 조명/구도·같은 톤의 색보정. 실제 사진/촬영 소스의 품질이 Yitai 장점을 구현하는 핵심. 작업자 얼굴 노출은 필수가 아님.

## 2026-10-20 기존 홈페이지 미디어 재활용 원칙 (D-035)
- **리뉴얼 자산 우선**: 새 공장 영상/사진 촬영 전에 기존 홈페이지의 실사용 자료를 검토한다. 확인 경로: [12-existing-media-asset-audit-v1.md](12-existing-media-asset-audit-v1.md).
- 현재 repo에 실존하는 `src/assets/company_intro.gif`(약 47.7MB, 본문/회사 소개), `knitting_unit.jpg`, `processed_inventory.jpg`, `public/logo.png`, `og-image.jpg`. 상품별 Firestore+Cloudinary 사진은 **존재하는 연동 구조**만 확인되어 실제 파일/사양 매칭 미검증. 메인 Spline은 외부 3D 콘텐츠이므로 제조 현장 영상과 구별.
- **영상 히어로 첫 후보**로 회사 소개 GIF의 실제 장면과 별도 원본 동영상 존재 여부를 살펴본다. 사용할 만한 장면이 있으면 원본 화질 확인 후 편집/인코딩하고, 너무 무겁거나 저화질이면 **신규 촬영 범위를 필요한 장면으로 최소화**한다. 기존 약 47.7MB GIF를 그대로 첫 화면에 넣지 않는다.
- 사진·상품 자산도 **그대로 재사용 / 색감·크롭 등 정제 / 보조 이미지 / 교체 필요**를 선택해 페이지 섹터에 매핑한다. Yitai 사례의 제조 실사 신뢰+Camira 표현의 완성도를 자체 자료로 구현한다.
- 영상 품질·기술/저작권/초상권/소재·공정 사실성·성능을 확인하지 않고 특정 기존 파일을 바로 히어로로 확정하지 않는다. **새 촬영 전 자산 검토가 선행**한다.

## 2026-10-20 추가 의견 — 영상 + 타이틀 히어로 우선 검토 (결정 전 논의 기록)
### 사용자의 제안
- 사용자는 **Camira와 같이 화면에 자연스럽게 통합된 영상 + 타이틀 문구가 첫인상과 차별화를 만드는 데 더 효과적일 수 있다**고 평가.
- 앞서 정적 실사 사진을 우선 권고한 선택은 '어느 공장에나 있는 단순 타이포+사진'이라는 인상을 줄 수 있으므로 재검토를 요청. **디자인 방향을 함께 조율하는 과정이며, 영상 구현을 승인하거나 운영 중 코드/촬영 진행을 요청한 것은 아님**.

### 디렉터 평가
- **조건부로 영상 히어로를 1순위 디자인 가설로 격상**. 화성섬유는 실제 원사·기계·편직 과정·원단 롤/제품·현장 관리 장면을 보여줄 현실적 대상이 있어, 영상의 '움직이는 제조 근거'와 현대적인 표현을 결합하면 차별성에 도움이 될 수 있다.
- 단순 고급 영상 도입으로 성과가 보장되지 않는다. **영상 첫 장면/정적 첫 프레임에서도** 회사가 환편 원단을 직접 편직·공급하며 상담하는 업체임을 알 수 있도록 별도의 고정 제목·설명·명확한 제품/용도·샘플 상담 접근을 갖춘다.
- 영상 자체가 회사 이름/취급 원단/문의 메시지를 대신하게 하지 않는다. 예: '원단을 직접 편직합니다'처럼 사실에 근거한 한글 타이틀 + '폴라폴리스·인타록·싱글 원단 등'의 정확한 보조 내용. **문구는 제안**, 영업 성과 보장·프리미엄 소재 주장 금지.
- **영상 콘텐츠 예시 8~12초 실촬영 편집:** 현장 전경 → 원사 공급/편직기 실제 움직임 → 작업자의 점검 장면(가능하면) → 생산된 원단·표면·롤. 첫 프레임부터 제조 실체를 볼 수 있게. 컷 길이와 타임라인은 촬영 후 결정할 시안 초안이며 확정 스펙 아님.
- 배경 비디오는 웹페이지와 일체화된 muted/playsinline 영상으로 표현하고, **유튜브/외부 플레이어의 영상 프레임·재생 버튼이 첫 화면의 중심을 차지하지 않도록** 한다. 가독성 유지, 자동 재생 가능 환경에서는 조용히 자연스럽게 재생하되 실패/모바일/저속 회선에서는 최적화된 정지 이미지를 표시.
- 반복 재생/움직임은 접근성 대응: 적절한 일시정지/중지 제어, 사용자의 줄인 동작 설정(reduced motion) 준수, 움직임이 본문 읽기와 경쟁하지 않게.
- **선결 조건:** 영상의 촬영·조명·구도·색감·편집 품질이 충분해야 하고, 실제 화성섬유 환편 현장을 정확히 담아야 함. 조잡한 편집이나 소재 부족 시 정적 사진 히어로가 더 신뢰할 만하므로 대안을 보존.
- 기술 단계에서 데이터 용량/초기 화면 표시(LCP)/모바일·배터리·네트워크/영상 포스터·SEO 텍스트 노출 테스트. 영상 히어로 사용 여부는 '첫 5초 이해도 + 시각 완성도 + 성능 + 실제 촬영 가능성'을 비교한 후 사용자 승인.

### 다음 비교할 시안
A. **현장 제조 시퀀스 배경 영상 + 고정 타이틀/보조 설명 + 두 상담 진입점** (현재 1순위 권고 가설).
B. 같은 메시지·구도를 적용한 **고품질 정지 사진 히어로** (촬영·성능 대안).
C. 필요시 사진/영상 레이아웃 혼합형, 화면의 절제된 스크롤 움직임. 
영상 대 사진은 '디자인 취향'만이 아니라 **실제 원본 영상의 퀄리티/일관된 사진/모바일/고객 이해도** 기준으로 비교. 외부 사이트 영상 무단 복사 금지.

## 8. 검토 상태
- **확인된 사용자 선호:** Yitai 실물 사진·현장·사람·원단·적은 문장, Camira 히어로·정제된 무드·미묘한 인터랙션.
- **사용자가 명시적으로 배제한 것:** 어색한 유튜브 플레이어처럼 보이는 메인 동영상, 첫 화면에서 사업/주력 분야를 알기 어려운 홈페이지, 실제 제조 사진을 보기 어려운 지나치게 디자인회사 같은 사이트.
- **아직 미승인 추천:** 정확한 히어로 문구/구성, 현장 사진 중심 분할 vs 풀블리드, 컬러/서체, 인터랙션 사양, 섹터 순서/높이, 상세 시안.
