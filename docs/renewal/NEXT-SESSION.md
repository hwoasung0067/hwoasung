## 확정하지 않은 것
- 홈페이지 최종 핵심 카피·사이트맵·정보 구조·문의 폼의 상세 입력값/단계.
- 실제 제품별 대표 SKU, 사진, 중량·폭·가공·가용 재고 표시 정책.
- 온라인 업종별 타깃 우선순위. 제품 중심 검색 유입과 소개/직접영업 신뢰 보강은 검증할 가설.
- ERP 내부 중요 문의 메모 기록 공간이라는 **최소 사업 범위는 합의 완료**. 세부 필드·접근권한/보존·실제 ERP 페이지 구현은 미승인. 전체 자동수집/상담 파이프라인/알림/실발주 자동 매칭은 현 단계에서 **보류**. 별도 CRM/관리 앱은 제외한다.
- UX 시안·디자인 무드보드/브랜드 시스템, SEO URL·기술 구조, GA4 이벤트 구현 및 배포.

## 다음 작업의 정확한 순서
1. **현재 ERP 영업문의 자동화 논의 종료:** 선택적 중요 문의 메모만 MVP 방향(D-028). ERP 구현 자체는 별도 ERP 코드/권한 점검 및 후속 사용자 승인 후 수행. 이미 확인된 카카오 1:1 채팅 형태와 자동화 선호를 다시 묻지 않는다.
2. **Phase 1 제품 콘텐츠 검토:** 폴라폴리스·인타록·T/R 싱글·DTY 싱글 중 홈페이지에 대표로 보여줄 실제 공급 원단의 사양·사진·용도·선별된 선재고/보유 생지 안내를 어떤 수준까지 공개할지 하나씩 결정한다. 제품군 4종 선정 자체는 재질문하지 않는다.
3. **마케팅/성과 과제:** 네이버 블로그·파워링크·Google 검색·홈페이지의 역할 분담과 이미 확인한 GSC/GA4 계측 한계를 토대로 유효 B2B 문의를 늘리는 경로를 검토. A 직접 공급형 핵심성과/B 개발형 별도 지표는 유지하되 현재 CRM 구현을 강요하지 않는다.
4. P1 승인 항목 검토 → P2 UX/IA → P3 디자인 → P4 콘텐츠/SEO → P5 기술·계측 → P6 통합 승인 → P7 Codex 구현.
