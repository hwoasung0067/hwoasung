## 확정하지 않은 것
- 홈페이지 최종 핵심 카피·사이트맵·정보 구조·문의 폼의 상세 입력값/단계.
- 실제 제품별 대표 SKU, 사진, 중량·폭·가공·가용 재고 표시 정책.
- 온라인 업종별 타깃 우선순위. 제품 중심 검색 유입과 소개/직접영업 신뢰 보강은 검증할 가설.
- ERP 내부 중요 문의 메모 기록 공간이라는 **최소 사업 범위는 합의 완료**. 세부 필드·접근권한/보존·실제 ERP 페이지 구현은 미승인. 전체 자동수집/상담 파이프라인/알림/실발주 자동 매칭은 현 단계에서 **보류**. 별도 CRM/관리 앱은 제외한다.
- UX 시안·디자인 무드보드/브랜드 시스템, SEO URL·기술 구조, GA4 이벤트 구현 및 배포.

## 최신 브랜드 방향 — 2026-10-20 (브랜드 선택 D-030 승인, 상세 시안 미승인)
- 판매 목표는 여전히 A 기존 원단 직접 공급형이 우선, B 조건부 샘플 개발은 별도 가치(D-023). 주력 4종 + 추가 보드레 및 본딩/누빔 등 용도 진입 후 상담(D-029)도 **그대로 승인된 원칙**.
- 새 쟁점은 **홈페이지 첫 화면의 커뮤니케이션 방법**: 주력 4종을 크게 진열하면 실제 온라인 방문자의 니즈보다 좁아 보일 수 있음. 기존 '샘플 보내달라' 문구가 샘플/사양 미숙 구매자를 더 유도했을 가능성.
- 사용자는 온라인 구매자 30~50대/밴더·창업자·비전문 바이어 비중이 높고 기존 주요 고연령 공장 사장님은 온라인 유입이 적을 수 있다고 추정. 이는 **미검증 가설**이며 이미 본 정성 문의 표본에는 채널/문구 선택 편향이 있음.
- 제조 경력과 유연한 운영 감각을 함께 가진 **2세 30대 경영자**라는 장점은 직접 홍보보다 디자인, 현대적이고 명확한 UX, 부담 없는 소통, 정확한 공급 정보로 암시하고자 함.
- **D-030 승인:** 사용자 스스로 현재 **프리미엄 원단** 브랜드를 표방하기에는 준비가 부족하다고 평가하고 제외. 대신 기존 **2번 제조 기술·공장 전문성 + 3번 현대적이고 유연한 제조 파트너십**을 결합하는 브랜드 방향 확정. 제조 신뢰/실제 현장 기반, 원단을 잘 모르는 사람도 상담 가능, 2세/30대는 메인에서 전면 홍보하지 않음.
- **화면은 아직 미정:** 홈페이지 메인의 정확한 카피·이미지·제품 카드 위치/비중·탐색 UX는 Phase 2/3에서 결정. 주력 제품 실제 공급 능력의 증거와 제품명/사용처·샘플 2가지 진입 경로를 모두 검토. 기존 상품 카탈로그형/샘플상담형 비교도 UX 판단 참고 이력으로 남긴다.
