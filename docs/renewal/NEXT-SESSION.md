## 가장 중요한 확인 완료 사항 (중복 질문 금지)

| 영역 | 사용자 확인 사실/전략 | 결정 |
|---|---|---|
| 사업 우선 목적 | 편직 임가공 자체의 문의보다 **직접 편직 기반의 원단 공급**, 특히 가공 완료 원단 판매 확대 | D-003~D-005 |
| 주력 4개 제품군 | **폴라폴리스, 인타록, T/R 싱글, DTY 싱글**. 나열 순서는 판매 우선순위가 아님 | D-012 |
| 추가 판로 | 보드레는 생지·원사 보유 기반 기회. 국내/수출 수요 및 마케팅 범위는 추후 검증 | D-013 |
| 보유 완제품 | 네 제품군 모두 일부 공통 사양/색상의 염색·가공 완료 원단을 선별적으로 보유. 모든 색상/규격에 있다고 홍보하지 않음 | D-014~D-015 |
| 샘플 | 역량 내면 새로운 사양도 적극 검토하되, 신규 원사 구매는 고객 비용 부담을 전제로 예외 검토. 기계 세팅이 필요한 샘플은 비용 청구; 바쁜 시기 수락 어려울 수 있음. 본 발주 시 차감은 건별 협의 | D-016~D-018 |
| 수량 제약 | **'신규 생산 500yd부터 가능' 문구 폐기.** 가용 완제품은 절 단위 공급 가능; 보유 생지 후가공은 공정 최소량; 신규 편직은 세팅/상당한 물량, 신규 원사 구매는 기계 기본 원사 투입량 필요 | D-019 |
| 선호 고객 | 원단 도매·유통업체와 실제 원단을 쓰는 본딩·누빔·PU코팅·봉제 공장. 실제 주요 거래는 소개·업계 인맥·직접 영업에서 시작. 온라인 신규 실거래는 아직 증명되지 않음 | D-020~D-021 |
| 온라인 현재 근거 | GSC에서 광범위한 '편직/섬유공장/원단공장' 검색어가 확인되고 검색 클릭은 루트에 집중. GA4에 제품별/성공 문의 전환 측정 부족. 이메일 접수에 특수·저적합 문의 혼재. 검색어 익명화·전화/카카오 누락 유의 | D-022 |
| 영업 성과 | **A 보유 제품 직접 공급형 = 1차 핵심 성과**, **B 조건부 신규 개발형 = 별도 성장 지표**. C 범위 밖/D 정보 부족은 운영 절차 미확정 | D-023 |
| 거래 가치 | **대량 첫 발주와 반복 거래 모두 중요한 우량 고객**. 샘플만 받고 중단, 무관한 문의, 높은 개발 부담과 소량·일회성이 겹치는 요청은 가치 낮을 수 있음. A/B와 대량/반복은 서로 다른 분류 축 | D-024 |

## 확정하지 않은 것
- 홈페이지 최종 핵심 카피·사이트맵·정보 구조·문의 폼의 상세 입력값/단계.
- 실제 제품별 대표 SKU, 사진, 중량·폭·가공·가용 재고 표시 정책.
- 온라인 업종별 타깃 우선순위. 제품 중심 검색 유입과 소개/직접영업 신뢰 보강은 검증할 가설.
- 문의 이후 견적·샘플·실발주 결과를 어떤 도구로 기록/대조할지 및 정량 KPI.
- UX 시안·디자인 무드보드/브랜드 시스템, SEO URL·기술 구조, GA4 이벤트 구현 및 배포.
