# 현재 방향 — 승인 범위와 보류 구분
출처: 기존 decisions D-023/029/032/043/044/046/050, 사용자 제공 피드백(2026-10-23), D-053 도구 변경. 아래 추가 분석은 `design-judgment.md`에서 제안으로 구분한다.

## 승인된 핵심
- 실제 자체 환편 기반 B2B 원단 제조·공급사. 기존 제품 기반 가공 완료 원단 공급 확대가 우선이며 무제한 맞춤 편직 대행 광고가 아니다.
- 브랜드 철학: 제조 전문성은 깊지만 고객과의 거리는 가까운 회사.
- 긴 Why·품질/납기 자기평가 반복 대신 원단·현장·타이포·여백·목적 있는 움직임으로 정체성과 호기심을 전달한다.
- Hero → Our Fabrics(+사용처) → Manufacturing → Field Notes → Closing/Contact 다섯 장면.
- Tintex의 밝고 정돈된 편집 + Arville의 실제 제조 현장감. R2 밝은 방향 우선, 전체 다크/프리미엄 패션 포지셔닝 아님.
- 원단: 폴라폴리스·인타록·T/R 싱글·DTY 싱글 우선, 보드레도 정식 추가 품목.
- 자체 원사 매입·환편 편직/생지 생산과 협력 염색·기모·후가공을 구분.
- 원단명/사양 또는 용도/샘플 양쪽에서 상담. 재고·MOQ·샘플비·납기·공급 가능성은 개별 확인.

## 최신 도구·권한 (2026-10-23)
Figma MCP 한도로 사용자가 브라우저 시안 제작으로 전환 승인. Figma 연결 복구를 기다리거나 재시도하지 않는다. 기존 파일 9개 프레임은 보존할 이력이며 브라우저 버전과 동일시하지 않는다. 검토용 코드·반응형/동작 QA는 진행 가능. 운영 src 교체·main 푸시·DB·ERP·배포는 별도 승인.

## 미확정
`제조의 깊이를, 더 가깝게.`는 작업 문구. 최종 슬로건·색·폰트·세부 배치·모션·제품 실사·최종 디자인은 승인 전. 현재 브라우저 04.2도 검토용 DRAFT다. 03은 사용자 채택 제외 이력이다. 영상 제작은 보류. 실적 수치/타사·AI 사진을 사실로 추가하지 않는다.

## 협업
자료 조사·분석·검증·문서화·승인된 시안 발전은 계속 진행. 핵심 선택은 대안 2~3개·1순위·이유·단점을 함께 제시. 이미 정한 브랜드와 구조는 재질문하지 않는다. 사용자 피드백은 그대로 복종하는 스타일 명령이 아니라 의도·사업 효과·부작용을 검토할 근거다.
