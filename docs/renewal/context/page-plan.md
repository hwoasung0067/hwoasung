# 5장면 실행 계획

| 장면 | 역할/필수 정보 | 현재 보완 | 검토 기준 |
|---|---|---|---|
| Hero | 짧은 메시지 1개·원단 제조/공급 정체성·원단 진입 | 사진과 타이포의 통합 구도 | 첫 화면에서 업종·다음 행동이 보이는가 |
| Our Fabrics | 주력 4종+보드레·사용처 작은 연결 | 균등 카드 반복 완화, 제품 접근 유지 | 제품과 사용처를 혼동하지 않는가 |
| Manufacturing | 원사·환편·생지·협력 가공 경계 | 현장 이미지 존재감·낮은 텍스트 밀도 | 자체 염색처럼 오인하지 않는가 |
| Field Notes | 기존 실제 블로그의 유용한 글 | 최신순 대신 바이어 질문 중심 편집 | 허구 글 없이 전문성 탐색으로 연결되는가 |
| Contact | 편안한 상담·연락 경로 | 제품명/용도 선택 맥락 이어주기 | 공급 약속 없이 문의를 시작할 수 있는가 |

다섯 장면은 동일 높이 카드 다섯 묶음이 아니다. 강한 도입→밝은 소재→밀도 있는 현장→조용한 기록→가벼운 문의의 리듬을 설계한다. 사용처 확장은 실제 공개 사진이 확보되고 필요가 검증될 때만 제안한다.
