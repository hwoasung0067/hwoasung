# 레퍼런스 — 사용자 감상과 분석 분리

## Arville https://arville.com/
- 사용자 감상(기존 15·D-037/043): 고품질 제조 사진과 풍부한 영상에서 신뢰를 느낌. 동일 수준 자료 확보 가능성은 부담.
- 실제 재검토(기존 34, 2026-10-23): 큰 현장 미디어/타이포, Products·Sectors·Capabilities의 사진 내비게이션을 확인. 전체 모션/모바일 성능을 검증한 것은 아님.
- 적용 판단: 실제 제조 장면의 힘과 제품/사용처의 구분을 취한다. 노란색·기업 규모·자가 코팅·인증·긴 Why는 복제하지 않는다.

## Tintex https://www.tintextextiles.com/
- 사용자 감상: 라이트하고 깔끔한 인상, 편직/원단이라는 업종 유사성. 영어 설명을 해석해서가 아니라 사진·영상·여백·움직임·전체 톤이 좋았음.
- 실제 재검토: 미디어가 화면을 채우는 Hero, 밝은 사진 분류, 비대칭 텍스트/이미지, 어두운 기술 구간 대비 확인.
- 적용 판단: 밝은 편집은 단순 아이보리 배경을 의미하지 않는다. 미디어와 타이포의 관계·밀도 차이를 설계한다. 지속가능성/자가 후가공 능력은 화성섬유 주장으로 가져오지 않는다.

보조: Camira의 첫인상/절제된 상호작용, Yitai의 실제 현장·사람·제품 사진. 디자인 스튜디오나 럭셔리 브랜드처럼 제조 실체가 사라지는 방향은 피한다.

상세 근거: 기존 11, 15, 34번 문서. 실사/영상 자산을 복사하거나 무단 사용하지 않는다. 사이트의 현재 버전은 변할 수 있으므로 새 분석은 날짜/확인 범위를 기록한다.
